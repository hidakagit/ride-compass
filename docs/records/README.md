# 記録

この配下は**記録**であり、維持しない。

- **記録時点で嘘がないようにする。** 後から事実が変わっても書き換えない
- **訂正するなら、訂正の記録を足す。** 過去の記録を書き換えて辻褄を合わせない
- したがって、ここに残るリンクや名前が現在の実装と食い違っていても欠陥ではない。
  レビューの対象にも、検知器の走査対象にもしない

| 置き場所 | 中身 |
|---|---|
| `tasks/` | タスクの記録。`Txxx.md` が1件=1ファイル。日付名のものは、タスク単位に分ける前の実施記録 |
| `decisions/` | 決定の記録 |

現在の状態を知りたいときは記録ではなく、台帳（`../improvement-plan.md`）と正本
（`../architecture.md`・`../modules/`・`../conventions/`）を見る。
