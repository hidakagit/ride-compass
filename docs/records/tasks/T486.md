# T486. ルート設定・ルート結果パネルの省スペース化と色分けの2択簡素化

状態: 完了（2026-08-31）

- 背景: ユーザー指示。「上に地図を見ながら下で設定したいので、パネルはなるべくエリア
  少なめがいい」（ルート設定パネル）・同様の省スペース化（ルート結果パネル）・
  「おすすめ度は距離の合わせ込み・・・」の説明文をタイトル横の情報アイコンへ・
  生成したルートの色分けを「①総合難易度／②地図で選択中のレイヤ」の2択に簡素化・
  ルート全体プロファイルをルート設定パネルで有効にした軸だけに絞る、の5項目。
  実装前にAskUserQuestionで3点確認済み（色分け2択の設置場所→ルート結果パネル内に新設、
  プロファイルの絞り込み基準→チェックボックスON[重み問わず]、実装範囲→5項目すべて）。
- 対応:
  1. `RouteSettingsPanel.module.css`: 軸一覧`.group`へ`max-height: 40dvh; overflow-y: auto`。
     軸数に関わらずパネルの自然な高さを抑える。
  2. `page.tsx: renderRouteColorSectionBody`: 色分けのRadioGroupを、軸カタログ全件から
     「①総合難易度／②選択中の軸（現在の`routeStyleModeId`が非difficultyならそれ、
     でなければ`filteredRouteStyleModes`の先頭）」の2択へ簡素化。凡例チェックリストは
     `Disclosure`で既定折りたたみに変更（MapLayersPanel.module.cssの`.layerSection`等を
     流用、RouteSettingsPanelの「除外する道路」T419と同じ方針）。
  3. `RouteList.tsx`: `SCORE_HINT`の常時表示段落を、情報アイコンのポップオーバー
     （`FieldLabel`、他パネルの軸説明と同じ部品）へ収納。
  4. `page.tsx`: `RouteAxisProfile`へ渡す`axes`を`routePreference[axisId] > 0`（チェックON）
     で絞り込み。
  5. `BottomSheet.module.css`: ユーザーからの追加指摘「パネル上部（タイトルのみ）が
     冗長」を受け、`.closeButton`のmin-width/min-height 44px（タップ領域目安）が
     `.header`行全体を押し上げていたのを28px角へ縮小し、`.header`のpaddingも詰めた
     （`.handle`をT419で同じ理由から縮小した実績に揃える）。
- 検証: `tsc --noEmit`・関連テスト55件（RouteList・RouteSettingsPanel・RouteAxisProfile・
  BottomSheet・page.test.tsx）通過。Browserペインで実際にルート生成→ルート設定/結果
  パネルの新レイアウトを操作し、①スクロール境界②色分け2択の切替（勾配↔総合難易度、
  凡例Disclosureの開閉）③ルート全体プロファイルの絞り込み（重み0の軸[夜間]が
  出ないこと）④BottomSheetヘッダーの見た目、いずれも正しく動作することを確認した。
- 経緯（並行セッションとの作業ツリー共有について）: 検証中、別セッションが同じ作業ツリーで
  T416（洪水キキクル、MapView.tsx/dynamicWeather.ts/riskMap.ts等）を並行実装しており、
  その未完了状態と思われるMapLibreクラッシュで一時的にブラウザ確認がブロックされた
  （待機後、相手の作業が進み解消した）。それらのファイルには一切触れていない。
