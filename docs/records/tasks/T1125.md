# T1125. 地図で押した道の詳細を、見切れず短く読める形にし、評価を利用者がいま設定している重みで出す

状態: 未完了（2026-09-25起票）

## 背景

ユーザー報告（2026-09-26、スマホ）: wayの詳細画面が使いにくい。画面上で見切れる。折りたたみをもっと積極的に使ってシンプルにしてほしい。バーが重みと連動していない。調べた結果: ①評価（POST /api/region/axis-inspector）はbackendが既定の重み（region_service.py: RoutePreference()）で計算し、frontendも今の重みを送っていない——重みタブで0にした軸も効いて見える。②詳細はMapLibreのPopupで、開いた後に「この道の評価を見る」で中身が伸びても位置を決め直さない（popup._updateは地図が動いたときだけ）ため上へはみ出す。③地図のタイルから出す事実（道路名・路面・一方通行等）と、backendのタグの行（道路の種類・路面・一方通行等）が同じ項目を二重に出す（スクリーンショットで「道路の種類 primary」が2回）。規模の根拠: backendのルーター・サービスとそのテスト、frontendのRoadInspectorPopup・MapView・regionApi・そのテスト、生成物・設計書で、変わるファイルは8〜10（③20以下）。
