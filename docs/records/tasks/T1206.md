# T1206. backend が決める値・制約を、backend 側の宣言から母集団を導いて画面へ配る（経由地の上限が画面に届かず、9点目で英語の422が出る）

状態: 未完了（2026-09-27起票）

## 背景

周期レビュー第14回（2026-09-27）の起票案（ダッシュボード proposal-backend-declares-from-backend-side、承認済み）。

規模M（根拠: 段1 は routes.py・export_openapi.py・useGenerationConditions.ts・生成物の4〜5ファイル。段2以降は母集団で決める）

■ 背景
性質: backendが決めるべき値をfrontendが計算し直す（再発: 第13回 T1140・T640）。T1140 は「frontend の直書きを生成物と突き合わせる」数え方で母集団を取ったため、次の3種が原理的に見えない: (1) backend が配っていない事実 (2) 文の中の事実 (3) 写しではなく導出されたもの。
実害: routes.py:172 の `waypoints Field(max_length=8)` が route-generate-config.json に無く、画面（useGenerationConditions.ts:84）は経由地を上限なしに足す。9点目で422になり、lib/apiError.ts が Pydantic の英語の msg をそのまま結果欄へ出す。ほか routes.py:140 le=50・MAX_SPLICED_EDGES も生成物に無い。
(2) の例: mapLayers.ts の「現在〜3時間先」（weather_elements の frame_rule）・「キキクル4種」「5段階」・「建物は塗りません」、TodayOutlook の「2時間ごと」（weather_service の private 定数）。(3) の例: 軸の識別色を画面が HSL で作る（backend は CIELCh）、段の色の補間、RAMP_AXIS_VALUE_KIND・MAX_EXPERIMENT_SLOTS・windLayer の 0.0025・EARTH_RADIUS_KM、生成物の配列を位置 [n] で引く11件、map_value_thresholds が null のとき画面が既定を2か所で解く。

■ やること
段1: 経由地の上限・探索距離の上限・合成の区間数を domain の1モジュールへ集め、生成物へ出し、画面は上限で操作を止める。422 の文言を日本語にする経路も確かめる。
段2: 母集団を backend 側から導く: request モデルの Field/Query の制約（AST で ge/le/max_length）、応答の中身を決める services/routers の private 定数、WEATHER_ELEMENTS の frame_rule を列挙し、「生成物に出ているか／画面から操作・表示されるか」で分類。frontend 側は文言の中の数字＋単位・生成物を [数字] で引く箇所・色を組み立てる関数で突き合わせる。
段3: 分類の結果で直す（文の中の事実は宣言から組み立てる、色は backend が配る）。

T1140 は閉じ、T1159 は括弧・色の置き場の決まり。数え方の欠けは新しい規則。
