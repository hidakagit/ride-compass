# T957. 軸スタジオで刻んだしきい値が、地図では黙って減ることがある 規模S

状態: 未完了

未着手（2026-09-19起票、T939から分離）

## 背景

[T939](T939.md)で、**折れ線が同じ難易度へ写す境界は段として作らない**ことにした
（`domain/axis_display.py: ramp_band_thresholds`）。評価が区別できない差に色の境界を引くと、
色だけが変わって評価は同じ、という見分けを地図が見せることになり、しかもルート線側は難易度を
塗るためその段を作れない（前後で段の数が食い違う）。

この畳み込みは`display_thresholds_override`——**人が軸スタジオのGUIで指定した値**——にも効く。
テストのフィクスチャでは、4つ刻んだ上書き`[2.0, 4.0, 7.0, 12.0]`が、折れ線が5.0で100へ達する
ため`[2.0, 4.0, 7.0]`になる。**画面はこれを何も伝えない**——保存はできるのに、地図の段は
指定より少ない。

## 対応方針（着手時に確定）

軸スタジオのしきい値編集で、折れ線が飽和して効かない境界をその場で示す。どの形にするかは
未定（入力欄の脇に印を出す／保存時に知らせる／分布プレビューへ重ねる等）。

## 保留した場合の影響

刻んだ数と地図の段数が合わない理由が画面から辿れない。較正のたびに「効かない値」を
手探りで見つけることになり、`ramp_band_thresholds`の存在を知っている人にしか説明が付かない。
