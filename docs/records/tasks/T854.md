# T854. 生成したルートを保存して、後から呼び出せるようにする

状態: 未完了

## 背景

「ルート結果」ヘッダに「保存（準備中）」のdisabledアイコンが常時置かれていた
（[T597](T597.md)で位置だけ先に確保したもの）。押しても何もできない入口を残さない方針
（`docs/design-principles.md`「UI仕様」）に反するため[T760](T760.md)で撤去した。
**機能そのものの要否はここで引き取る。**

いま生成結果を手元へ残す手段はGPX出力だけで、これはファイルを書き出す操作である。
「同じ条件でまた生成する」「気に入った候補を後で見返す」には足りない。

## 決める必要があること

- **何を保存するか**: 生成条件（`route_preference`・距離・0次除外・地点）か、生成結果の
  候補そのもの（geometry・segments）か、両方か。条件だけなら軽いが、生成し直すと同じ
  候補が出るとは限らない（フロンティア方式は決定的だが、道路データ・気象が変われば変わる）。
- **どこへ保存するか**: localStorage（端末に閉じる・容量数MB）か、backend＋DB（端末を
  またぐが、利用者の識別＝ログインの導線が要る）。現在このアプリに認証は`/admin`の
  Basic認証しかない。
- **走行中に使うか**: 主用途がロードバイク走行中のスマホであることを踏まえ、一覧・呼び出しの
  導線をどこへ置くか（`docs/design-principles.md`「走行中に見るかを基準に情報量を絞る」）。

## 保留し続けた場合に起きること

生成した結果を残す手段がGPX出力だけの状態が続く。GPXは外部アプリへ渡すためのもので、
このアプリの中で「前に作ったあれ」を開き直すことはできない。条件を毎回組み直すことになる
ため、評価軸の重みを詰めて使う使い方（このアプリの中心）ほど手戻りが大きい。
