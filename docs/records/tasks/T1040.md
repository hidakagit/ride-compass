# T1040. PNG_CONTENT_TYPEが2つのタイルサービスに重複している

状態: 完了

## 判断: 見送り（2026-09-23・周期レビュー第12回、ユーザー承認済み）

## 背景

土地被覆タイルと地形タイルの2つのサービスが、同じ内容の定数をそれぞれ持っている。

## 見送りの理由

**1語の定数で、片方が古くなっても症状が出ない。** 共有すべき「決まりごと」は、
片方だけ変わったときに食い違いが実害になるものを指す。この値は外部仕様（PNGの
メディアタイプ）で固定されており、片方だけを変える理由が存在しない。

共通化すると、2つのサービスの間に共有モジュールへの依存が1本増える。得るものが
無いまま依存が増える側に倒れる。

## 再評価の条件

**この値が可変になったとき**（例: WebP等への切り替えを条件で行うようになったとき）。
そのときは値が判断を含むようになるため、1箇所へ集約する理由が生まれる。
