# T925: 較正を更新から分け、実データが主役の画面にする

状態: 未完了

未着手（2026-09-17起票。背景だけを書いた段階で、対応方針・段階分けはまだ無い）

## 背景

「決まっている値を直す（更新）」と「実データを見ながら値を探る（較正）」は、要るものが違う
——前者は全項目の一覧性、後者は分布と地図の見え方。いまはどちらも同じダイアログに同居し、
較正の道具（分布プレビュー・段階プレビュー）がフォームの脇役になっている。

更新はAPIでも代替できる（業務ユーザー向けのショートカット）が、**較正はGUIにしかできない**
——そこがこの画面の存在理由なので、主役として扱える場所を別に持たせる。

## 保留（ユーザー判断）: 軸スタジオで、値を探る「較正」を別の画面に分けるか（2026-09-23 依頼）

利用者への約束（管理者向け）: 実データの分布と地図の見え方を見ながら、軸の折れ点・段の境界を決められること。

いま: 軸スタジオの編集ダイアログに、全項目の入力欄と、分布プレビュー・段階プレビューが同居している。折れ点を
動かして地図での見え方を確かめたいとき、プレビューは入力欄の脇の小さな枠で、入力欄をスクロールしながら見ることになる。
起きない場面: 決まった値を書き換えるだけ（更新）なら今のダイアログで足りる（APIでも代替できる）。

1. **（推奨）較正を別の画面にし、分布と地図を大きく出して値の入力は脇に置く。** 更新は今のダイアログに残す。
   [T396](T396.md)で方向だけ合意していた編集カードの3種類化も、この画面の作り直しに含める（同じダイアログを
   2回作り直さずに済む）。画面は実装の前にモックで詰める。
2. **今のダイアログのまま、プレビューを大きくするだけにする。**
3. **見送る（今のまま）。**

保留した場合: 方針と段階分けが無いため、担当へ振り出せない。
