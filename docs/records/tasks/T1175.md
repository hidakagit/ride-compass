# T1175. 路面の材料を2つ（surfaceタグの路面区分・tracktypeの等級）作り、まず地図で別々に確かめられるようにする（区分への合成と、舗装質の軸・所要時間への反映は後の段）

状態: 未完了（2026-09-26起票）

## 背景

起票案 proposal-surface-class（2026-09-26承認）。T856-surface-untaggedへのユーザーのコメントから。段階1（材料と地図、M）: ①surfaceタグの路面区分（舗装／締め固め・細砂利／砂利・未舗装／土・草・泥・砂／石畳／タグ無し）②tracktypeの等級（grade1〜5／タグ無し。区分へ写さず等級のまま。grade2は大半が砂利76%）を派生だけで作り、地図の別々のレイヤーと道の詳細で見られるようにする。評価と所要時間は変えない。段階2（L、本番DBへ書く）: 区分を合成し、舗装質の軸と走行モデルの転がり抵抗が同じ区分を読む（問いは段階2の前に置く）。調査の数字（本番DB20%抜き取り・延長で重み付け）とOSM以外の候補を採らない理由は起票案の本文にあり、着手時に記録へ移す。
