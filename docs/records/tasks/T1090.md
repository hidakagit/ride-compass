# T1090. frontendが呼ぶAPIのパスを、OpenAPIの宣言と型で照合する

状態: 未完了（2026-09-24起票）

## 背景

frontendのサービス層は、タイルのURLも含めてAPIのパスを17か所すべて手で書いている（services/*.ts）。OpenAPIの生成物（types/generated/api.d.ts の paths）には同じパスが宣言されているが、突き合わせる仕組みが無いため、backendでパスを変えると画面から実際に呼ぶまで食い違いに気づけない。案: パスの文字列を paths のキーとして型で縛る（例: satisfies keyof paths）。T1001段階Aの見直しでタイルのパスの手書きとして見つけた。サービス層の全呼び出しへ当てるかを1つの判断として決める（2026-09-24、ユーザー承認）。
