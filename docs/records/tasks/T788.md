# T788. 重みタブから余白と操作を削り、軸の説明をチップへ戻す

規模S。
状態: 完了（2026-09-13、[T784](T784.md)の実機フィードバック。採番はT786で確保しようとしたが
並行セッションが先に使ったため振り直した）

## 背景

[T784](T784.md)で帯グラフを主役にした結果、帯の上の余白（ドラッグ中バッジ用）と、
選択中の軸の行（±ボタン）が要らなくなった。%は帯とチップの両方に常時出ており、
ドラッグすればその場で動くのが見えるため、説明文も操作の重複も不要。

## 対応方針

- 帯の上のドラッグ中バッジと、そのための余白を撤去して見出しを上へ詰める。
- 「増やしたぶんは〜」の説明文を削る。
- 選択中の軸の行と±を撤去し、調整手段を帯の境界ドラッグへ一本化する。
- 軸の説明は各軸チップの情報アイコンから読む形へ戻す。

## 実装メモ

- ドラッグ中バッジ（`stackBarDragBadge`）とそのための上余白（24px）を撤去。帯の区間と
  チップの%がドラッグ中もその場で動くため、同じ値を浮かせて出す必要が無くなった。
- 選択中の軸の行・±・`adjustAxisShare`を撤去し、調整は帯の境界ドラッグ（と矢印キー）へ
  一本化。軸チップは本体タップで有効/無効、(i)で説明、有効な軸は%を併記する形へ戻した。
- 除外タブのベタ書き説明も見出し脇の(i)の奥へ移した。
- この2点（冗長なものは削る／ベタ書きの説明を置かない）をUI全般の原則として
  `docs/design-principles.md`「UI仕様」節へ追記した（[T785](T785.md)で入れた「利用者が
  決めた値は覚える」も同じ節へ）。

- `配分を増やす/減らす`のボタン 0件、「増やしたぶんは〜」の文言なし
- 軸チップの説明(i) 11件（公開軸ぶん）、除外タブはベタ書き文言なし・見出し脇に(i)あり
