# T1050. 「信号とみなす半径」の較正値を、ノードの値を埋める派生バッチが読んでいない

状態: 未完了（2026-09-23起票）

## 背景

domain/tuning.py が較正値 signal.match_radius_m（既定40m、効き方NODE_ATTRIBUTE_BATCH）を宣言し管理画面から変えられるが、実際に信号を判定する batch/derive_node_materials.py は自前の定数 SIGNAL_RADIUS_M=25.0 を使い、較正値を読んでいない（grep -rn match_radius_m backend/app の参照は宣言1件のみ、2026-09-23 T1009作業中に確認）。管理画面で変えても何も変わらず、画面の既定40mと実際の25mも食い違う。TuningEffect.NODE_ATTRIBUTE_BATCH のコメントも撤去済みの road_nodes を指す。
