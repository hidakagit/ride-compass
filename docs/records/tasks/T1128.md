# T1128. 撤去・移動を含むタスクを閉じるとき、未完了タスクの記録と「範囲外で見つけたもの」が点検されない

状態: 完了

## 背景

周期レビュー第13回（2026-09-26）の指摘。性質: 前提の消えたタスク（再発。T1028が第12回後に事後で棚卸しした形がT1112で再発）・未起票フォローアップ。T1112がタイル単位の材料キャッシュ・axis_registry_meta・掃除の関数を撤去したのに、前提にしていた未完了7件（T958・T959・T1051・T1007・T972・T388・T127）の記録が直っていない。閉じたタスクの「範囲外で見つけたもの」6件がリンクも理由も無く残った（T1099・T1096・T1092・T984・T965・T985。CLAUDE.md「人が見る3つ」の2は「未実施の段階・派生」だけを対象にしている）。大きな作り替えの後始末は説明文を拾ったが、生き残った型の既定値・任意型・設定項目は見ていなかった（T1112後にLeanEdgeの|None既定・読み手のいない設定が残存）。直すもの: CLAUDE.md「人が見る3つ」の2・3と.claude/commands/review.mdへ、(a)撤去・改名した名前で台帳の未完了タスクの記録もgrepし当たった記録へ1行追記する (b)閉じる点検の対象に「範囲外で見つけたもの」を加える（review.mdの検索語にも「範囲外」） (c)生産者を減らしたら残った型の既定値・任意型・設定項目を組み立て箇所・読み手と突き合わせる、を足す。検知器にはしない。

## 着手時の確認（2026-09-26）

- 前提の7件のうちT958・T959はb6c5a97bで「前提が消えたためクローズ」済み。残り5件（T1051・T1007・T972・T388・T127）は周期レビュー第13回がダッシュボードにkind `決定`で申し送りを置いており、各タスクの着手時に記録へ移る。このタスクでは5件の記録を書き換えない（規則を足すのが範囲）。
- ダッシュボードにT1128の件は無かった。
- origin/masterのCLAUDE.md「人が見るしかないのは次の3つだけ」の2は「未実施の段階・派生」だけ、3は撤去した差分のコメント行だけを見ていた。review.mdの「分割元タスクの未起票フォローアップ」の検索語は「未起票」「別タスク」「スコープ外」で、「範囲外」が無かった。(a)の二重チェックはreview.md「トリガー付きタスクの棚卸し」の③（消えた名前を未完了タスクの記録でgrepする）に既にあったため、review.mdへは足していない。

## 対応

- CLAUDE.md「人が見るしかないのは次の3つだけ」
  - 2へ、閉じるときに「範囲外で見つけたもの」も見て、1件ずつ行き先（既存のTxxxへのリンク・起票案として置いたこと）か直さない理由を添える、を足した。見出しは揃っていない（「範囲外」「範囲外で見つけたもの」「範囲外で気づいたこと」「範囲外の観察」）ので綴り「範囲外」で引くと書いた。
  - 3を「関数・ファイル・設定項目を撤去・改名するとき、それを前提にしたものが取り残されないか」に広げ、従来のコメント行の点検に、(a)台帳の`- [ ]`行が指す記録を撤去・改名した名前でgrepし、当たった記録へ1行書き足す（仕掛中ならダッシュボードにkind `決定`）、(c)値を作る経路を減らしたら残った型の既定値・任意型・設定項目を組み立て箇所・読み手と突き合わせる、を並べた。
- .claude/commands/review.md
  - 「分割元タスクの未起票フォローアップ」の検索語へ「範囲外」を足し、閉じたタスクの記録を対象にすると書いた。リンク先に既存タスクを含めた。
  - 「冗長さの型」へ「生産者を減らした後に残った既定値・任意型・設定項目」を足した（名前が消えないので名前の逆引きでは拾えない）。
- 長い説明を置く先の docs/conventions/*.md は、タスクを閉じる・撤去するときの点検を持つ文書が無く、足した文も短いため新設しなかった。
