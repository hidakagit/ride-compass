# T902. 土地被覆レイヤーが、都心では一律のグレーにしかならない

規模S。
状態: 完了（2026-09-16）

## 背景

配信も描画も正しく動いている。グレー`#9AA0A6`は**建物クラス**で、利用者が最初に見る場所が
ほぼ全部そのクラスだった、というだけである（本番の実タイルの画素を数えて確認）。

| 場所 | 建物の占有率 |
|---|---|
| 都心 z12 / z13 / z14 | 95% / 95% / 85% |
| 奥多摩 z13 | 8%（樹木89%） |
| 三浦半島 z13 | 55%（樹木36%・水面8%） |
| 関東本土bboxからz13を58枚抽選 | 中央値3%・建物70%超は6枚 |

**関東全体では建物は少数派なのに、既定の現在地（都心）だけが建物ほぼ100%**になる。そこで
ONにすると画面全体が不透明度0.32のグレーで覆われ、基礎地図が濁るだけで情報が増えない。

このレイヤーで知りたいのは「緑があるか・水辺か・畑か」で、**建物があることは基礎地図を
見れば分かる**。

## 対応方針

建物クラスを**塗らない**。レジストリ（`domain/landcover.py: LANDCOVER_CLASSES`）から
建物を消すのではなく、クラス自身へ「地図に塗るか」の宣言を持たせる——区間インスペクタは
8クラス全部の割合を数値で出しており、そちらは建物も要る（数値は薄まらない）。

チップの名前も「土地被覆」から変える。塗る対象が自然被覆だけになるため、名前が
「何が出るか」と食い違う。

## 完了条件

- 都心でONにしても基礎地図が濁らず、公園・川沿い・郊外の緑だけが浮き上がる（本番実機）。
- 区間インスペクタの内訳は8クラスのまま。
- タイルの世代が自動で変わる（配色レジストリの変化は署名が捕まえる）。

## 実装メモ

レジストリから建物を消すのではなく、`LandcoverClass`へ`painted: bool`を足して**クラス自身に
宣言させた**。区間インスペクタは8クラス全部の割合を数値で出しており、そちらは建物も要る
（数値は他のクラスに薄められない）。生成物（`landcover-classes.json`）へもこの宣言を載せ、
フロントの凡例は`LANDCOVER_PAINTED_CLASSES`を使う——塗らないクラスを凡例へ並べると、
色見本があるのに地図のどこにも無い表になる。

**チップの名前を「土地被覆」→「緑と水」へ変えた。** 塗る対象が自然被覆だけになったため、
名前が「何が出るか」と食い違う（都心でONにしても何も出ないのに「土地被覆」と書いてある、
という状態になる）。裸地・雪氷も塗る対象だが関東ではほぼ出ない（実測で裸地0.1%・雪氷0%）
ため、支配的なものを名前に採った。説明文とⓘには建物を塗らない理由を書いた。

タイルの世代は**手で上げていない**。`LANDCOVER_TILE_VERSION`はレジストリの署名から決まる
ため、`painted`を足した時点で自動で変わる（生成物`region-tile-config.json`の差分で確認）。

## 検証結果

配布元の実ラスタ（`54S_2024.tif`）で描き直し、画素を数えた。

| 場所 | 変更前 | 変更後 |
|---|---|---|
| 都心 z13 | 建物95% ・水面3% ・樹木2% | **透明95%** ・水面3% ・樹木2% |
| 代々木〜新宿 z14 | 建物93%・樹木7% | **透明93%・樹木7%**（代々木公園・新宿御苑だけが残る） |
| 奥多摩 z13 | 樹木89%・建物8% | 樹木89%・**透明8%**（変わらず読める） |

- 合成ラスタでのテストを追加（塗らないと宣言したクラスの色がタイルに出ないこと。
  「塗らないクラスが0件ならこのテストは何も確かめていない」というガード付き）。
  フロント側にも凡例から外れることのテストを追加。
