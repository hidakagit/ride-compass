# T1097. 経路探索エンジンのテストに残るFakeScoreMatrixとBagによる代役（NodeSpatialIndex・SearchMaterials・材料・_LegCostComposer等）を、本物の型で作る形へ置き換える

状態: 完了（2026-09-25）

## 背景

T1094・T1095で同じtest_road_graph_engine.pyの道路グラフの偽物と探索構造の偽物7種を本物の型へ置き換え、本物の型を作り変えたときにテストが落ちるようになった。T1095の担当が同じ性質の代役が残っていると報告した: FakeScoreMatrix（本物はdomain/evaluation.pyのStaticEdgeScoreMatrix。形が既にずれていて、本物はaxis_scoresの2次元配列、偽物は列の辞書を返す）と、Bagによる代役（NodeSpatialIndex——差し替えがBag(node_ids=…)を返し、テストが本物に無いnode_ids属性で渡された引数を確かめているので、置き換えるには差し替えがどの引数で呼ばれたかの記録の仕方から変える。SearchMaterials・材料・_LegCostComposer等）。完了の条件の案はT1095と同じ（本物で作れない入力でしか成り立たないテストはテストを弱めずに要確認として出す・置き換え前後の件数と行とカバレッジと偽物の数を並べる・本物の型を作り変えて検知を確かめる）。規模の根拠: ファイルは1本だが、記録の仕方の作り直しと組み立ての箇所の多さで変更行が200を超える見込み。起票案 kihyoan-engine-test-remaining-stand-ins として2026-09-25承認。

## 方針

担当W-standins。origin/master 3249b87e の上で行った。実装は変えていない。

- **範囲**: 題名の名前ではなく「このファイルが組み立てて渡し・読む、自分が持つデータ型の代役」という性質で決めた。
  ASTで`Bag(...)`の呼び出し76件とクラス定義（入れ子を含む）を列挙し、1件ずつ何の型の代わりかを決めた。
  同じ性質で題名に無かったもの（`TracedLoop`・`LoopTurnaround`・`RouteCandidate`・`RouteSegmentDetail`・`BoundingBox`・
  `WindForecastSeries`・`RoutePreference`・`AxisComposition`・`RiderProfile`・`DynamicAxisRequestContext`）も含めた。
- **範囲外と判断したもの**:
  - 層の境目・プロセス内の状態の代役: `FakeGraphService`・`FakeWeatherService`（Service）、`FakeSearchGraphCache`（キャッシュ層の
    モジュールごとの差し替え）。testing.md「フェイクの数は、実装の外向き参照の写し」の「層の境目」で、データ型ではない。
  - 関数の代役とその記録係: `ComposerWorld`・`PathRecorder`・`DiverseRecorder`と`fake_*`の関数群。
  - フィクスチャが返す一式の器（`search_world`・`ring_world`・`via_world`が返していた`Bag`3件）。何の型の代わりでもないため、
    `Bag`を消して標準の`types.SimpleNamespace`にした。
  - 識別用の目印（`"LAZY"`・`"STATICS"`・`"STRUCTURE_…"`・`"STALE"`・`"REBUILT"`・`object()`、21箇所）。キャッシュの素通しと
    同一性だけを見るテストが使い、エンジンは中身を1つも読まない——形を持たないのでずれようがない。
- **作り方**: 本物の型のコンストラクタで作る。足した作り方は、`segment_detail`・`route_candidate`・`traced_loop`（必須項目を
  型を満たすだけの値で埋める）、`wind_series`（時別の予報）、`node_index`（Nodeを持たない索引。最寄りNodeの探索は各テストが
  差し替えている）、定数`BBOX`。
  - `ElevationSource`はProtocolで、エンジンが知るのはこの口だけ。本物の実装（`EdgeMaterialArrays`・タイルのビュー）は材料カタログの
    列を要し、このファイルの責務外になるため、口を満たす表`ElevationTable`をテスト側に置いた（Protocolの実装であって、具体型の代役ではない）。
  - `RoutePreference`は宣言（`AXIS_DEFINITIONS`）に無い軸を拒むため、`tests/axis_system_fixture.py`の`replaced_axis_definitions`で
    架空の2軸を公開軸として宣言した間に組む（組んだ後の`with_time_scope`は宣言が空なら重みをそのまま返す）。
  - `_LegCostComposer`の代役（`detour_ratio`・`speed_kmh`・`_weights`だけを持つ`Bag`）は、既存の`make_composer`で本物を組んだ。
  - `DynamicAxisRequestContext`・`RiderProfile`は差し替え（`setattr`）自体を消し、エンジンが本物を組む。
- **空間索引の差し替えの記録の仕方**: `build_node_spatial_index`の差し替えを`bound`で本物の署名へ当て、渡された`node_ids`を
  `search_world.node_index_requests`へ記録してから本物の`NodeSpatialIndex`を返す形にした。
  `test_routable_node_index_is_keyed_by_the_zeroth_filter_settings`は、テスト内の独自の差し替えを消し、この記録で
  「2回組まれた・どちらも除外後のNode列で組まれた」を確かめる。
- **本物の型に合わせて値を直した入力**（テストの主張は変えていない）: `test_a_reversible_loop_keeps_the_easier_direction`は
  区間1本の経路にレグ番号を2つ持たせていた（本番で起こらない形）ので、区間2本の経路にした。
  `test_geometry_is_fetched_once_for_every_candidate_together`は候補に本物に無い`traced`を持たせて順序を見ていたので、
  候補のidで順序を見る形にした。
- **偽物にしか無い形**: 見つからなかった（本物で作れない入力でしか成り立たないテストは0件）。保留は無い。
