# T1097. 経路探索エンジンのテストに残るFakeScoreMatrixとBagによる代役（NodeSpatialIndex・SearchMaterials・材料・_LegCostComposer等）を、本物の型で作る形へ置き換える

状態: 未完了（2026-09-25起票）

## 背景

T1094・T1095で同じtest_road_graph_engine.pyの道路グラフの偽物と探索構造の偽物7種を本物の型へ置き換え、本物の型を作り変えたときにテストが落ちるようになった。T1095の担当が同じ性質の代役が残っていると報告した: FakeScoreMatrix（本物はdomain/evaluation.pyのStaticEdgeScoreMatrix。形が既にずれていて、本物はaxis_scoresの2次元配列、偽物は列の辞書を返す）と、Bagによる代役（NodeSpatialIndex——差し替えがBag(node_ids=…)を返し、テストが本物に無いnode_ids属性で渡された引数を確かめているので、置き換えるには差し替えがどの引数で呼ばれたかの記録の仕方から変える。SearchMaterials・材料・_LegCostComposer等）。完了の条件の案はT1095と同じ（本物で作れない入力でしか成り立たないテストはテストを弱めずに要確認として出す・置き換え前後の件数と行とカバレッジと偽物の数を並べる・本物の型を作り変えて検知を確かめる）。規模の根拠: ファイルは1本だが、記録の仕方の作り直しと組み立ての箇所の多さで変更行が200を超える見込み。起票案 kihyoan-engine-test-remaining-stand-ins として2026-09-25承認。
