# T803. 常設ヘッダーのバーを短くする（日の出・日没は「今日」パネルへ）

規模S。
状態: 完了（2026-09-13、ユーザー要望「上のバーもう少し短縮できないか。日の入り、日没は
今日ボタンの中に移動して」）

## 背景

常設ヘッダーのバーが390pxで溢れていた（実測 scrollWidth−clientWidth＝3px）。

置き場の根拠も古くなっていた。バーはアメダス実測、「今日」パネルは外部予報（Open-Meteo）、
という取得元の違いで分けていたが、予報は[T645](T645.md)で気象庁MSMのローカル同期へ移行し、
いまはどちらも気象庁由来で区別が無い（ユーザー指摘）。

## 対応

分ける基準を取得元から**値の性質**へ変えた。バーは走行中に何度も見る瞬間値だけに絞り、
1日1個の値は「今日」パネルへ置く。日の出・日没は後者のため移した。

- `WeatherPanel`: 天気アイコンのチップから日の出/日没を外す（チップは天気アイコンのみ）。
  JST整形のローカル関数も不要になり撤去。
- `TodayOutlook`: 「日の出・日没」の1行を追加（`weather.sunrise`/`sunset`。MSM予報の
  レスポンスにbackendのastral計算結果が乗っている）。時刻の整形は`dynamicWeather.ts:
  formatDynamicFrameHourMinute`を使い、同じJST整形を書き足さない。

## 検証

Playwright（dev実機・390px・ダーク、天候APIはモック）:

| | 変更前 | 変更後 |
|---|---|---|
| バーの幅 | 336px | 292px |
| ヘッダーの溢れ | 3px | 0px |

「今日」パネルに「日の出・日没 05:20〜17:51」が出ることも同じ実行で確認。
`npx vitest run`（WeatherPanel・TodayOutlook）29件 passed。
