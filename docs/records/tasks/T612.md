# T612. 地図上チップの▶パネルを表示専用から操作可能へ（全チップ共通の内訳トグル） 規模S

状態: 完了（2026-09-06）

## 背景

[T610](T610.md)（災害系7種の1チップ統合）の検討中に、7要素が同時表示されると面レイヤー
同士が混色して危険度5段階を読み取れないという問題が判明した。ユーザーから「▶パネルに
個別トグルを置くのを、全地図ボタン（災害や環境に限らず）に共通適用できる？　その整理が
一番きれい」との方針提示があり、災害チップ専用のUIを作らず共通機構を先に用意することに
決定した。

着手前、地図上チップ（`MapOverlayControls`）の▶パネルは**表示専用**で、`page.tsx`の
`UNUSED_LEGEND_FILTER`（一致することのないダミー値）により凡例は描画するが絞り込みは
効かなかった。一方サイドバー（`MapLayersPanel`）は同じ凡例に対する実際の絞り込みを持ち、
`legendFilter.ts`の汎用機構がその実体になっている。この非対称を解消する。

## 規模の見積もり訂正

起票時は規模Lと見積もったが、実際の実装差分は6ファイル・258行（うちテスト122行）の
規模S相当だった。必要な部品が既に揃っていたため:

- `LegendCheckboxList.tsx`（T525で`MapLayersPanel`と`RouteAxisProfile`の重複を統合済み）が
  そのまま流用できた
- 非表示キーの保存先（`hiddenLegendKeysByMode`、localStorage永続化込み）も既存
- `LegendFilterSummaryAxis`は元々`hiddenKeys`を持っており、地図上チップ側が表示に
  使っていなかっただけだった

見積もりを外した原因は、着手前に`LegendCheckboxList`の存在を確認しなかったこと。

## 対応方針・実装内容

- `legendFilter.ts`: `LegendFilterSummaryAxis`へ`axisId?: string`を追加した。**これを持つ
  軸だけがユーザー操作で絞り込める**という契約にし、保存先の識別子を兼ねる。
- `MapOverlayControls.tsx`: `renderLegendDetails`が`axisId`を持つ軸を`LegendCheckboxList`
  で描き、持たない軸は従来の読み取り専用一覧（非表示分を薄く+「非表示」バッジ）のまま
  描く。propsへ`onLegendEntryToggle(axisId, key)`を1本追加した。CSSは既存の
  `.detailList`/`.detailRow`/`.detailRowFallback`/`.detailSwatchDot`をそのまま渡している。
- `page.tsx`: 既存の絞り込み軸（路面の種類・道路の種類・静的属性軸群・ルートの色分け）へ
  `axisId`を付与し、`onLegendEntryToggle`には既存の`toggleHiddenLegendKey`をそのまま
  渡した——サイドバーと地図上チップが同じ関数・同じstateを共有する。ラスタ系
  （降水ナウキャスト・風・災害の危険度凡例）は`axisId`を持たせず読み取り専用のまま。
- 災害チップ: `DISASTER_SOURCE_LEGEND`（7要素）を`axisId="disaster"`の軸として▶パネルの
  先頭へ置いた。keyは`DYNAMIC_WEATHER_RENDERERS`のdisasterグループのソースキーと一致
  させる必要がある。
- `useDynamicWeatherLayers.ts`: `hiddenDisasterSources`を受け取り、`showDisasterSource`が
  ソースごとの`visible`を決める。あわせて3本のフェッチ（キキクル・雷竜巻・落雷）は、
  その系統の要素がすべて非表示なら実行しない。

## 災害チップの「表示する情報」が他の軸と異なる点

`axisId`を持ちながら、反映先が地物のフィルタ式ではなく**レイヤーソースの表示切替**である
点だけが他の軸と違う。UIは同じチェックボックス行で、`page.tsx`が`axisId`に応じて反映先を
振り分ける（凡例カテゴリ→`hiddenLegendKeysByMode`をMapLibreのフィルタ式へ、災害の要素→
同じ保存先の値を`useDynamicWeatherLayers`の`visible`へ）。

## ユーザー判断（2026-09-06）

面レイヤー5種（土砂・大雨・浸水・雷・竜巻）の重なりは、排他（1つだけ選ぶ）ではなく
**複数選べる形にしてユーザーに任せる**。既定は7要素すべて表示で、「何か起きている」ことを
見逃さないことを優先し、混色して読みづらいときはこの▶パネルで絞り込む。
