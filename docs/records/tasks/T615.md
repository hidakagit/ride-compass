# T615. 地図上チップの排他ドメインを廃止し、すべて複数選択可にする＋▶パネルへ一括ON/OFFを追加 規模M

状態: 完了（2026-09-06）

## 背景

[T610](T610.md)で災害チップを排他ドメインの対象外にしたところ、本番実機確認でユーザーから
「災害と降水は重複ONできるけどこれは不整合にならない？」との指摘。降水も災害も面（ラスタ）
であり、「面を重ねると読めなくなるから1つに絞る」という排他ドメイン（T400/T406）の目的から
すれば、災害だけを例外にする理由は無い——防災情報を消したくないという別の価値判断で例外を
作っただけで、仕組みとしては一貫していない。

[T612](T612.md)で▶パネルの内訳トグルが入り、「重なって読めないときにユーザーが自分で絞る
手段」が用意できたため、排他という強い制約自体を廃止して例外を無くす方針をユーザー判断で
決定した。

あわせてユーザー要望「各▶パネル内で一括ON/OFFチェックを省スペースで追加して」に対応する。
サイドバー（`MapLayersPanel`）が持つ「すべて表示/すべて隠す」の一括操作を、地図上チップの
▶パネルにも省スペースな形で置く。

## 対応方針・実装内容

### 排他ドメインの廃止

- `mapLayers.ts`: `MapOverlayExclusiveDomain`型・`MAP_OVERLAY_EXCLUSIVE_DOMAIN`表・
  `mapOverlayExclusiveDomainFor()`を撤去した。`MapOverlayGroup`（道路/環境/スポット）は
  表示上のまとまりだけを表す。
- `page.tsx: handleLayerToggle`: 同一ドメインの他レイヤーをOFFにするループを撤去した。

**軸スタジオ由来のレイヤー（`isAxisStudioLayer`、ramp軸・windAxis・gradientAxis）だけは
1つだけ選べる状態を残す。** これらは同じ道路の同じ位置をそれぞれの評価で塗り分けるため、
重ねると後から描画した色が前の色を完全に覆い、道路グループの線のように並行トラックで
並べて見ることもできない。地図上チップではなくルート設定パネル・レンズから操作する。

道路グループの線同士は`line-offset`による並行トラック
（`MapView.tsx: applyRoadMaterialTrackOffsets`、`ROAD_MATERIAL_TRACK_LAYER_IDS`）で
重ならずに並ぶ——T400が排他を導入したとき、この機構は既にありながら使われない状態に
なっていた。

### ▶パネルの一括ON/OFF

`axisId`を持つ軸の見出し行へチェックボックスを1つ置いた（`renderLegendDetails`）。
狭い▶パネルにサイドバー側の「すべて表示」「すべて隠す」2ボタンを置く余地が無いため、
1つのチェックボックスで両方向を兼ねる:

- 1つ残らず表示中 → チェックが入る → 押すと全部隠す
- 1つでも隠れている → 未チェック → 押すと全部表示に戻す

`Checkbox`（Radix）は`checked`がbooleanのみでindeterminateを表現しないため、2状態で
扱う。ラベルの無い軸（路面など）は「すべて」と表示する。保存先は個別トグルと同じ
`hiddenLegendKeysByMode`で、`onLegendAxisSetHidden`→`setHiddenLegendKeysForAxis`へ繋ぐ。
