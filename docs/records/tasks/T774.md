# T774. ルート結果ヘッダの操作アイコンが小さく、閉じる✕と紛れる 規模S

状態: 完了（2026-09-12。ユーザー実機フィードバック「ルート結果のタイトルにあるアイコンが
小さくてわかりにくい」「特にルートをクリアの×は、パネルを閉じる×と並んでいて視認性が
良くない」から）

## 背景

「ルート結果」ヘッダの操作枠（保存・GPX出力・ルートをクリア）は、隣に並ぶパネルの
閉じる✕（`BottomSheet.module.css: .closeButton`、28px・`--foreground`・枠線なし）より
**小さく（1.6rem＝約25.6px）薄い（`--color-muted`）**。操作のほうが目立たない状態だった。

さらに「ルートをクリア」は丸で囲んだバツ印で、閉じる✕の**すぐ隣に同じ形が2つ並ぶ**。

## 対応

| 変更 | 内容 |
|---|---|
| 大きさ・濃さ | 操作ボタンを2rem・`--foreground`・`--color-border-strong`へ。アイコン自体も18pxへ |
| ルートをクリア | `ClearRoutesIcon`（ゴミ箱）を新設。**バツ印を使わない**——閉じる✕の隣では同じ形が識別できない |
| 未使用の撤去 | 旧`ClearIcon`（丸で囲んだバツ）は使い手が無くなったため削除 |

## 検証結果

- 実装したアイコンを描画して確認（ヘッダ行に保存・GPX・ゴミ箱・閉じる✕を並べ、
  ゴミ箱が✕と別物として読めること）。
- 「効いている」の確認: ゴミ箱をバツ入りのアイコンへ戻すと`page.test.tsx`が落ちる
  （テストはバツ印のパスが**出ないこと**とゴミ箱のパスが**出ること**の両方を見る）。
- `npx vitest run` → 1,272 passed。`tsc --noEmit`・`eslint` → 指摘なし。
