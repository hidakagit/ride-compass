# T779. 生成結果を「素材」、編集の結果を「採用ルート」として分ける 規模M〜L

状態: 未完了

設計中（2026-09-12起票、ユーザー構想「最初にルート生成してできたものが素材。その
素材をそのまま採用か、合成して目指すルートを作るようなUIがいい。最短経路は採用ルートの
デフォルト1番目」）

## 背景

[T769](T769.md)で「見る（ルート結果）」と「作る（ルート編集）」を分けたが、作った結果の
居場所は[T621](T621.md)の判断のまま**候補一覧への差し込み**になっている。そのため
「どれがどれを編集した結果か」「何をどう変えたか」が残らず、編集前後を見比べられない。

## 台帳にあった補足

- 素材から採用ルートを組み立てるUIへ。編集前後を見比べられるようにする

## 保留（ユーザー判断）: ルート編集で作ったルートを、生成した候補とは別の欄に置くか（2026-09-23 依頼）

利用者への約束: 自分で手を入れたルートが、どの候補から何を変えて作ったものか分かり、元と見比べられること。

いま: 「ルート結果」で候補を1本選び、区間ごとに別の候補の道へ差し替えて「新しいルートを作る」と、できたルートは
生成した候補の一覧へ1本として足される。3回編集すると、一覧に生成した候補と編集結果が混ざって並び、どれが元で
どれを直したものかは一覧から分からない。
起きない場面: 編集をしない（生成した候補から選んで走るだけ）利用者には何も変わらない。

1. **（推奨）生成した候補（素材）と、編集で作ったルート（採用ルート）を別の欄に分ける。** 採用ルートには元にした
   候補と変えた区間を付けて残し、元と並べて見比べられる。最短経路は採用ルートの最初の1本として置く（起票時の構想）。
   画面は実装の前に変更前後のモックで詰める。
2. **今のまま候補一覧へ差し込む（見送り）。** 画面は変わらない。何をどう変えたかは残らない。

保留した場合: [T808](T808.md)の残り（段階3）はこの判断に合流しているため、どちらも未完了のまま残る。
保存（[T854](T854.md)）は生成の条件だけを保存すると決まっており、この判断とは独立に進められる。
