# T1019. 地点マスタの読み飛ばしが黙っている

状態: 未完了（2026-09-23起票）

## 背景

[T1012](T1012.md)で`wbgt_client.py`のテストを起こし直したとき、
`_parse_point_master`が配布CSVの行を2通りの理由で読み飛ばすのに、どちらもログを
出していないことが分かった。

- 終了日の列が無い（列数不足）
- 緯度・経度が数値として読めない

## 何が起きるか

環境省が配る地点マスタの列構成が変わると、読める行だけが残って地点が静かに減る。
近傍検索は残った地点から選ぶため、**利用者の現在地から遠い地点の暑さ指数が、
何事もないように表示される**。全滅（0件）なら気づけるが、一部が落ちる形では
表示も`/api/debug/stats`も正常に見える。

`docs/conventions/logging.md`は「候補0件はWARNING以上で常時出す」と定めているが、
「候補が減った」は対象になっていない。

## やること

読み飛ばした行数を、取得1回につき1行のサマリとして出す（行ごとに出さない——
列構成が変わると全行に出る）。レベルは、1行でも飛ばしたらWARNING。

同じ形の「黙って減る」パーサが他にないかを、`app/infrastructure/`の
`continue`・`except (...): continue`で機械的に列挙してから直す
（CLAUDE.md「範囲は性質から導く」）。

## 完了の条件

1. 読み飛ばしが起きたとき、飛ばした行数と総行数がログに出る
2. わざと列を削ったCSVを1件通して、実際にWARNINGが出ることを見た
3. 同じ性質の箇所の列挙結果（母集団の定義と件数）がコミットメッセージにある
