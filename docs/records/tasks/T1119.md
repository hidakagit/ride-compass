# T1119. 地図のチップの凡例の色見本から地色の台をやめ、点は大きく・線は地図と同じ太さで見せる

状態: 完了（2026-09-25起票・2026-09-26完了）

## 背景

ユーザー報告（2026-09-26、スマホ・ダークモード）: T1102で入れた凡例の色見本の地色の台（22px幅の明るい台に8pxの色の点）が、暗いパネルの上でかえって見にくい（台の白が目立ち、明るい色は白に溶ける）。ユーザー決定: 台をやめる。点は大きめに、線は太線・細線（T1110で道路の種類の線に付けた太さ）も見本で表す。規模の根拠: MapOverlayControls.tsxとそのテスト・設計書で、変わるファイルは2〜3（③7以下）。

## 実施（2026-09-26、T1112のクラウドのセッション）

- チップの▶の凡例（`MapOverlayControls.tsx: renderSwatch`）から地色の台（`--swatch-ground`）を外し、見本をパネルへ直に置いた。
  点の見本は8px→12px、線の見本は長さ20px・高さは地図と同じ太さ（凡例の行の`lineWidthPx`、道路の種類なら3〜6px）。
  大きさで意味を示す行（事故の重大度）は今までどおり地図の点と同じ直径。見本の枠は幅24pxにそろえ、ラベルの位置をそろえた。
- 台が無くなったぶん、濃い色（道路の種類の幹線の紫等）はダークモードのパネルでは地図より沈んで見える。ユーザーの決定
  （台をやめる）どおりで、設計書へ暗黙の前提として書いた。
- 設計書static-map-layers.mdの「地色の台に載せる」を直した。T1110で`line`を`lineWidthPx`へ置き換えたときに同じ段落の
  `line`の記述が残っていたので、ここで直した。地色（`basemap_ground`）はfrontendから参照されなくなったが、backendの
  分類色の明度の上限とそのテストが基準に使うので残し、コメントから凡例の台の話を消した。
