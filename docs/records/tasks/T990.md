状態: 未完了

未着手（2026-09-21起票、[T979](T979.md)の完了確認で移設先を走査して判明）。

## 背景

`docs/modules/`・`docs/architecture/`が名指しする識別子のうち**52件が実装に存在しない**。
最大は`docs/modules/backend/routing-engine.md`の33件で、996行のうち594〜930行が、
置き換えられる前の設計を現在形で説明している（`LoopRoutingEngine`・
`get_or_build_graph_with_attributes`・`_ensure_tiles_cached`・`RawOsmRepository`など）。

T979の移設で入ったものではない（同ファイルへT979が足したのは11行）。以前からあり、
`dead_identifier_refs`が参考表示で出し続けていたものが、T986でその検知器ごと消えて
引き取り手がいなくなった。

## 対応方針

母集団は手で持たず、下のスクリプトで導出する（許可リストを持たない。出た件を1件ずつ
実装と突き合わせて判断する）。

```python
# 対象: docs/modules/**/*.md・docs/architecture/**/*.md
# 判定: バッククォートで囲まれた識別子（`_`を含むか CamelCase）のうち、
#        backend/app・backend/scripts・backend/tests・backend/migrations・
#        frontend/src・frontend/e2e・scripts 配下の実ファイル全文に1度も現れないもの
```

1件ごとに、①実装が改名されただけなら新しい名前へ直す、②その仕組み自体が無くなって
いるなら節ごと落とす、③説明として残す価値があるなら識別子を外して挙動の記述にする。

  説明していること）。
