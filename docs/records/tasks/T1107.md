# T1107. ルートの風の表示を区間の通過時刻の風にそろえ、区間の詳細に使った風（予報の地点・時刻・風向風速）を出す

状態: 未完了（2026-09-25起票）

## 背景

ユーザー質問（2026-09-25）: 風はルート途中ではそこまで走った時点の、その地点の風を使っているか。それが分かるようにしたい。調べた事実: 探索は往路・復路ごとに1時間刻み（最大4本、backend/app/services/road_graph_engine.py の TIME_BIN_HOURS・MAX_TIME_BINS）で経過時間の風を引くが、区間の表示値（_build_segment_details が読む leg.axis_arrays・material_arrays）はレグの中間の時刻の代表ビン（_representative_bin）1本だけで、区間の到達予想の時刻の風ではない（目的地ルートの復路だけは passage_hours で区間ごと）。docs/modules/backend/routing-engine.md は表示と探索コストの一致を約束しており食い違う。承認時の決定: ①表示を区間ごとの通過時刻の風にそろえる（不具合の修正）②区間の詳細に、使った風を出す（例: 出発地点の予報・12時台・東 3.2m/s）。規模の根拠: backendの区間の組み立てとAPIモデル・生成物・frontendの区間の詳細とそれぞれのテストで8〜20ファイル。
