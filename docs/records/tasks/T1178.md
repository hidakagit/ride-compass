# T1178. 汎用の形のアイコン（警告・風・雨・時計・コピー・メニュー等の23個）を、自前の SVG から lucide-react へ置き換える

状態: 未完了（2026-09-27起票）

## 背景

起票案 proposal-std-icons-lucide（2026-09-27承認。標準の道具の棚卸しから）。規模S（根拠: 同じ名前で書き出し直せば使う側は変わらないので、変わるのは icons.tsx・package.json の2本の見込み）

■ 背景（画面の見た目に関わる）
components/ui/icons/icons.tsx（711行）はアイコン51個を自前の SVG で持つ。自前にした理由はコメントの「外部のアイコンライブラリは使わず、同じ線画の様式にそろえる」だけで、lucide-react も同じ線画（線の色は文字色・丸い端・線の太さを指定できる）なので、理由として弱くなっている。軸・レイヤー・乗り換えなど、このアプリ固有の形の28個は自前のまま残す。

■ やること
汎用の23個（約285行）を lucide-react の同じ意味の形へ置き換え、線の太さを今にそろえる。見た目が変わるので、着手したら置き換え前と後の画面写真（地図の上のボタン類・警報バッジ・軸のアイコンの並び）をダッシュボードに置き、確認を取ってから確定する。混ぜたときにそろって見えなければ置き換えず、理由をコメントへ具体的に書く。

該当する未完了のタスクは無い（アイコンを扱った T251 は完了済み）。
