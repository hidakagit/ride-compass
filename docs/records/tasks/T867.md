# T867. デバッグログを1押しでコピーできるようにする

状態: 完了（2026-09-15）
規模: S

## 背景

デバッグログを人へ渡すとき、行ごとのdivを1件ずつドラッグ選択するしかなかった
（ユーザー要望「デバッグログモードも簡単にコピペできるようにして。コピペボタンは簡易な
アイコンにして」）。backendの直近ログのパネルには同じ用途のボタンが既にあったが、その実装が
そのパネルの中にあり、他から使えなかった。

## 対応

- `hooks/useCopyToClipboard.ts`（新規）: 書き込みと結果表示（コピー済み・失敗）をまとめる。
  `BackendLogsPanel`にあった実装をここへ移し、両方が同じものを使う（骨格を写さない）。
  Clipboard APIは[SecureContext]のため`navigator.clipboard`自体がundefinedになりうる。
  `.catch()`はPromiseの拒否しか捕まえないので、プロパティアクセスの同期TypeErrorをtryで
  受けないとボタンが無反応のままになる。
- `DebugConsole`のヘッダーへコピーのアイコンボタンを置く。渡すのは**表示中の行だけ**
  ——絞り込みを無視して全件にすると、絞って見つけた数行を渡したいときに関係ない行まで混ざる。
  形は画面の見た目と同じ`時刻 [カテゴリ] 本文 詳細`。
- コピーのボタンは両方ともアイコンにした（`CopyIcon`を`icons.tsx`へ追加）。名前は
  `aria-label`と`title`が持ち、押した後は「コピーしました」へ変わる。

## 検証

- `DebugConsole.test.tsx`へ2件追加: 行の形そのままで渡すこと、絞り込み中は見えている行だけを
  渡すこと。`BackendLogsPanel.test.tsx`の既存のコピー検査はラベル変更に追従。
- `npx vitest run`（全件）・`tsc --noEmit`・`eslint`・`prettier`。
