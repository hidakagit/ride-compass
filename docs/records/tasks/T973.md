# T973. 非商用データ（国土数値情報 N10/N12）に依存する機能を削除する 規模M

状態: 未完了

未着手（2026-09-20起票）。

## 背景

国土数値情報の**緊急輸送道路（N10）**・**重要物流道路（N12）**は、提供元の公式ページに
「このデータの使用許諾条件 **非商用**」と明記されている（[N10](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N10-v2_0.html)・
[N12](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N12-2021.html)、2026-09-20確認）。

RideCompassは将来商用になりうる前提で扱う（ユーザー方針、2026-09-20）。そのため両データと
それに依存する機能を削除する。取り込んでから今日まで、採用時・評価軸への組み込み時・以後の
どの段階でも許諾条件が確認されていなかった。再発防止は[T975](T975.md)。

## 段取り

1. **公開軸の扱いを先に決める**。`designation`は`material_catalog.py`の`MaterialSpec`
   （`tile_property`付き）であり、`CAR_STRESS_DESIGNATION_KINDS`経由でcar_stress軸の加点に
   入っている。軸定義は`axis_definitions`テーブルの行データで、CLAUDE.mdの規定により
   **`axis_admin`のAPI経由でしか変更しない**（migrationへ行データを書かない）。材料を消す前に
   軸側の参照を外す必要があり、順序を逆にすると`refresh_axis_definitions`のfail-fastで
   backendが起動しなくなる（[T396](T396.md)と同型）。
2. 取込を止める: `source_adapters/ksj_designation.py`・`_ksj_zip.py`・
   `source_adapters/__init__.py`の登録行・`source_profile.yaml`のエントリ
3. 派生を止める: `derive_way_materials.py`の`derive_designations`、`way_materials`の
   `designation_emergency_transport` / `designation_critical_logistics`列
4. 読み出しを止める: `road_graph_repository.py`・`material_sql.py`・`material_catalog.py`・
   `registry.py` / `registry_defaults.py`
5. frontendのレイヤー・フィルタ・凡例
6. `source_features`の`designation`パーティションを落とす（本番・開発DBの両方）
7. OpenAPI・生成物の再生成（`export_openapi.py` → `npm run generate:api`、
   `material-catalog.json`・`axis-catalog.json`）
8. テストの削除（新しい動作を検証しないものは移植せず消す）

## 影響

car_stress軸から指定路線の加点が消えるため、**軸の較正がずれる**。ずれの大きさを削除前後で
実測し（同一bbox・同一ルート条件での軸スコア分布の比較）、較正の再調整が要るかをこのエントリへ
記録すること。「消したら軸が変わった」で終わらせない。
