# T498: 重み配分バーへ凡例ポップオーバー・ドラッグ中のライブ%表示を追加

状態: 完了（2026-08-31）
## 背景

T497で軸の凡例チップ（色ドット+ラベル）を導入したが、チップが折り返して並ぶため
色と軸の対応が一覧しにくい。またドラッグ中の帯グラフの割合は、ホバー限定のブラウザ
native title属性でしか確認できず、モバイルでは事実上見えなかった。ユーザーから
「情報アイコンを押すと、そのなかに凡例出してほしい」「バーをドラッグ中に数字が出て
ほしい」との要望を受けた。AskUserQuestionで2点とも方向性を確認した。

## 対応方針

- 「重み配分」見出し脇に新規の情報アイコンを追加し、押すと全軸ぶんの凡例
  （色ドット+ラベル+現在の%）を一覧できるポップオーバーを出す。
- 帯グラフの境界ドラッグ中だけ、その境界の両隣2軸の%をハンドル直上にフロート
  バッジで表示する。ドラッグ終了で消える。

## 実装

- `frontend/src/components/RouteSettingsPanel/RouteSettingsPanel.tsx`:
  - `stackBarWrap`内に`stackBarHeader`（見出し+情報アイコン）を新設。情報アイコンは
    Radix Popoverのトリガーで、`Popover.Content`内に`catalog.axes`を走査した凡例
    リスト（色ドット・ラベル・`Math.round(pct)`%）を表示する。
  - `draggingBoundary`state（`{axisIdA, axisIdB} | null`）を新設。`startBoundaryDrag`で
    セットし、window pointerup/cancelでクリアする。境界ハンドルの描画時、この状態と
    一致するハンドルにだけ`stackBarDragBadge`（両隣の%をフロート表示）を出す。
    実際のパーセント値は`routePreference`から毎回計算する（ドラッグ中は
    `handlePairWeightChange`経由で毎pointermoveごとに再レンダーされるため常に最新）。
- `frontend/src/components/RouteSettingsPanel/RouteSettingsPanel.module.css`:
  `.stackBarHeader`・`.stackBarLegendTrigger`（見出し脇の単独アイコンボタン、凡例
  チップ内の`.legendInfoButton`と違いborder-leftを持たない）・`.stackBarLegendList`/
  `.stackBarLegendItem`/`.stackBarLegendLabel`/`.stackBarLegendValue`・
  `.stackBarDragBadge`を追加。

## 検証結果

- `npx vitest run src/components/RouteSettingsPanel/ --pool=threads`: 13件全て成功
  （既存テストへの影響なし、新規テストは追加していない——凡例ポップオーバー・
  ドラッグバッジとも既存のPopover/ドラッグ機構の表示内容追加のみで、新しい分岐条件
  ロジックは無いため）。
- `npx tsc --noEmit`・`npx eslint src/components/RouteSettingsPanel/`: エラーなし。
- Browserペインで実機確認: デスクトップ・モバイル(375x812、BottomSheet展開中)いずれも
  情報アイコンを押すと全軸の色ドット+ラベル+%が一覧表示されること、境界を
  ポインタドラッグ中だけハンドル上に両隣の%（例: 「41% / 4%」）がフロート表示され、
  ドラッグ終了で消えることを確認した。凡例ポップオーバーを開いたままドラッグすると、
  ポップオーバー内の数値もリアルタイムに更新されることも確認した。
