# T891. 検知器の母集団を是正する（コメント除外・記法の絞り込み撤去・リンクのパス解決）

規模M。
状態: 完了（2026-09-16）

## 背景

`review_checks.py docs`のフル実行は「違反なし」を返すが、その0件が3つの理由で信用できない。

1. **実在判定corpusがコメント込み**。撤去済みの名前がコメントに1つでも残れば「実在する」と
   判定される。実測: `find_undeclared_dead_refs`（architecture.md）は0件だが、corpusから
   コメントを除くと12件（`docs/modules/*.md`も0件→19件）。同じファイル内の
   `find_source_comment_dead_identifier_refs`は既にコメント除外corpusを使っており、
   doc側だけがそれを使っていない。
2. **記法での絞り込み**。`removed_axis_mentions`は`{a for a in mentioned - live if "_" in a}`で
   アンダースコアを含まないidを落とす。今回撤去した`openness`・`curvature`が両方これに当たる。
   死んだリンク検知はリンクを解決せず名前一致だけを見るため、解決不能なリンク83本を見逃す。
   コメントの死んだ識別子検知はバッククォート付きの綴りしか見ない。
3. 撤去済み軸の**日本語ラベル**が母集団に一切入らない（ラベルはスナップショット履歴から導ける）。

統合レビュー第10回のP0 F-2(1)(2)（[2026-09-16_all.md](../../../.claude/commands/review/history/2026-09-16_all.md)）。前回の
[T871](T871.md)が検知器本体の母集団を導出へ変えたのに対し、今回は**検知器を検査する側**と
**記法での絞り込み**に同じ型が残っていた。

## 実装メモ

### (a) 実在判定corpusからコメントを外す

`source_corpus`が`split_source_comments`のコード側だけを返すようにした（コメント側の
検知器は最初からそうしており、doc側だけが外れていた）。

**外した結果を見て、corpus側の不足が3つ分かった**——コメントが支えを外れたことで、
「実装に存在するのに本文へ綴りが無い」ものまで違反になった。真の違反と区別するため、
corpusを次の3つで補った。

- **モジュール名**（`export_openapi`等）。ファイル名にしか現れない。
- **テストに定義された部品**（`FakeRoadGraphRepository`・個々のテスト関数名）。テストケース
  本体は母集団外のままだが、`def`/`class`/`function`で**定義している**綴りだけは実在として
  扱う。変数（`const`/`let`）は含めない——含めると、撤去された本番の定数をテストが同名の
  ローカル変数として持っているだけで実在になり、実測で1件を見逃した。
- **外部由来の語彙**（`APScheduler`・`Geofabrik`・`NoReferencedTableError`等）。これは
  corpusではなく`EXTERNAL_VOCABULARY`の問題で、コメント側の検知器にしか効いていなかった。
  名指しした側がdocsでもコメントでも判断は同じなので、共通の`find_dead_identifier_refs`へ
  移した。

### (b) 記法での絞り込みをやめる

`removed_axis_ids`の`if "_" in a`を外したところ、`signed`（テストのフィクスチャ軸id）が
`MapView.tsx`の「真のsigned distance fieldではなく」という説明を誤検知した。
綴りの形で分けるのではなく、**実際に公開されていた軸か**（スナップショットのgit履歴に
あるか）で分ける形にした——履歴にあるidは綴りの形に関わらず対象、ソースの`axis_id="…"`に
しか現れない綴りだけ従来どおり複合語に限る。

あわせて**表示ラベル**（日本語）も母集団へ入れた（`removed_axis_labels`）。idを消しても
ラベルは残りやすく、読み手が「現行の軸」と受け取るのはラベルの方である。

### (c) リンクをパス解決で検査する

`check_dead_doc_links`が、リンク記法の行き先を実際に解決するようにした。名前だけの照合では
`docs/records/tasks/T889.md`が実在する限り`../tasks/T889.md`（階層が1つ足りない）も通る。
記録として残す文書（`history/`・`task/history/`・改善計画アーカイブ）は対象外、
書き方の雛形（`Txxx`）は除外する。
