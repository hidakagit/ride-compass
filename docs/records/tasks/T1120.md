# T1120. 道の線の「不明」「その他」を、地図の上で見える濃さで描く（不透明度0.15→0.6）

状態: 完了（2026-09-25起票・2026-09-26完了）

## 背景

ユーザー報告（2026-09-26、スマホ、路面の線）: 路面の線が無い道があり、「不明」にも見えない。原因: 路面タイルには取り込んだ道がすべて載り、値の無い道は「不明」（灰の破線）・分類の外は「その他」（灰の実線）として描かれているが、不透明度が0.15（map_display.py: ROAD_UNKNOWN_OPACITY）で、基礎地図の地色#f8f4f0に対する合成色#eae8e6のコントラスト比は1.12しかなく見えない（本番データでの確認は未、線の無い道を押して「路面」の行が無ければこの見立て）。ユーザー決定: 不明・その他とも不透明度0.6前後（コントラスト比約1.5）にし、分類のある道（0.8）より薄いまま見えるようにする。規模の根拠: map_display.py・生成物・backendの配色テスト・設計書で、変わるファイルは3（③7以下）。

## 実施（2026-09-26、T1112のクラウドのセッション）

- `ROAD_UNKNOWN_OPACITY`を0.15→0.6。灰（`no_data` #9ca3af）を地色#f8f4f0へ0.6で重ねたコントラスト比は約1.6（0.15では1.12、
  0.5で1.48、0.8で1.92。WCAG 2.xの式で計算）。道の線の「不明」「その他」と、評価軸の線の「データなし」が同じ値を使うので、
  どちらも濃くなる（どれも同じ「値が無い・対象外」の意味）。
- 評価軸の下敷き（材料の線と一緒に出すときの太い帯）が同じ値を借りていたので、`ROAD_UNDERLAY_OPACITY`（0.15のまま）へ分けた。
  下敷きは材料の線より手前の段（`lensLine`）に重なるため、0.6にすると材料の線の色を隠す。
- backendのテストへ「値が無い道の灰の線が地色に対してコントラスト比1.5以上、分類のある道より薄い」を足した。設計書の
  「不透明度だけ大きく下げる」を、見える濃さに留める形へ直した。
- 凡例の見本には不透明度を掛けていない（分類のある行の見本も地図の0.8を掛けずに描いており、それと揃えた）。
