# T1120. 道の線の「不明」「その他」を、地図の上で見える濃さで描く（不透明度0.15→0.6）

状態: 未完了（2026-09-25起票）

## 背景

ユーザー報告（2026-09-26、スマホ、路面の線）: 路面の線が無い道があり、「不明」にも見えない。原因: 路面タイルには取り込んだ道がすべて載り、値の無い道は「不明」（灰の破線）・分類の外は「その他」（灰の実線）として描かれているが、不透明度が0.15（map_display.py: ROAD_UNKNOWN_OPACITY）で、基礎地図の地色#f8f4f0に対する合成色#eae8e6のコントラスト比は1.12しかなく見えない（本番データでの確認は未、線の無い道を押して「路面」の行が無ければこの見立て）。ユーザー決定: 不明・その他とも不透明度0.6前後（コントラスト比約1.5）にし、分類のある道（0.8）より薄いまま見えるようにする。規模の根拠: map_display.py・生成物・backendの配色テスト・設計書で、変わるファイルは3（③7以下）。
