# T806. 地点の印を地図のピンと同じ図形にし、候補数は消さず押せない状態で残す

規模S。
状態: 完了（2026-09-13、採番はT805で確保しようとしたが並行セッションが先に使ったため
T806へ振り直した。ユーザー要望「ルート生成パネルの中の、出発地、経由地、目的地
アイコンと、地図上にプロットできるアイコンをデザイン一致させてほしい」「押せない状態で
残す——候補数をdisabledで表示するまででok。近い将来拡張すると思うので」）

## 背景

[T804](T804.md)で地図のピンを揃えたが、パネルの行の印とは別々に書いていたため一致して
いなかった（出発地: 地図は白バッジ＋十字／行は赤い丸、経由地: 地図は訪問順の番号／行は
ただの丸）。同じものを2箇所で描いている限り、片方だけ直せばまたずれる。

候補数は経由地を置くと消えていた。backendが常に1件へ固定する（`route_generator.py:
generate_via_waypoints`）ため操作しても無駄なのは事実だが、消えると壊れて見える。

## 対応

- 印の中身（HTML文字列）と背景色を`components/Map/pinMarks.ts`へ1つだけ置き、地図のピンと
  パネルの行が同じものを使う。地図側はMapLibreのMarkerへ渡す生のDOMを組み立てるため
  React要素を使えず、両方から使える形がHTML文字列しかない（差し込む値はこのモジュールの
  定数と経由地の番号だけで、外部の入力は入らない）。
- 出発地の印の色（位置が未取得なら灰色）も行へ渡し、同じ状態を同じ色で示す。
- 候補数は消さず、押せない状態（`data-disabled`＋ボタンのdisabled、値は「1件」）で残す。
  理由は隣の(i)の奥（設計原則「説明文をベタ書きしない」）。

## 検証

Playwright（e2eのモック環境、390px）で行の印と地図のピンのDOMを突き合わせ:

- 出発地: どちらも同じ十字のSVG（色も一致。位置未取得のときは両方#9ca3af）、背景は白
- 経由地: 背景はどちらも`rgb(37, 99, 235)`。行は件数、地図は訪問順の番号
- 目的地: どちらも「⚑」、背景は`rgb(5, 150, 105)`
- 経由地があるとき候補数の±がdisabled、理由の(i)が出る
