# T1111. backendのデプロイは、入れ替えたコンテナが /health に応答するまで待ち、応答しなければ失敗として止まる

状態: 未完了（2026-09-25起票）

## 背景

T1059で、本番と同じDockerfile・docker runの引数でも、起動が止まる状態（ワーカー2で作り直しが続く・ワーカー1で再起動の繰り返し）のままコンテナはUpでデプロイのジョブは成功扱いになることを確かめた。deploy-backend.ymlは docker run -d で終わり起動の成否を見ていない。docker run -d のあと /health が200を返すまで待ち、上限までに返らなければ docker logs の末尾を出してジョブを失敗させる。待つ上限は本番のログ（起動の開始と最初の応答の時刻）から決める。起票案 proposal-deploy-health-wait（担当 D-workers、2026-09-25 承認）
