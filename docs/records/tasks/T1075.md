# T1075. 旧car_stress一族に代わる走りにくさの軸を、指定路線の材料なしで作り直す

状態: 未完了（2026-09-23起票）

## 背景

T973で非商用データ（国土数値情報N10/N12）を撤去した際、それを加点に使っていたcar_stress一族6軸は軸ごと本番から削除された（c1e7b743c）。ユーザー決定（2026-09-23、T1074）: 作り直す。別タスクで行う。方針: 残る材料（道路種別・車線数・速度規制・交通量等。一覧はmaterial_catalog.pyの登録から導く）で幹線・車の多さによる走りにくさの軸を組み、axis_admin API（軸スタジオ）で追加する。材料の選定と較正の根拠をこの記録に書き、公開する前にユーザーへ見せる（公開はユーザーの確認後）。docs/architecture/design-principles.mdと評価軸のdocs/modules/*.mdを着手前に読む。完了条件: 軸が本番に公開され軸スタジオとGET /api/axis-catalogで見えること、指定路線系の材料を参照しないこと、較正の根拠（どの区間でどの値になるかの抜き取り）が記録にあること。
