# T1165. 司令塔の登録（board claim）が、引用符を含むコマンドから呼ぶと黙って失敗し、定期確認が走らない

状態: 未完了（2026-09-26起票）

## 背景

2026-09-26の第3回で、司令塔が `cd "<本体のパス>" && git fetch ... && python scripts/orchestrate.py board claim; ...` の1行で登録したところ、coordinator_session は前の司令塔（09-25 22:55）のまま変わらず、next_check も04:55のままで、約1時間半、道具を使うたびの定期確認が一度も走らなかった（司令塔が気づいたのは18:35、単独の `python scripts/orchestrate.py board claim` で登録し直して直った）。原因は hook.sh の orch_string_value が JSON の値の中の `\"`（エスケープした引用符）を値の終わりとみなすため、tool_input.command が `cd \` で切れ、`board claim` の語に届かないこと。登録に失敗しても `board claim` は「記録する」と出力するだけで、失敗を知らせない。直す方向: 引用符を含むコマンドでも登録できる（エスケープを読み飛ばす等）、登録できたかを `board claim` 自身か直後の確認が確かめて、できていなければ失敗として出す。わざと引用符付きのコマンドで呼んで登録されること・登録されないときに失敗が出ることを確かめてから閉じる。第3回の改善（派生元 T1162）。
