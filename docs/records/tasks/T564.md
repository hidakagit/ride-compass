[T570](T570.md)（着手中、コメント方針の機械的強制と合わせてCI組み込みを行う想定）と

T561・T563の完了後に着手）

## 背景

T560で導入した`python scripts/review_checks.py docs`（全件監査）は、新規ファイルだけでなく
既存の実装ファイルについても「ファイル名がdocs/modules/*.mdのどこにも出現しない」ものを
18件検出した。pre-commit（`--staged`）は新規ファイルしか止めないため、既存分は放置される。
CLAUDE.md「完了扱い前の機械的チェック」4（新規ファイルの記載）が導入される前に作られた
ファイルが大半。

| 分類 | ファイル |
|---|---|
| 汎用UI部品（特定モジュールの責務ではない） | `components/ui/Button/Button.tsx`・`ui/Card/Card.tsx`・`ui/Checkbox/Checkbox.tsx`・`ui/Dialog/Dialog.tsx`・`ui/Input/Input.tsx`・`BottomSheet/BottomSheet.tsx`・`Disclosure/Disclosure.tsx`・`ErrorText/ErrorText.tsx`・`WarningBadge/WarningBadge.tsx` |
| 機能部品（責務を持つモジュールがあるはず） | `WeatherPanel/WeatherPanel.tsx`・`TodayOutlook/TodayOutlook.tsx`・`DynamicLayerTimeSlider/DynamicLayerTimeSlider.tsx`・`types/route.ts`・`types/experimentSlot.ts` |
| admin API routes（軸スタジオ・開発者ツール） | `app/admin/api/axis-definitions/route.ts`・`[axisId]/route.ts`・`[axisId]/unpublish/route.ts`・`app/admin/api/debug/logs/route.ts`（後者はT563で記載） |

## 対応方針

1. **汎用UI部品**: `docs/modules/README.md`索引のどのモジュールにも属さないため、
   (a) `page-composition.md`へ「共通UI部品」表を1つ設けて1行ずつ列挙する、または
   (b) スクリプト側に「記載対象外ディレクトリ」（`frontend/src/components/ui/`等）を
   持たせて検査から外す、のどちらかをユーザーと決める。既定案は(a)（設計書側で
   「どこにも書かれていないファイルは無い」状態を保つ方が、除外リストの二重管理より単純）。
2. **機能部品・admin API routes**: `docs/modules/README.md`索引の「内容」列を根拠に責務が
   一致するモジュール（`dynamic-weather-layers.md`・`route-settings-and-results.md`・
   `axis-studio.md`（frontend）・`developer-research-tools.md`）の対象ファイル表へ追記する。
3. **CIへの組み込み**: 全件監査が0件になった時点で、`.github/workflows/`へ
   `docs-consistency.yml`（`push`/`pull_request`、paths: `docs/**`・`backend/app/**`・
   `frontend/src/**`・`.claude/commands/review/**`・`scripts/review_checks.py`。python標準
   ライブラリのみなので依存インストール不要、数秒で終わる）を追加し
   `python scripts/review_checks.py docs`を実行する。`ci.yml`はdocs/**をpaths-ignoreして
   いるため別ワークフローにする（backend/frontendジョブをdocsのみの変更で起動しないため）。

## 完了条件

- CIワークフローが追加され、masterへのpushで実行されることを1回確認する。
- 汎用UI部品の扱い（上記1）の決定をdocs/modules/README.md「記載粒度」節または索引へ1文で残す。

## 実装（2026-09-03）

- **対応方針1（汎用UI部品）**: 既定案(a)を採用。`ErrorText.tsx`・`BottomSheet.tsx`・
  `Disclosure.tsx`を`page-composition.md`の対象ファイル表へ「特定モジュールの責務ではない
  共通部品」として追加、既存の`components/ui`行（Button/Card/Checkbox/Dialog/Input）へ
  `.tsx`拡張子を補完した（拡張子無しの記載だとreview_checks.pyの完全一致チェックを
  すり抜けたまま実質未検出になっていたため）。決定を`docs/modules/README.md`索引の
  「ページ全体構成・状態管理」行へ1文で残した。
- **対応方針2（機能部品・admin API routes）**: `WeatherPanel.tsx`・`weatherCode.ts`・
  `TodayOutlook.tsx`・`WarningBadge.tsx`・`DynamicLayerTimeSlider.tsx`を
  `dynamic-weather-layers.md`（既存行はディレクトリ名のみでファイル名が無く同じく
  検出をすり抜けていた）、`types/experimentSlot.ts`を`route-settings-and-results.md`
  （`ComparisonPanel.tsx`と同じ行、型の実消費者）、`axis-definitions`配下の3つの

  `axis-studio.md`（`axisAdminApi.ts`が叩くproxy route handler）へそれぞれ追記した。

  `route.ts`ファイル群と衝突しうるgeneric basename）だったため`types/route.ts`へ訂正した。
- **対応方針3（CI組み込み）は見送り**: [T570](T570.md)（着手中）が「コメント方針の機械的
  強制」の一環として`scripts/review_checks.py`のCI組み込み・pre-commitフック整備を
  スコープに含んでおり、本タスクで同時に`.github/workflows/docs-consistency.yml`等を
  追加すると重複ワークフロー・競合editの危険があるため、CI組み込みはT570へ委ねる。
- **検証**: `python scripts/review_checks.py docs`の「実装ファイルのdocs/modules記載漏れ」
  が18件（T563完了直後の17件）→0件。記載粒度違反・死んだ参照とも0件のまま変化なし。
  docsのみの変更のためbackend/frontendのテストスイート再実行は行っていない
  （コード変更なし）。
