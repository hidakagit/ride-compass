# T1039. applyMapSceneのisSameValueがGeoJSONを深く比較している

状態: 完了

## 判断: 見送り（2026-09-23・周期レビュー第12回、ユーザー承認済み）

## 背景

シーンを地図へ当てるとき、変わった値だけを`setData`/`setTiles`するための同値判定が
GeoJSONのペイロード全体（ルートの座標列・風のグリッド）を深く比較している。

## 見送りの理由

適用が走るのはシーンの入力が変わったときだけで、毎フレームではない。**負荷は未計測**で、
測らずに「重い」と主張すると根拠の無い数字になる（CLAUDE.md「実測を伴わない最適化は
premature として指摘対象」の裏返しで、実測を伴わない「重い」も同じ）。

なお、この深い比較は**目的があって置かれている**——`setTiles`の呼び出しが参照の同一性
だけで判定されていた頃に、毎回新しい参照になって無駄な再取得が起きた経験がある。
浅い比較へ戻すと、その問題が再発する。

## 再評価の条件

**地図の操作に体感の遅さが報告されたとき。** そのときは、利用者が通る経路の単位で
測る（同値判定の関数だけを測って結論にしない）。具体的には、ルート生成後の描画と
レンズ切り替えの所要時間を実機で測り、そのうち同値判定が占める割合を出す。
