# T1084. 軸スタジオの段階プレビューの「N段階になります」が、地図で落ちる値も段として数えている

状態: 未完了（2026-09-23起票）

## 背景

T957（ユーザー決定: しきい値の入力欄の横に地図では効かない値を名指しする。26f55215）の担当が挙げた範囲外の不一致1（ユーザー決定 2026-09-23: 起票する）。折れ線が同じ難易度へ写す境界は地図で段にならない（backend/app/domain/axis_display.py の _map_band_thresholds、T939）。軸スタジオの段階プレビューの見出し「N段階になります」はこの落ちる値も数えるため、印は出ても段数は地図より多いまま表示される。やること: 見出しの段数を、T957で新設した判定（thresholds_the_map_drops、POST /api/admin/axis-definitions/preview-display-thresholds）の結果から数え直し、地図の段数と一致させる。フロントに判定を写さない。完了条件: 落ちる値を含むしきい値で、見出しの段数が地図の凡例の段数と一致することを、入力に対するあるべき値のテストで示す。frontend/e2e/ と playwright.config.ts はユーザーの別セッション（T1078）が作り直し中なので触らない。
