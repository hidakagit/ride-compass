# T1095. 経路探索エンジンのテストが持つ探索構造の偽物（FakeLazyGraph・FakeCsr等7種）を、本物の型で作る形へ置き換える

状態: 未完了（2026-09-25起票）

## 背景

T1094で道路グラフと座標の偽物を本物の型へ置き換えた際、同じtest_road_graph_engine.pyにdomain/routing.py・domain/attributes.pyの型をまねた偽物が7種（LazyRoadGraph・CsrGraphStructure・SearchGraphStatics・TurnExpandedStructure・TurnExpandedTree・NodeJunction・ElevationAttributeの代役）、組み立て30箇所残っていると分かった。偽物は本物と形が既にずれている（FakeCsrは本物の必須フィールドindicesを持たず、FakeTreeはstate_cost等を持たない）。本物が変わっても偽物は黙って古い形のまま通る。完了の条件の案: 7種を消して本物で作る。本物で作れない入力でしか成り立たないテストはテストを弱めずに要確認として出す。置き換え前後の件数・行・対象モジュールの行/分岐カバレッジ・T1021完了の条件7の(a)(b)の数を並べる。規模の根拠: ファイルは1本だが組み立て30箇所を本物で組み直すため変更行が200を超える見込み。起票案 kihyoan-engine-test-search-structure-fakes として2026-09-25承認。
