# T983. 事故と指定路線だけ、取込の中でHTTPを叩いている 規模S

状態: 未完了

未着手（2026-09-21起票）。

## 背景

外部ソースの取得は取込と分ける形に揃えてきた——標高は`scripts/fetch_dem_tiles.py`、
土地被覆は`scripts/fetch_lulc_raster.py`、OSMの抽出ファイルは`scripts/fetch_osm_pbf.py`。
取込はローカルのファイルを読むだけにする。

`source_adapters/npa_honhyo.py`（警察庁の本票）と`source_adapters/ksj_designation.py`
（国土数値情報の指定路線）だけ、アダプタの中で配信元へ取りに行く。手元に無ければ
落としてくる作りで、取込のトランザクションの中でHTTPが走る。

取込はソースごとに別トランザクションのため、失敗しても他のソースは巻き戻らない。
被害は限定されるが、**形が揃っていない**。どのソースがローカルで完結し、どれが外部に
依存するのかが、実装を読むまで分からない。

## 対応方針

`fetch_*`へ切り出し、アダプタは手元のファイルを読むだけにする。ローカルに無ければ
「先に取得を流せ」と言って止まる（`gsi_dem_tile.py`と同じ形）。

## 完了条件

- 取込のどのアダプタも、実行中に外部へ接続しない。
- 取得を流していない状態で取込を実行すると、何を流せばよいかが分かる形で止まる。
