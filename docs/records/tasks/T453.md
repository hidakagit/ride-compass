  数値のみ、経緯説明は該当history本文へ）。
- Confidence: High（docsシャードが実ファイルを直接確認）。

- **対応**: 説明文側の行（ui節、24点の行）へ数値デルタ`-76`を先頭に追加し、既存の説明文は
  括弧書きとして残した（スコア値自体[24/2/3/2/0]は変更していない）。
- **運用ルールへ明記**: `scores.md`冒頭の運用ルールへ「前回差分列は初回行のみ『初回記録』、
  以降は必ず数値デルタを先頭に置いた上で経緯説明を括弧書きで続ける（対象範囲が異なり
  単純比較できない場合もその旨を括弧内へ注記し、数値デルタ自体は省略しない）」を追記した。
- **横展開チェック**: 全10行を確認し、他に同種の不統一（数値デルタ欠落）が無いことを
  確認した。
- 「追記のみ（過去の行を書き換えない）」という既存運用ルールとの関係: 本タスクはスコア値
  （P0〜P3件数・総合スコア）自体は一切変更せず、書式（数値デルタの欠落）のみを補った。
  タスク自身の対応方針がこの修正を明示的に想定していたため、書式修正はこのルールの
  例外として扱ってよいと判断した。
- **検証**: Markdownの表構造が壊れていないことを目視確認。
