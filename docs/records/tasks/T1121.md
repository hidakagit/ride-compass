# T1121. 配信で値を受け取る評価軸（勾配のレンズ等）の線が、値があっても全部破線になるのを直し、地図の式がfeature-stateを読めない場所で使っていないかを検査する

状態: 未完了（2026-09-25起票）

## 背景

ユーザー報告（2026-09-26、スマホ）: 勾配のレンズの線が全て破線になった。原因: T1105で値が無い道を破線にしたとき、配信で値を受け取る軸（値はfeature-state）の「値が無い」の判定式をline-dasharrayへ渡した。MapLibreのline-dasharrayはfeature-stateを読めない（style-specのparametersがzoom・featureだけ）ため、どの道も値が無いと判定されて破線になる。MapLibreのスタイル検証（validateStyleMin）はこの誤りを捕まえない（実測: feature-stateを含むline-dasharrayでエラー0件）。ユーザー指示: 他も総点検し、変な依存関係ができているならシンプルにする。規模の根拠: axisLines.ts・scene.state.contract.test.ts・axisLines.test.ts・設計書で、変わるファイルは3（③7以下）。
