# T1074. car_stress軸を指定路線の材料なしで作り直すかを決める（判断待ち）

状態: 未完了（2026-09-23起票）

## 背景

T973で非商用データ（国土数値情報N10/N12）を撤去したとき、それを加点に使っていたcar_stress一族6軸は材料の参照を外すのではなく軸ごと本番から削除された（c1e7b743c）。いま公開軸にcar_stress相当（幹線・車の多さによる走りにくさ）は無い。指定路線の材料なしで作り直すかは評価軸の品揃えの判断で、ユーザーが決める。作り直す場合は、残る材料（道路種別・車線数・速度規制・交通量等）から軸を組み、axis_admin API経由で追加する。作り直さない場合は見送りとして閉じる。
