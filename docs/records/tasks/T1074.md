# T1074. car_stress軸を指定路線の材料なしで作り直すかを決める（判断待ち）

状態: 完了（2026-09-23）

## 背景

T973で非商用データ（国土数値情報N10/N12）を撤去したとき、それを加点に使っていたcar_stress一族6軸は材料の参照を外すのではなく軸ごと本番から削除された（c1e7b743c）。いま公開軸にcar_stress相当（幹線・車の多さによる走りにくさ）は無い。指定路線の材料なしで作り直すかは評価軸の品揃えの判断で、ユーザーが決める。作り直す場合は、残る材料（道路種別・車線数・速度規制・交通量等）から軸を組み、axis_admin API経由で追加する。作り直さない場合は見送りとして閉じる。

## 保留（ユーザー判断）: car_stress軸を作り直すか（2026-09-23 依頼）

**問い**: 幹線・車の多さによる走りにくさを表す公開軸（旧car_stress一族）が、いま無い。指定路線の
材料を使わずに作り直すか。

1. **作り直す**: 残る材料（道路種別・車線数・速度規制・交通量等）で軸を組み、軸スタジオ
   （axis_admin API）で追加する。材料の選定と較正は別の担当が行い、公開前に見てもらう。
2. **作り直さない（見送り）**: このタスクを見送りとして閉じる。

**保留した場合の影響**: 機能は壊れない。旧car_stress一族が担っていた評価は、公開軸に無いまま続く。
**ユーザー決定（2026-09-23）**: 作り直す。別タスクで行う（「別タスク起票して」）→ [T1075](T1075.md)。
