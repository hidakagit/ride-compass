# T1052. Open-Meteoと環境省WBGTの出典が画面に出ていない

状態: 未完了（2026-09-23起票）

## 背景

T975でdocs/architecture/data-sources.mdを作り表記の要件と画面を突き合わせたところ、CC BY 4.0のOpen-Meteo（MSMの配布元）と、PDL1.0の環境省WBGTの出典が地図・画面のどこにも出ていなかった。

## 何が足りないか（2026-09-23、[data-sources.md](../../architecture/data-sources.md)の表と画面を突き合わせて判明）

- **Open-Meteo**: MSMの配布物はCC BY 4.0で、表示箇所の近くにOpen-Meteoへのリンク付き
  クレジットを求める（[licence](https://open-meteo.com/en/licence)）。現状、画面のどこにも
  Open-Meteoの名前が無い。風レイヤーのソースは`attribution: "気象庁MSM"`だけ
  （`frontend/src/features/map/scene/groups/weather.ts`）。しかもMSMは風のコストとして
  **ルート計算に常時使う**ため、レイヤーのON/OFFで消えない常時表記（`MapView.tsx:
  MAP_BASE_ATTRIBUTION`、[static-map-layers.md](../../modules/frontend/static-map-layers.md)
  「出典表記」の区分）に当たる可能性が高い。
- **環境省 暑さ指数（WBGT）**: 熱中症予防情報サイトはPDL1.0準拠で出典を求める。WBGTは
  `WarningBadge`に出るが、出典（環境省）が画面に無い。
- **気象庁の配信物の「加工した旨」**: 気象庁タイルは補間して配っている
  （`backend/app/infrastructure/jma_tile_interpolation.py`）。PDL1.0は加工したときに出典とは
  別に加工した旨を求める。現状のソース側表記は「気象庁」だけ。補間が「加工」に当たるかを
  利用規約の文言に照らして決める。

## 母集団と完了条件

母集団は`docs/architecture/data-sources.md`の表のうち、**画面に値が出るか、画面に出る値の
計算に使われる**行すべて。各行の「表記の要件」を満たす表記が、そのデータが効いている間
画面に出ていること。

- 完了の確認は実機（開発サーバー＋Chromium、PC幅とモバイル幅）でⓘを展開し、各行の要件と
  1件ずつ突き合わせる。常時表記・レイヤー側表記のどちらに置いたかと理由を記録する。
- 要件を満たさないまま残す行があれば、残す理由をユーザーへ確認する（こちらで決めない）。
- 情報量の追加になるため、文言・置き場（常時表記へ足すか、レイヤー側か）は実装前に
  ユーザーと詰める（走行中のスマホが主用途で、表記は既定で折り畳まれている）。
