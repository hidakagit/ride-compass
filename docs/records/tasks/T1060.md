# T1060. sceneが旧居（components/Map）から借りている宣言を、持ち主の置き場へ移す

状態: 完了（2026-09-23、T1001段階Dへ統合）

## 背景

T1029の第2段。T1029でsceneの入力型をMapViewのpropsから切り離しimport循環は0件になったが、features/map → components/Map の依存は残る。どの値がsceneの持ち物かの基準と対象の導出はT1029.mdの「第2段」節にある。

## 対象の導出（再現できる形で）

母集団: `frontend/src/features/map/**`の非テストファイル（`*.test.*`を除く）が、
`frontend/src/components/Map/**`から**import文で名指ししている名前**。TypeScriptのASTで
`import`・`import type`の束縛を取り、名前ごとに「features/mapの外の本番コードからも
importされているか」を添える（コメント・文字列一致は数えない。T1023の列挙器と同じ規則）。

T1029完了時点（2026-09-23、master `f98d5dd6`＋T1029）の実測は37名。うち
**features/mapの外に本番の消費者が無いもの**が16名（例: 評価軸の値の式
`buildAxisRampValueExpression`・「不明」の色`COLOR_UNKNOWN`・降水と風のカラーストップ・
ルートの矢印の絵・JMAタイルのプロトコル・面の差し込み位置`areaLayerAnchor`）、
**両側に消費者がいるもの**が21名（例: 凡例の段の鍵`legendBandKey`・`LEGEND_NO_DATA_KEY`・
段の配色`bandColorsFor`・軸カタログのビュー型`RampAxis`・`DedicatedWayValueAxis`・
レンズの配色`LENS_NEUTRAL_COLOR`）。

## 基準（どの値がsceneの持ち物か）

1. **sceneの外に本番の消費者が無い宣言は、sceneの持ち物**。地図に何をどう描くか
   （色・しきい値・記号の絵・MapLibreへの当て方）の宣言で、画面部品は読まない。
   `features/map/scene/`（家族の宣言なら`groups/<家族>.ts`、家族をまたぐなら
   `sceneBuilders.ts`等）へ移し、元の置き場から消す。
2. **sceneと画面部品（凡例・チップ・軸スタジオ）の両方が読むものは、どちらの持ち物でもない**。
   「地図と凡例が同じ値を読む」ための共有の宣言で、sceneへ入れると画面部品がsceneへ依存し
   返し、`components/Map`に残すとsceneが旧居へ依存し続ける。**両方より下の第三の置き場**へ
   移す。
3. **軸カタログから導くビュー型**（`RampAxis`・`DedicatedWayValueAxis`と、それを作る変換）は
   地図の描画ではなく「軸カタログをフロントの形へ移す」ものなので、`lib/axisCatalog.ts`の側へ
   寄せる候補。
4. **MapLibreのインスタンスを触る低水準の操作**（`runWhenStyleReady`・`areaLayerAnchor`）は、
   どのレイヤーかを知らないものだけを置く`mapStyleOps.ts`の性質を保ったまま、置き場だけを
   基準2と同じく両側より下へ。

## 着手前に決めること（置き場と命名。CLAUDE.md「新しい種類の成果物は、置き場と命名を先に決める」）

基準2・4の「両側より下の第三の置き場」は既存の慣習が無い。書き始める前に置き場と命名を
決めて司令塔（またはユーザー）の合意を取る。候補:

- **A.** `features/map/display/`（地図の表示語彙: 段の鍵・配色・凡例の型）を新設し、
  `features/map/scene/`と`components/Map/`の両方がそこを読む
- **B.** `lib/mapDisplay/`（`lib/`は画面部品に依存しない層という既存の慣習に乗せる）

## 完了条件

- 上の導出で「features/mapの外に本番の消費者が無い」名前が0件。
- 両側に消費者がいる名前は、合意した第三の置き場へ移り、`components/Map`にも
  `features/map/scene`にも定義が無い。
- 本番コードのimport循環が0件のまま（T1029の導出と同じ: `import type`も辺に数える）。
- 移した宣言を説明している`docs/modules/frontend/*.md`の対象ファイル表・本文が、新しい置き場を
  指している。
