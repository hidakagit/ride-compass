# T1004. E2Eが、地図が描けたかを見ていない 規模S〜M

状態: 完了

未着手（2026-09-22起票。[T1003](T1003.md)でmaplibre-glをv6へ上げる際、Workerを壊した状態で
E2E 9本が全て通ったため判明）。

## 何が起きたか

Workerのスクリプトが404になり地図が**一切描かれない**状態（canvasは残るが中身が空、
`Failed to load module script: ... non-JavaScript MIME type of "text/html"`）で、
`npm run test:e2e`の9本がすべて緑になった。E2Eはチップの開閉・候補一覧・シートの表示という
**DOMの状態だけ**を見ており、地図が描けたかを見ていない。

**害**: 地図アプリの回帰のうち最も重いもの（何も描かれない）をCIが通す。利用者からは
「真っ白な地図」として届く。

## 完了条件

- 地図が描けたことを見る検査が1つ入っていること。**壊れた入力を1件通して落ちることを確認する**
  （`configureMaplibreWorker()`の呼び出しを外してビルドすると落ちる、が再現手順。手順の詳細は
  [T1003](T1003.md)「確認の手順」）。
- 何を見れば「描けた」と言えるかを決めて書くこと。候補: canvasのピクセルが一様でないこと
  （`toDataURL`の分散）・タイル要求が200で返ること・`maplibregl-canvas`のサイズが
  コンテナと一致すること。**どれを採るかは、上の「壊して落ちる」を満たすかで決める**
  ——満たさないものを入れても、いまと同じく緑のまま通る。
- 1本だけにすること。全specへ足すと、遅いうえに同じことを9回確かめる。

## 実施（2026-09-23）

`frontend/e2e/map-runtime.spec.ts`に1本だけ足した（「地図が描ける（Workerが動き、ソースの面が
画素になる）」）。基礎地図スタイルの応答を、世界全体を覆うGeoJSONの面を専用色（マゼンタ）で
塗るスタイルへ差し替え、`canvas.maplibregl-canvas`の写しを取ってその色の画素の割合が過半に
なるまで待つ。

### 「描けた」を何で見るか

**GeoJSONソースの面が画素として出たこと**を採った。候補を「Workerを壊すと落ちるか」で選んだ:

| 候補 | Workerが読めないとき | 採否 |
|---|---|---|
| canvasの画素（採用） | GeoJSONの取り込みはWorkerが行うため、面が1画素も出ない | 落ちる |
| `maplibregl-canvas`のサイズがコンテナと一致 | canvasはMapの生成時に作られ、サイズも合ったまま残る（T1003の観測「canvasは残るが何も描かれない」） | 落ちない |
| タイル要求が200で返る | E2Eの基礎地図は空スタイルで、タイル要求そのものが無い。ラスタタイルの取得はメインスレッドで行われ、Workerの生死に依らない | 落ちない |

画素は`toDataURL`ではなく要素の写し（`locator.screenshot()`）から数える。MapLibreは既定で
描画バッファを保持しない（`preserveDrawingBuffer: false`）ため、`toDataURL`は描けていても
空を返しうる。地図の上にはチップ・パネルが重なるので、全面ではなく過半（>0.5）を条件にした。

置き場は新しいファイル`map-runtime.spec.ts`（地図の実ブラウザでしか出ない挙動の置き場）にした。
[T1014](T1014.md)で既存のE2Eを観点ごとに組み直すときの受け皿にもなる。

`docs/conventions/testing.md`パターン4へ「地図が描けたかは画素で見る」（1本だけに置く）を足した。

### 検証（2026-09-23、CIのe2eジョブ＝Linux）

壊した入力: `MapView.tsx`から`configureMaplibreWorker()`の呼び出し（とimport）を外した
コミット（`1bebe145`、masterへは入れない）を作業ブランチへpushした。
[CI run 35819720575](https://github.com/hidakagit/ride-compass/actions/runs/35819720575)の
e2eジョブ: **1 failed / 9 passed**。落ちたのは本テストだけで、再試行も含め
`Expected: > 0.5 / Received: 0`（マゼンタの画素が1つも出ない）。他の9本はWorkerが死んだ
状態でも緑のまま——T1003で見た「DOMだけを見ているので通ってしまう」がそのまま再現した。
壊していない側の結果は、このコミット自身のCIが持つ。
