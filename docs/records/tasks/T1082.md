# T1082. 降水短時間予報（rasrf）の配信要素と時刻一覧の在り処を源泉へ宣言する

状態: 未完了（2026-09-23起票）

## 背景

T1080で気象のデータ層は配信要素idとパスの系統を源泉（mapDisplay.weatherElements）から引く形になったが、降水の60分〜15時間先（降水短時間予報、要素rasrf・系統rasrf）はbackendのWEATHER_ELEMENTSにもJMA_TILE_SPECSにも宣言が無く、precipitationNowcast.tsが要素idと系統を手で持つ。時刻一覧の在り処（jmaNowcastFrames.ts: JMA_TARGET_TIMES_PATHS）もbackendのプリウォームと画面が別々に持つ。

## なぜT1080で片付けなかったか（決めることがある）

降水の名前付きソース`precipitationNowcast/main`のラスタは、選んだ時刻によって**2つの配信要素**
（60分以内=`hrpns`/系統`nowc`、60分〜15時間=`rasrf`/系統`rasrf`）から届く。今の宣言
`WeatherElement`は1要素=1配信要素idで、（チップ, ソース, 描き方）が一意という不変条件
（`test_map_display.py`）があるため、`rasrf`を2件目として足すことはできない。形を決める必要がある:

- 案A: `WeatherElement.jma_element`を「時刻の段ごとの配信要素の並び」にする（生成物の形が変わり、
  画面の`weather.ts`・`jmaNowcastFrames.ts: declaredJmaElement`も追従）。ソースのズーム範囲は
  段の間で一致することを不変条件にする。
- 案B: 60分〜15時間先を別の名前付きソースにする（描き方・重なり順・データ取得状態の集約が変わる）。

また`rasrf`を`JMA_TILE_SPECS`へ足すと、backendの奇数ズーム補間（`source_zoom_for_interpolation`）が
`rasrf`のタイルにも効き始める。`rasrf`の`zoomUse`・`maxNativeZoom`は一次情報で未確認
（`sjfcstmap`と同じく公式ページが設定を外部化していない可能性がある）。**今は`rasrf`が仕様に無いため
奇数ズーム（z5/z7/z9）の短時間予報が空タイルになっている疑いがある**（未確認）。

## やること

1. 気象庁の公式ページが読み込む設定ファイルで`rasrf`の`zoomUse`・`maxNativeZoom`を確かめる
   （`docs/modules/backend/weather-dynamic-layers.md`「要素ごとのズーム上限」節の出典の取り方と同じ）。
   あわせて、開発機から`/api/jma-tile/bosai/jmatile/data/rasrf/.../surf/rasrf/9/...`を1枚取り、
   奇数ズームが空かを実測する。
2. 案A/Bを選び（ユーザー確認）、`rasrf`を源泉へ宣言して`JMA_TILE_SPECS`へ仕様を足す。
3. 時刻一覧の在り処: 画面の`JMA_TARGET_TIMES_PATHS`とbackendのプリウォーム
   （`services/jma_tile_prewarm_service.py`の`_*_TARGET_TIMES`）が同じ事実を別々に持つ。
   要素ごとの時刻一覧（`nowc`は`targetTimes_N1/N2/N3`へ分かれる）を配信元の仕様として
   backendへ宣言し、両方がそこから引く。

## 母集団と完了条件

- 母集団: `frontend/src`のテスト・生成物以外で、配信要素id・パスの系統・時刻一覧のidを文字列で持つ箇所
  （grep: `["'\`](rasrf|hrpns|land|rain_mesh|inund|flood|sjfcstmap|thns|trns|liden)["'\`]`、
  `group: "(risk|nowc|rasrf)"`、`fetchJmaTargetTimes\(`の第1引数）。コメント中の例示は除く。
- 完了: 上の母集団のコード中の手書きが0件。変更が届くvitest・pytestと全体のtscが通る。

## 保留すると何が起きるか

backendが降水短時間予報の要素idや系統、時刻一覧の在り処を変えても、画面は古い値でURLを組み立て、
タイルは404→空タイルに倒れて地図から黙って消える（`jmaTileProtocol`は404を失敗として記録しない）。
奇数ズームの空タイルの疑いが本当なら、降水の60分〜15時間先はズームによって出たり消えたりしている。
