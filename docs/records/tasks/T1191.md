# T1191. 凡例パネルとレンズを開いたまま絞り込むと「読み込み中です」が一瞬出て中身が揺れるのを止める

状態: 完了（2026-09-27。読み込み中は文にせずドットだけで示す）

## 背景

地図のチップの▶（凡例パネル）とレンズを開いた先に取得状態を文で出す一行があり、読み込み中も含まれていたため、凡例の絞り込みやON/OFFでタイルを取り直すたびに「読み込み中です」が一瞬出ては消え、下の凡例が上下に揺れていた（2026-09-27 ユーザー報告「チラツキは目につく。読み込み中はアイコンの右上で示せている」）。

起票案 proposal-legend-loading-flicker（2026-09-27承認）。規模S（根拠: 変わるファイルは実装3・テスト2の5本で7以下）。

## 対応

- 開いた先へ文として出すのは失敗・空だけにし、読み込み中はドットだけで示す。判定は`mapLayers.ts: layerDataStatusNotice`に
  1つ置き、`MapOverlayControls`（▶の凡例パネル）と`LensControl`（レンズのポップオーバー）の両方が使う。`title`（ホバー向けの
  複写）は従来どおり読み込み中も含める。
- 凡例を持たないチップは、読み込み中に▶自体も出さない（▶の中身が状態の文だけだったため、▶の出入りもちらつきになっていた）。
- 規約（`page-composition.md`「失敗・空・待ちの伝え方」3）と`static-map-layers.md`へ「待ちは文にしない」を書き足した。

### 範囲の導出

「取り直しのたびに状態の文が出入りする」箇所を、`role="status"`と「読み込み・取得中・計算中・更新中・問い合わせ中」の
grep（`frontend/src`の`*.tsx`、テストを除く）で列挙した。該当は上の2か所だけ。他の当たりは該当しない:
天候バー（`WeatherPanel`）は観測値が無いときだけ「天候取得中...」を出し、取り直しの間は前の値を出したまま／
ルート設定（`RouteSettingsPanel`）の`role="status"`は失敗だけ／道の評価（`RoadInspectorPopup`）と管理画面は押した操作への応答。
origin/master 84cc7abe へ当て直した後にも同じgrepを回し、同じ結果だった。
