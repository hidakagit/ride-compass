# T1102. 道路種別の線の色と、地図のチップの凡例の色見本を見やすくする

状態: 完了（2026-09-25）

## 背景

地図のチップの「道路種別」の5段が濃い青灰色の濃淡で、地図でも凡例でも見分けにくい（ユーザー報告 2026-09-25、スマホ）。T1026の順序のある配色の規則（明度だけの濃淡、色相固定）が原因。凡例の見本は色7pxに地色の輪3pxで、輪が太く色の部分が見えにくい。ユーザー決定（2026-09-25）: 線の色は明度で順序を保ったまま色相も動かす（紫→緑、地色に3:1以上）、凡例の見本は地色の台に線の形で置く。チップの説明文「線の太さで表示」も今の挙動へ直す。

## 決定と変更（2026-09-25）

- **線の色**: 起票時の案（紫→緑）は評価の配色（緑〜赤）と重なり、`docs/modules/frontend/static-map-layers.md`の「一次属性の
  区分に評価の色を使わない」に反するため、ユーザーに聞き直して**紫→水色**（案B'）に決めた。順序のある配色の規則
  （`display_palette.py: ordered_colors`）を、明度で順序を示したまま色相も動かす形に変えた（色相305°→205°・明度26→56・彩度45、
  sRGBに収まらない色は彩度を下げて収める）。規則そのものを変えたので、順序のある軸すべてに効く（今は道路種別だけ）。
  地色に対する3:1以上・隣どうしのΔE 10以上は既存のテストで確かめている。設計書の配色の規則の記述もこの形へ直した。
- **凡例の見本**（案2）: 地図と同じ地色の台に、地図と同じ形で色を置く。線で描く行（道路の区分）は線の形、点で描く行は
  点の形。`LegendEntry`に`line`を足し、チップの凡例（`MapOverlayControls`）が見本を描く。
- **説明文**: 道路種別の説明は「線の太さで表示」のまま古くなっていたので、今の挙動（色で表示・一緒に表示すると線を横へ並べる）へ
  直した。路面だけ説明（ⓘ）が無かったので足した（ユーザー指摘「路面だけ説明がない。」）。
- 色の正本はbackendのままで、frontendに色の値を足していない（ユーザーの確認に答えた）。

## 検証

- 見た目: e2eの模擬（`openMobileApp`・配信情報を全系統入れた軸カタログ）でスマホ幅の「道路の種類」「路面の種類」の凡例を撮り、
  地色の台に線の見本が並ぶことを見た（一時のspecで撮り、コミットしていない）。
- `pytest tests/test_primary_attribute_display.py` 61 passed。frontendは変更したシンボルを参照するテスト12ファイル 242 passed。
  足した凡例の見本の形のテスト2件は、道路の区分から`line`を外すと落ちることを見た。
- ruff・mypy・prettier・eslint・`tsc --noEmit`・knip・`review_checks.py docs`は指摘0件。OpenAPIと生成物を作り直して差分が無いことを見た。
