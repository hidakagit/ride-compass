# T974. 出典表記が提供元の要件を満たしていない 規模S

状態: 未完了

未着手（2026-09-20起票）。

## 背景

2026-09-20に外部データ6ソースの許諾条件を提供元の公式ページで確認した（経緯と全ソースの
調査結果は[T975](T975.md)）。その結果、いまの出典表記が要件を満たしていない点が3つ見つかった。

現在の表記は `frontend/src/components/Map/MapView.tsx` の定数1本:

```
© OpenStreetMap contributors / 国土数値情報（国土交通省） / 警察庁 /
土地被覆: Esri, Impact Observatory, Microsoft (CC BY 4.0)
```

## 直すこと

### ① PDL1.0の「加工した旨」の記載が無い

国土地理院・警察庁はどちらも[公共データ利用規約（第1.0版）](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)で、
出典とは**別に**加工したことの明記を求めている。

> コンテンツを編集・加工等して利用する場合は、上記出典とは別に、編集・加工等を行ったことを
> 記載してください。なお、編集・加工した情報を、あたかも国土地理院が作成したかのような態様で
> 公表・利用してはいけません。
> （記載例）地理院タイル（標高タイル（基盤地図情報数値標高モデル））を加工して作成

警察庁側も同文（[利用規約](https://www.npa.go.jp/rules/index.html)）。いまの表記は出典元の
名前を並べているだけで、加工した旨が無い。**我々は加工している**——標高タイルから勾配を導き、
事故点から区間ごとの重み付き件数を導いている。

### ② 国土地理院が主たる出典に入っていない

`GSI_RELIEF_ATTRIBUTION` / `GSI_TERRAIN_ATTRIBUTION` はラスタレイヤーを表示したときだけ出る。
一方、標高タイル由来の**勾配は全画面・全ルートで常時使われている**のに、主たる出典表記に
国土地理院が無い。

### ③ 基礎地図（OpenFreeMap / OpenMapTiles）が主表記に無い

配信元が求める表記は `OpenFreeMap © OpenMapTiles Data from OpenStreetMap`。スタイルJSON側が
`attribution` を持っていてMapLibreが出している可能性があるため、**実機で表示を確認してから**
不足分だけ足すこと（二重表示を作らない）。

## 完了条件

- 実機（開発サーバ）の地図上で、次がすべて読める状態をスクリーンショットで確認する
  - OpenStreetMap contributors（`/copyright` へのリンク付き。ODbLの明示を兼ねる）
  - 国土地理院
  - 警察庁
  - Esri, Impact Observatory, Microsoft (CC BY 4.0)
  - OpenFreeMap / OpenMapTiles
  - **加工して作成した旨**（地理院・警察庁のぶん）
- 表記が長くなるため、モバイル幅で地図を覆わないこと（既定は折り畳み、ⓘで展開等）を
  実機で確認する。[docs/design-principles.md](../../design-principles.md)のUI原則に従う
- [T973](T973.md)で国土数値情報を削除したら、その行も表記から消す

## 注意

`MapView.tsx` の定数を書き換えるだけの作業に見えるが、**表示を実機で見ずに完了にしない**。
出典表記はレイヤーの切り替えで出たり消えたりする作りになっており、定数を直しても画面に
出ていないことがありうる。
