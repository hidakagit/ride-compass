# T450. needs_bearing=False分岐が未テストのまま宣言されている

状態: 完了（2026-08-31）

- 背景: `統合レビュー第2回`（`.claude/commands/review/history/2026-08-30_all_2.md`P3-1）の
  指摘。`needs_bearing=False`分岐が宣言されているが、それを使う材料が現状存在せず
  （wind/gradientとも`needs_bearing=True`）、この分岐に対する直接のテストが無い。
- 対応方針: `needs_bearing=False`を使うダミー材料（またはパラメタライズドテスト）を
  用意し、この分岐が実際に正しく機能することを検証する回帰テストを追加する。
  T445（bearing_deg型シグネチャ不整合）と関連するため、着手時にまとめて確認すると
  効率が良い。
- Confidence: High（backendシャードがコード上の分岐とテストカバレッジを確認）。
- 規模S。

## 実施記録（2026-08-31完了）

- **対応**: `test_region_routes.py`へ`test_region_dynamic_way_values_needs_bearing_false_does_not_require_bearing_deg`を追加。
  `DYNAMIC_WAY_VALUE_MATERIALS`（region.pyが`from ... import`で束縛した同一dictオブジェクト）へ
  `monkeypatch.setitem`で`needs_bearing=False`のダミー材料を差し込み、`bearing_deg`を
  省略しても422にならず200で`fake.last_request`の`bearing_deg`にNoneがそのまま渡ることを
  検証した。monkeypatchのため他テストへの汚染は無い。
- T445（bearing_deg型シグネチャ不整合）との関連は、T445側で既にrouter/service間の型を
  `float | None`へ揃えNoneガードを追加済みのため、本タスクでの追加対応は不要と判断した。
- **検証**: `pytest tests/test_region_routes.py`25件すべて通過。
