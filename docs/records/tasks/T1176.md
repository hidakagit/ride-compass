# T1176. 警報・洪水予報の区域を、国土地理院の逆ジオコーダではなく気象庁の区域の境界データから引く

状態: 未完了（2026-09-26起票）

## 背景

起票案 proposal-jma-area-geocode（2026-09-26承認）。T1053-gsi-reverse-geocoder の答え(1)から。jma_warning_client.py が地点の区域を国土地理院の逆ジオコーダ（利用規約が無く商用利用に触れていない、data-sources.md で要確認）へ毎回問い合わせている。気象庁の「市町村等（気象警報等）」区域の境界GISデータ（気象庁ホームページの利用規約。着手時に公式で確かめ data-sources.md へ）を取得し、地点→区域コードを手元で引く形へ置き換え、逆ジオコーダへの問い合わせを撤去する。境界はファイルで持ちプロセス内で引く見込み（PostGISへ入れるなら本番DBへ書くのでL）。区域コードが今と同じになることは代表の地点で移行時に1回確かめ、残すテストは入力に対するあるべき区域コード。境界データの更新（市町村の合併等）を追う手順を書く。画面の表示は変わらない。
