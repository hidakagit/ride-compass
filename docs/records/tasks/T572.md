# T572: 国土地理院 色別標高図タイルのバックエンド永続キャッシュ化

状態: 完了（2026-09-04）

## 背景

[T412](T412.md)（JMA動的タイル系レイヤーのバックエンド経由化）の「横展開の検討」で、
国土地理院の色別標高図タイル（`cyberjapandata.gsi.go.jp`、`frontend/src/components/
Map/MapView.tsx`）がJMAタイル系と同様の性質（一度取得したら内容不変、`tile_cache.py`の
永続キャッシュがそのまま使える）を持つと判明した。JMAの「非公式内部API」とは異なり
「ブラウザからの直接埋め込み利用を前提に国が公開している正式なAPI」のため負荷分散の
観点では対象外だが、レスポンス速度向上（キャッシュヒットで高速化）の余地はあるとして
「別の軽量タスクとして起票する」方針でユーザーと合意していた。

## 対応方針（着手時に確定）

`basemap_client.py`/`jma_tile_client.py`と同じ「pathを丸ごとプロキシ＋`tile_cache.py`の
永続ファイルキャッシュ」パターンを踏襲する。色別標高図タイルは時刻依存パラメータを持たない
静的データのため、TTL付きキャッシュ（`targetTimes.json`相当）の分岐は不要。

## 実装メモ（2026-09-04）

`GsiTileClient`（`app/infrastructure/gsi_tile_client.py`、新規）を
`basemap_client.py`と同型で実装（URL書き換え・TTL分岐は不要なぶんbasemap_client.pyより
薄い）。`app/api/routers/gsi_tile.py`（`GET /api/gsi-relief-tile/{path:path}`、新規）・
`api/dependencies.py: get_gsi_tile_client`・`config.py:
gsi_tile_rate_limit_per_minute`（300/分、basemap/jma-tileと同水準）を配線。
`next.config.ts`のrewritesへ`/api/gsi-relief-tile/*`を追加し同一オリジン化。

`MapView.tsx`の`GSI_RELIEF_TILE_URL`を直接埋め込みの絶対URL
（`https://cyberjapandata.gsi.go.jp/xyz/relief/{z}/{x}/{y}.png`）から相対パス
（`/api/gsi-relief-tile/xyz/relief/{z}/{x}/{y}.png`）へ変更。

docs/architecture.md（対象ファイルツリー・「標高オーバーレイ」節・「横展開の検討」節・
Step10 API仕様例、計6箇所）・docs/modules/backend/weather-dynamic-layers.md
（対象ファイル表・simple_api_client.py対象外リスト）を同一コミットで更新し、
「バックエンドを介さない」という陳腐化した記述を解消した。
