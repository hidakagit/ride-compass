# T807. 区間を合成して作ったルートの結果が、押した場所から見えない

規模S。
状態: 完了（2026-09-13、ユーザー報告「さっき新ルートを作ってみたけど、追加されていない
ように見えた」）

## 背景

「この組み合わせを候補へ追加」を押した後、**成功しても失敗しても押した場所には何も出ない**。

- 成功: 新しいルートは`routes`へ入り`selectedRouteId`も切り替わるが、それが見えるのは
  「ルート結果」の一覧。押した利用者は「ルート編集」にいるため、画面は何も変わらない
  （モバイルはシートが排他表示で、結果のシートは開かない）。
- 失敗: `setErrorMessage`で入れた文言の出し先は`renderRouteOutcomeEmptyState`だけで、
  **候補が1件でもあると描かれない**。つまりエラーが完全に飲まれる。

[T758](T758.md)で「生成」については同じ穴（押した結果が操作している場所から見えない）を
塞いだが、合成は対象外のまま残っていた。

## 対応

- 合成の失敗は編集パネル自身へ出す（`RouteSplicePanel`の`error`）。対象を選び直したら消す。
- 成功したら`notifyRouteOutcome()`で結果欄を開き、モバイルは「ルート結果」シートへ切り替える
  ——**押した結果が見える場所まで連れて行く**。自動で開かない方針（T758）は、生成のように
  背後で終わる操作が対象で、ここは押した操作の直接の結果のため当てはまらない。
