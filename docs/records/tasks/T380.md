# T380. 推定グループ展開時、地図オーバーレイの▼縦送りボタンがチップ列から水平方向にずれて浮く不具合を修正 規模S（2026-08-27完了）

状態: 完了

- 背景: ユーザーから実機スクリーンショット付きで「▼アイコンが出る位置がおかしい」と
  報告。再現条件は「推定グループを開いている時」との追加指摘あり。
- 原因: `MapOverlayControls.module.css`の`.pageButton`（改善計画T374で導入、はみ出し
  ページ送り用の丸ボタン共通クラス）に`align-self: center;`が付いており、これを
  縦送り（▲▼、`.wrapper`直下＝列flexの子）と横送り（◀▶、`.headerLegendRow`直下＝
  行flexの子）の両方で共用していた。flexの`align-self`はクロス軸方向の寄せを指定する
  ため、列flexでは「水平方向の中央寄せ」、行flexでは「垂直方向の中央寄せ」という
  正反対の意味になる。推定グループを展開すると`.estimatedFlatRow`（軸タイルの横並び）
  が`.wrapper`の`width: max-content`を大きく広げるため、▲▼に付いた
  `align-self: center`がその広がった`.wrapper`幅の中央へ▲▼を引き寄せてしまい、
  縦一列のチップ列（左端に固定）から離れた地図上の余白に浮いて見えていた。
- 修正: `.pageButton`から`align-self: center`を削除（`.wrapper`自身の
  `align-items: flex-start`に委ね、縦送り▲▼は常にチップ列と同じ左端に揃う）。
  横送り◀▶（`.headerLegendRow`内、軸タイルより丈が低いため垂直中央に置きたい）
  だけに個別クラス`.pageButtonHorizontal { align-self: center; }`を追加し、
  `MapOverlayControls.tsx`の◀/▶ボタン（`pageEstimatedRowBackward`/
  `pageEstimatedRowForward`側）にのみ付与した。
- 検証（2026-08-27）: Playwrightで実機相当の検証を実施。推定グループを展開した状態で
  `chipRowViewport`のmax-heightを検証用に一時的に縮め（本番CSSは変更せず、テストの
  みの上書き）縦送り▼を強制的に発生させたところ、修正前は▼のx座標がチップ列の
  x座標から+146px右にずれて表示された（ユーザー報告の再現に一致）。修正後は▼が
  チップ列と同じx座標（diff=0）に揃うことを確認した。加えて横送り◀▶が引き続き
  正しい位置（推定チップ列の右端付近、垂直中央）に表示されることも確認。
  frontend tsc/eslint/vitest（`MapOverlayControls.test.tsx`38件）green。
