# T706. CIが検証するNodeと本番が動かすNodeを揃える 規模S

状態: 完了（2026-09-10起票、統合レビュー第6回。2026-09-10完了）

## 背景

- `.github/workflows/ci.yml:98,140,162` はいずれも`node-version: "22"`
  （コメントも「dev環境と同じNode 22系に固定する」）
- `frontend/Dockerfile:1,8` は`FROM node:20-slim`（build・runの両方）
- `frontend/package.json`に`engines`の指定は**無い**

lint・型検査・vitest・e2eのすべてがNode 22で通っているが、**本番が動くのはNode 20**。
ランタイム差に起因する不具合（Node 22で挙動が変わったAPIに依存した実装等）はCIを素通りする。
この差を機械的に止めるものが1つも無い。

## 対応方針

Dockerfileを`node:22-slim`へ揃えるか、CIを20へ落とすか、いずれかへ一本化する。
揃える方向を選ぶなら`package.json`へ`engines.node`を書き、根拠を1箇所にする
（`npm ci`が`engines`を検証するため、以後の食い違いは機械的に止まる）。

## 対応

**Node 22へ揃えた**（CIを20へ落とす方向は採らない。Node 20は2026-04-30で
メンテナンス期限を過ぎており、本番だけがサポート切れのランタイムで動くことになる）。

版の正本は`frontend/package.json`の`engines.node`（`"22.x"`）1箇所に置き、
消費側はそれぞれ機械的に突き合わせる:

- `.github/workflows/ci.yml`（3ジョブ） — `node-version: "22"`を
  `node-version-file: frontend/package.json`へ。`actions/setup-node`は
  `volta.node`→`devEngines.runtime`→`engines.node`の順に読むため、`engines`だけで解決する。
  `defaults.run.working-directory`はactionのinputには効かないため、パスは3箇所とも
  リポジトリルート起点で書く。
- `frontend/.npmrc`（新規） — `engine-strict=true`。既定は警告のみで、
  食い違ったまま最後まで通ってしまう。これを入れることで`npm ci`が走る場所
  （CIの3ジョブ・Dockerイメージのbuild段・開発者の手元）すべてで
  `engines`を満たさないNodeがEBADENGINEで止まる。
- `frontend/Dockerfile` — `node:20-slim`→`node:22-slim`。build段とrun段で別の版が
  混ざらないよう`ARG NODE_VERSION`へ集約し、`.npmrc`をイメージへ渡して
  build段の`npm ci`が`engines`を検証するようにした（`COPY`の対象に入れないと
  イメージ内でengine-strictが効かない）。

`engine-strict`は依存パッケージの`engines`にも効くため、Node 22.22.2に対して
`node_modules`配下の全`engines.node`を突き合わせて不適合0件を確認してから入れた。

`package-lock.json`はルートエントリへ`engines`を反映するため`npm install
--package-lock-only`で再生成した。差分にはtailwindcssのwasmバンドル配下の
optionalエントリの追加（120行ほど）も含まれるが、これは現行npmが書き出す
正規の内容で、手で削らずそのまま入れている。

## 検証

- `npm ci --dry-run`（Node 22.22.2）が成功する
- `engines.node`を一時的に`"20.x"`へ書き換えると`npm ci`が
  `npm error code EBADENGINE` / `Required: {"node":"20.x"} Actual: node v22.22.2`で
  失敗することを確認（ガードが実際に発火する）。確認後に戻した
- `npm run build`（Dockerfileのbuild段と同じコマンド）がNode 22で成功する
- Docker本体はこのセッションの環境に無く、イメージビルド自体は未実行
