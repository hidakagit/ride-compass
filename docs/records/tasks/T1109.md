# T1109. 利用者に見えていない前提を総点検し、画面に出す・直す・そのままを1件ずつ決める

状態: 未完了（2026-09-25起票）

## 背景

ユーザー要望（2026-09-25）: 風予報を何時間先まで使うか等、ユーザーに隠した前提がほかにないか総点検したい。きっかけ: ルートの風は出発地点1か所の予報を全区間に使い、往路・復路とも最大4時間分（1時間刻み）の予報しか使わず、区間の表示はレグの中間の時刻の風だった（T1107・T1108）。段階1（S）: docs/modules/*.md の「暗黙の前提」等の節と、ルートの評価・表示に効くコード（backend/app/services/road_graph_engine.py・route_generator.py・domain の軸・材料の計算、frontend の表示）から、評価や表示に効いているのに画面に出ていない前提をすべて洗い出して一覧にする（例: 夜間の判定は出発時点1点で決まる・到達予想は一定速度・予報の範囲外は端の値を延ばす）。母集団の取り方（どの文書・どのコードを読んだか）を記録に書く。段階2: 一覧をユーザーへ見せ、1件ずつ画面に出す・直す・そのままを決めてもらう。
