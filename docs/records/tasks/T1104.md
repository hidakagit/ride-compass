# T1104. パネルのボタンを、コンパクトな文字入りアイコンのボタンへそろえる（ルート合成の入口を候補の中へ・クリアを全候補を消すと読める形へ・候補の行を所要の長さで崩さない）

状態: 未完了（2026-09-25起票）

## 背景

ユーザー指摘（2026-09-25）: ルート結果内のアイコンが分かりにくい。ルート合成（区間の乗り換えの編集）の入口がタブの上の見出しにあるが、タブ（選んでいる候補）の中にあるべき。ゴミ箱アイコン（ルートをクリア）は選択中のルートだけ捨てるように見える。候補の行は、所要の差（+12分・+1時間5分）が1時間を超えるかで折り返され、横棒グラフの長さが変わる。承認時の決定: アイコンは統一性が欲しい——ルート合成を含めコンパクトなまま文字入りのアイコンにする。ルート生成も同じで、パネルに出てくる全ボタンのUIを統一する。規模の根拠: 共通のButtonに文字入りアイコンの形を足し、page.tsx・RouteForm・RouteSettingsPanel・HardFilterPanel・RouteSplicePanelとそれらのテストを直すため、変わるファイルは8〜12でM。最初に、パネル（ルート設定・ルート結果・編集面）に出るボタンを機械的に列挙してから形を決める。
