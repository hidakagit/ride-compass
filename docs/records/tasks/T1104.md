# T1104. パネルのボタンを、コンパクトな文字入りアイコンのボタンへそろえる（ルート合成の入口を候補の中へ・クリアを全候補を消すと読める形へ・候補の行を所要の長さで崩さない）

状態: 完了（2026-09-25）

## 背景

ユーザー指摘（2026-09-25）: ルート結果内のアイコンが分かりにくい。ルート合成（区間の乗り換えの編集）の入口がタブの上の見出しにあるが、タブ（選んでいる候補）の中にあるべき。ゴミ箱アイコン（ルートをクリア）は選択中のルートだけ捨てるように見える。候補の行は、所要の差（+12分・+1時間5分）が1時間を超えるかで折り返され、横棒グラフの長さが変わる。承認時の決定: アイコンは統一性が欲しい——ルート合成を含めコンパクトなまま文字入りのアイコンにする。ルート生成も同じで、パネルに出てくる全ボタンのUIを統一する。規模の根拠: 共通のButtonに文字入りアイコンの形を足し、page.tsx・RouteForm・RouteSettingsPanel・HardFilterPanel・RouteSplicePanelとそれらのテストを直すため、変わるファイルは8〜12でM。最初に、パネル（ルート設定・ルート結果・編集面）に出るボタンを機械的に列挙してから形を決める。

## ボタンの列挙（2026-09-25）

母集団: `app/page.tsx`・`features/route/RouteForm`・`RouteSettingsPanel`・`HardFilterPanel`・`RouteSplicePanel`・`RouteAxisProfile`・
`components/BottomSheet`・`FloatingPanel`・`Disclosure`のJSXのうち`Button`・`button`・`Toggle`・`ToggleGroupItem`（正規表現で抜き出した）。
アイコンだけのボタンは、ルート結果の見出し（編集・GPX出力・クリア）と編集面（1つ戻す・全部戻す・差分を見る・新しいルートを作る）。
「ルート生成」は文字だけ。ほかは✕（閉じる・区間の選択の解除・経由地/目的地を消す）・‹（編集をやめる）・文字だけの小さな操作
（現在地に戻す・再試行・除外を既定に戻す）・トグル類と、地図の上のボタン（パネルの外）。

## 決定（ユーザー 2026-09-25、会話）

- 形は**アイコンの下に文字**（地図のチップと同じ並び）。
- **合成とGPXをタブの中へ**移し、見出しには全候補を消す操作だけを残す（GPX出力も選んでいる1本への操作のため）。
- 範囲: **✕と文字だけの操作は今のまま**。そろえるのはアイコンだけのボタンと「ルート生成」。

## 変更

- `Button`に`size="iconLabel"`（アイコンの下に短い名前）を足し、上の8つをこの形にした。見える名前は 生成／合成／GPX／全消去／
  1つ戻す／全部戻す／差分／作成。`aria-label`は見えている名前を含む形（ルート生成・ルートを合成・GPX出力・候補を全消去・差分を見る・
  新しいルートを作成）。生成中の進み（「生成中...(N秒経過)」）はボタンの名前と「ルート結果」の本文に出し、見える文字は「生成中」「順番待ち」。
  生成の印は新しいアイコン（`GenerateRoutesIcon`、実行の三角）——「ルート結果」のタブのアイコン（`RouteIcon`）と同じにすると区別できない。
- 「ルート結果」の見出しは「全消去」だけ。「合成」「GPX」は`renderCandidateActions(route)`がその候補のタブの中身の先頭に置く。
- 候補の中身の横棒（`RouteAxisProfile`の内訳バー）は、数値（総合難易度・所要・負荷）と同じ折り返しの行に入っていたため、所要が
  「58分」か「1時間5分」かでバーが数値の横へ入るか次の行へ落ちるかが変わり、長さが候補ごとに違っていた。数値の行とバーを分けた。
  起票時の見立て（候補の一覧の行の`+N分`）は違っていた——一覧の行の所要の差は常に「+N分」で、時間の単位へ繰り上がらない。
- 編集面の(i)の説明から「天秤は…その隣は…」を消し、差分の案内を「「差分」を押すと…」にした（名前が画面に出たため）。
- 設計書: `frontend-design-system.md`に「5-1. パネルの操作ボタンの形」を足し、`page-composition.md`・`route-settings-and-results.md`を
  今の置き場と形へ直した。
