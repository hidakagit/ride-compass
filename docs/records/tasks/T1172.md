# T1172. 事故データを、公開されている全年（2019〜2024年の6年分）取り込む

状態: 未完了（2026-09-26起票）

## 背景

T856-accidentへのユーザーのコメント（事故データが少ない。何年分集められるか・複数年度の設計）を受けた読み取りの調査（2026-09-26）。警察庁「交通事故統計オープンデータ」本票CSVは2019〜2024年の6年分が公開（2018・2025は404）、PDL1.0準拠で商用可・年数の制限なし。2019〜2021年は58列・2022〜2024年は68列だが、読む列は全年同名。今は source_profile.yaml の accident の years: [2024] の1行だけで絞っている（T977）。複数年の設計は既にある（自然キーに年、分母の年数は取込の記録から導く get_accident_years、材料は件数/km/年）。案A: 宣言を2019〜2024へ変え本番で取得→取込→派生（本番DBへ書くのでL、本番の操作はユーザー）。着手前に年をまたいだ二重計上（2024年ファイルに発生年2023の2,454件）を2023・2024年ファイルの突き合わせで確かめる段（S）を切る。見込み: 約60万件・事故のパーティション約0.8〜0.9GB（未計測）。決めること: 全6年か直近N年か／固定か最新年まで自動で追うか／地図の点も全年か／T856の事故軸の折れ点をこの後に回すか。起票案 proposal-accident-multiyear（2026-09-26承認）
