### 決めたこと（記録に残っていた選択。品質で決めた）

1. **全6年を取る**（直近N年にしない）。1年分では短い道の1件が偶然に左右される（T856-accidentの本文）。年を足すほど1本あたりの件数が
   増えて偶然が薄まり、6年で重なりは1件だけ。古い年の道の変化で外れる事故はありうるが、事故点は最も近い区間へ付けるので、道が
   残っていれば付く先は変わらない。容量は本番で+約0.8GB（下）で、空き26.4GBに対して小さい。
2. **年は宣言に書いた固定の並び**（最新年まで自動で追わない）。母集団の正本は宣言だけ（`source_profile.yaml`の冒頭）で、
   `source_runs.profile`に写って分母と地図の説明文の年になる。自動で追うと、取り込んだ時点の配布元の状態で母集団が決まり、
   リポジトリを読んでもDBに何年分が入っているか分からなくなる（開発DBと本番で黙って食い違いうる）。新しい年は宣言へ1つ足して取り直す。
   足すときはその年のファイルが開けること（`fetch_accident_csv.py`が確かめる）と、見る列（`domain/accident.py`の判定の列）が残っていることを見る。
3. **地図の点も全年**（コードを変えない。点のタイルは宣言を読まず、取り込んだ全行を出す）。点は、道の事故密度が何から数えられたかの根拠で、
   数える年と点の年がずれると「点が無いのに事故の多い道」「点があるのに少ない道」が出る。点の説明には発生年が出る。
   重さは実測した（開発DB、点の最も多いタイル。3回焼いた最速）:

   | タイル | 点 | 全年 | 2024年だけ |
   |---|---|---|---|
   | z12（地図に点が出る最も引いたズーム） | 18,607 | 353KB・1,377ms | 65KB・588ms |
   | z15 | 879 | 17KB・399ms | 3KB・85ms |

   z12の都心の1枚が約5.4倍になる。事故の点のレイヤーは既定でOFFで、焼いたタイルはディスクに残るため焼くのは世代ごとに1回。
   点が重いと分かったら、引いたズームでまとめて出す（点を間引く・数を出す）のが筋で、年を絞ることではない。
4. **T856の事故軸の折れ点はこの取込の後に回す**（記録どおり）。開発DBでも分布が大きく動いた（下）。測り直しの手順は下の「T856の測り直し」。

### T856の測り直し（本番の取込と派生の後）

T856-accidentの問いに答えるのに要る数（事故の無い道の割合・件/km/年の帯ごとの延長・事故のある道の長さの中央値・2つの折れ点での
難易度）を、本番DBの読み取りのセッションで測る。`measure_axis_saturation.py`は接続先を`settings.database_url`から取るため
`run_probe.py`では本番へ向かない。次のプローブをファイルに書いて、backendディレクトリから`python scripts/run_probe.py <ファイル>`で流す
（抽選率は環境変数`SAMPLE_PERCENT`、既定2%でT856の計測と同じ）。今の折れ点の行はmeasure_axis_saturationの事故の行と同じ値を出す（上の検算）。

```python
"""事故密度（件/km/年）の延長で重み付けた分布と、T856-accident の2つの折れ点で見た難易度（読み取りのみ）。"""
import asyncio, os, sys

import numpy as np
import sqlalchemy

sys.path.insert(0, os.environ["BACKEND_DIR"])
from app.batch._common import batch_session_factory  # noqa: E402
from app.infrastructure.road_graph_repository import RoadGraphRepository  # noqa: E402

MATERIAL = "accident_count_per_km_year"
SAMPLE_PERCENT = float(os.environ.get("SAMPLE_PERCENT", "2"))
OPTIONS = {"1 今の直線 [0→0,10→100]": ([0, 10], [0, 100]),
           "2 折れ線 [0→0,1→40,3→70,10→100]": ([0, 1, 3, 10], [0, 40, 70, 100])}


async def main():
    async with batch_session_factory(os.environ["PROBE_DATABASE_URL"]) as factory:
        async with factory() as session:
            await session.execute(sqlalchemy.text("SET default_transaction_read_only = on"))
            repo = RoadGraphRepository(session)
            years = await repo.get_accident_years()
            sample = await repo.sample_way_material_values(len(years), SAMPLE_PERCENT, 20_000, None)
    pairs = [(m, v[MATERIAL]) for m, v in sample if v.get(MATERIAL) is not None]
    lengths, raw = (np.array(c, dtype=float) for c in zip(*pairs))
    total = lengths.sum()
    print(f"収録年 {years} way {len(lengths):,}本 / {total / 1000:,.1f}km（抽選 {SAMPLE_PERCENT}%）")
    print(f"事故の無い道: 延長の {lengths[raw == 0].sum() / total:.1%}")
    for lo, hi in [(0, 1), (1, 3), (3, 10), (10, np.inf)]:
        sel = (raw > lo if lo == 0 else raw >= lo) & (raw < hi)
        print(f"  {lo}〜{hi} 件/km/年: 延長の {lengths[sel].sum() / total:.1%}")
    acc = raw > 0
    print(f"事故のある道の長さの中央値: {np.median(lengths[acc]):.0f}m")
    for name, (xs, ys) in OPTIONS.items():
        score = np.interp(raw, xs, ys)
        order = np.argsort(score)
        cum = np.cumsum(lengths[order]) / total
        qs = " ".join(f"p{round(q * 100)} {score[order][np.searchsorted(cum, q)]:.1f}" for q in (0.1, 0.5, 0.9, 0.99))
        print(f"{name}: 事故のある道の平均 {(score[acc] * lengths[acc]).sum() / lengths[acc].sum():.1f}"
              f" / 5以下 {lengths[score <= 5].sum() / total:.1%} / 95以上 {lengths[score >= 95].sum() / total:.2%} / {qs}")


asyncio.run(main())
```

測った数でT856-accidentの本文（「いまどうなっているか」「各選択肢で起きること」）を書き直し、答えを求める（T856の作業）。
