# T1085. 地図で段が落ちると、体感ラベルの上書きが件数不一致で黙って捨てられる

状態: 未完了（2026-09-23起票）

## 背景

T957の担当が挙げた範囲外の不一致2（ユーザー決定 2026-09-23: 起票する）。軸のしきい値のうち地図で段にならない値があると（backend/app/domain/axis_display.py の _map_band_thresholds）、体感ラベルの上書き（display_band_labels_override）の件数が地図の段数と合わなくなり、frontend の mapColorLegend.ts: bandLabelsForBandCount が上書きしたラベルを何も知らせずに捨てる（利用者が軸スタジオで付けたラベルが地図に出ない）。やること: どの段にどのラベルが当たるかを、落ちる値の判定（T957の thresholds_the_map_drops）と同じ規則から決める形にし、黙って捨てない（合わないときは軸スタジオで知らせる・保存時に揃える等。どれにするかは design-principles.md のUI原則と既存の配り方から決め、理由を記録に書く）。フロントに判定を写さない。完了条件: 落ちる値を含む軸で、上書きしたラベルが地図の凡例の各段に正しく当たる（または合わないことが画面で分かる）ことを、入力に対するあるべき値のテストで示す。frontend/e2e/ と playwright.config.ts は触らない。
