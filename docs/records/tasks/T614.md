# T614: 「ルート設定」パネルをタブ分割・入力欄圧縮・説明文のinfoアイコン化で高さを圧縮する

状態: 完了（2026-09-06）

## 背景

モバイル実機のスクリーンショットで、「ルート設定」BottomSheetが縦に長く、スクロールしないと
「除外する道路」「既定値に戻す」まで見えないことが判明した。ユーザー指摘: 「ルート設定パネル内
にタブ作ってもいいから、もう少し高さ低くて収まるようにしたい。あと距離や候補数が入力エリア
だけ変に大きい。説明内容を情報アイコンに収めたりとか工夫余地もありそう」。

## 対応方針（ユーザー確認済み）

- パネル内を2タブに分割する:
  - 「生成条件」: 周回/目的地トグル・距離・候補数（コンパクトな1〜2行）
  - 「重みづけ」: 重み配分バー・8軸チップ・除外する道路・既定値に戻す
  - 「ルート生成」ボタンはタブの外・パネル下部に常時表示にする（重みづけタブを見ている間も
    タブを行き来せず押せるようにするため）。
- 距離・候補数の入力欄を圧縮する（幅を数字2〜3桁分まで縮小・中央寄せ・横1行に並べる）。
- 「重み配分[帯の境界をドラッグして配分を調整できます]」の操作説明文を、見出し脇の
  既存(i)アイコン（凡例ポップオーバー）内へ移し、見出しは「重み配分」だけにする。

## 実装内容

- `RouteForm.tsx`: `Tabs.Root`（`@radix-ui/react-tabs`）で「生成条件」「重みづけ」の2タブを
  ホストする。両タブとも`forceMount`＋`data-state`表示切替（page.module.cssの
  `.outcomeTabPanel`と同じ方式）とし、`RouteSettingsPanel`のローカルstate（チェックOFF前の
  重み記憶等）がタブ切替のたびに失われないようにした。新規propの`weightsPanel`で
  「重みづけ」タブの中身（`page.tsx`から渡す`renderRouteSettingsSectionBody()`）を受け取る。
  「ルート生成」ボタン・エラー表示はタブの外・`<form>`末尾に常時表示し、どちらのタブを
  見ていても押せるようにした。
- 距離・候補数の入力欄を横1行に並べ、幅を`w-16`/`w-12`（内容に対して余裕を持たせつつ
  従来の`w-24`/`w-16`より圧縮）・`text-center`にした。
- `RouteSettingsPanel.tsx`: 「重み配分[帯の境界をドラッグして配分を調整できます]」の
  見出しを「重み配分」だけにし、操作説明は既存の(i)アイコン（凡例ポップオーバー）の
  先頭行へ移した。
- `page.tsx`: `renderRouteSectionBody`が`renderRouteSettingsSectionBody()`を`RouteForm`の
  `weightsPanel`propへ渡す形に変更（従来は`RouteForm`の後にsiblingとして並べていた）。
- ドキュメント追従: `docs/modules/frontend/route-settings-and-results.md`
  （`RouteForm.tsx`のタブホスト責務・重み配分見出しの説明を更新）、
  `docs/modules/frontend/page-composition.md`（モバイル「ルート設定」シートの説明を更新）。
