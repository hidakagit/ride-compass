# T509: 標高図をサイドバー「地図の見え方」パネルから除外

状態: 完了（2026-08-31）

## 背景

ユーザー指摘: 「地図の見え方」パネル（サイドバー、`MapLayersPanel`）に「標高図」
（`elevation`）が載っているが、これはラスタタイル（国土地理院配信）のため他レイヤー
（路面の種類・道路の種類・指定路線等）のような凡例ベースの絞り込みができず、
`MapLayersPanel.tsx`の実装（`renderSectionBody`の`case "elevation"`）も説明文のみで
設定項目を一切持たない。ON/OFFの単純な切替は地図上チップ（`MapOverlayControls`）側で
既に完結しており、サイドバーへ重複掲載する意味が無い。地図上チップのON/OFF自体は
引き続き必要（撤去対象ではない）。

## 対応方針

`MapLayerDescriptor`に`hideFromLayersPanel?: boolean`を新設した。既存の
`dataNature==="dynamic"`（降水ナウキャスト・風・雷・竜巻等、帯単位の絞り込み機能を
持たないレイヤーをこのパネルから除外する、2026-08-25ユーザー判断）と同じ理由だが、
`dataNature`を再利用しなかった——`dataNature`は「データの性質」（生/合成/時々刻々
変わる）を表す別概念のフィールドで、`elevation`は静的なラスタタイルのため
`"dynamic"`に当てはめると意味が食い違う。

`elevation`のみ`hideFromLayersPanel: true`を設定し、`MapLayersPanel.tsx`の行フィルタへ
`!layer.hideFromLayersPanel`条件を追加した。`renderSectionBody`の`case "elevation"`
（到達不能になった死コード）も削除した。

なお「環境」（terrain/weather）カテゴリに属するレイヤーは、elevation以外すべて
`dataNature="dynamic"`のため、この変更で「環境」グループの掲載レイヤーが0件になり、
グループ見出し自体がこのパネルから消える（`layers.length === 0`のグループを描画しない
既存分岐、副作用ではなく正しい帰結）。地図上チップ（`MapOverlayControls`）側の
「環境」グループ・標高図アイコンのON/OFFには一切影響しない。

## 実装メモ

- `frontend/src/components/Map/mapLayers.ts`: `MapLayerDescriptor.hideFromLayersPanel`
  フィールド新設、`elevation`descriptorへ設定。
- `frontend/src/components/MapLayersPanel/MapLayersPanel.tsx`: 行フィルタへ
  `!layer.hideFromLayersPanel`を追加、`renderSectionBody`の`case "elevation"`
  （死コード化）を削除。
- `frontend/src/components/MapLayersPanel/MapLayersPanel.test.tsx`: elevation関連の
  既存アサーションを更新（グループ見出しが「道路/スポット」のみになる・elevationの
  セクションが存在しない等）。elevation自身を例に使っていたON/OFFチップ操作系の
  2テストは、パネルに引き続き掲載される他レイヤー（`tunnel`）を使うよう差し替えた。
