# T597: デスクトップのサイドバーをモバイルと同じ3区分にし、ルート結果ヘッダに保存・GPX出力の操作枠を確保する

状態: 完了（2026-09-05起票・同日完了、分割元は[T590](T590.md)）

## 背景

デスクトップは「A. ルートを作る（設定＋結果を内包）」「B. 地図の見え方」の2段
（`page.tsx`のDisclosure構成）、モバイルは「ルート設定 / ルート結果 / 地図の見え方」の
3タブで情報設計が食い違う。将来のルート保存・参照・GPX出力（ユーザー要望2026-09-05）の
置き場も先に決めておく。

## 対応方針

- デスクトップのサイドバーを3区分（ルート設定 / ルート結果 / 地図の見え方）のフラットな
  Disclosureにし、モバイルの3タブと同じ順序・同じ見出しにする。両端末で説明が1種類で済む。
- ルート結果ヘッダの操作群（現状「ルートをクリア」と説明アイコン）を横並びの操作枠として
  固定し、「保存」「GPX出力」のアイコンを並べられる余地を作る。本タスクでは枠の確保と
  レイアウトだけを行い、機能は別途起票する（未起票。着手時に保存先[ローカル/サーバー]・
  GPX仕様を決めてから採番する）。
- 保存済みルートの参照は候補タブ列の先頭に固定タブ「保存済み」として置く設計とする。
  3区分は増やさない。本タスクではタブ列が先頭固定タブを持てる構造（`Tabs.Root`の
  value体系）にしておく。
- おすすめ度は撤去済みのため、ルート結果の先頭は総合難易度のみ。

## 対象ファイル

`frontend/src/app/page.tsx`（`renderRouteSectionBody`・`renderRouteOutcomeSectionBody`・
サイドバーのDisclosure構成）・`components/BottomSheet/`（変更なしの見込み）・
`docs/modules/frontend/`該当モジュール。

## 完了条件

- デスクトップとモバイルで区分の名前・順序・中身が一致する。
- ルート結果ヘッダに操作アイコンを追加しても再レイアウトが不要な構造になっている。

## 実装メモ（2026-09-05）

- ユーザー判断: 保存・GPX出力は実装までグレー（disabled）で位置だけ見せる。候補タブの
  表記は「順位番号 距離km」だけにする（方位・難易度はタブの中身に出る）。
- `page.tsx`: デスクトップのサイドバーを「ルート設定 / ルート結果 / 地図の見え方」の
  3つの`Disclosure`へ再編（開閉状態は`generateOpen`/`outcomeOpen`/`mapSettingsOpen`で永続化）。
  `renderRouteSectionBody`はルート設定のみ、`renderRouteOutcomeSectionBody`は見出しを
  持たず本文だけを返す（`showHeading`引数を撤去）。「ルート結果」区分は候補が無い間も
  出し、本文に案内文を置く。
- ヘッダ操作枠: `renderRouteResultHeaderActions()`を「保存」「GPX出力」（`SaveIcon`/
  `DownloadIcon`、disabled）→「ルートをクリア」→説明アイコンの横並びにし、デスクトップは
  `Disclosure.trailing`、モバイルは`BottomSheet.headerAction`から同じものを使う。
- タブ列: `SAVED_ROUTES_TAB_VALUE="saved"`を予約し`onValueChange`で無視する（先頭固定タブ
  自体は保存機能の実装まで描画しない）。
- 検証: `page.test.tsx`・`e2e/smoke.spec.ts`のタブ名期待値を更新。vitest全件・eslint・tsc
  （`layout.tsx`の既知エラー除く）green。実機確認（デスクトップ・モバイル両方で区分の
  名前・順序が一致すること）はPlaywright headlessのsmokeで担保。

## 追記（2026-09-06、T613で是正）

完了条件「デスクトップとモバイルで区分の名前・順序・中身が一致する」を満たしていなかった。
モバイルの「ルート設定」タブは`RouteSettingsPanel`のみで、`RouteForm`（周回/目的地選択・
距離・生成ボタン）はT250由来の常時表示バー（`mobileActionBar`）に取り残されたままだった
（本タスクでは見出しの3区分化のみ確認し、区分の中身の一致までは検証していなかった）。
[T613](T613.md)で`mobileActionBar`を廃止し、モバイルもデスクトップと同じ
`renderRouteSectionBody()`（`RouteForm`+`RouteSettingsPanel`）を「ルート設定」タブから
呼ぶ形へ是正した。
