# T544: 重み配分バーのドラッグ中バッジに軸ラベルを併記する

状態: 完了（2026-09-02）

- 背景: `RouteSettingsPanel.tsx`の「重み配分」スタックバー（帯の境界をドラッグして
  軸間の重みを再配分するUI）で、境界のハンドルをドラッグ中に浮かぶバッジが
  「15% / 13%」のように数字2つを`/`区切りで並べるだけで、どちらの数字がどちらの軸を
  指すのか分からないというユーザー指摘（実機確認）。
- 対応: `left.label`/`right.axis.label`をバッジへ併記し「勾配 15% / 舗装質 13%」の形へ
  変更（`RouteSettingsPanel.tsx`）。ラベル併記で文字幅が増え、バー両端付近のハンドルでは
  センター寄せ（既定の`left:50%; transform:translateX(-50%)`）のままだとバッジが
  パネル外へはみ出すことをBrowserペイン実機確認で発見・修正した。境界の累積%
  （`cumulativePct`）が25%未満/75%超のときは`data-align="start"`/`"end"`を付け、
  CSS側で端寄せ（`left:0`または`right:0`、`transform:none`）へ切り替える
  （`RouteSettingsPanel.module.css`）。
- 検証: `tsc --noEmit`・`eslint`・`RouteSettingsPanel.test.tsx`（13件）すべてgreen。
  ドラッグ中バッジ自体は既存テストが無かったため、Browserペインで実際に
  PointerEvent（pointerdown→pointermove、releaseせず）をディスパッチしてDOM上の
  バッジ文言を直接確認する形で検証した（左端「勾配 17% / 舗装質 11%」・右端
  「自転車インフラ 10% / 風 24%」いずれもパネル内に収まることを実機確認）。

## 追加修正（2026-09-02、同日ユーザー報告）

モバイルのBottomSheetでは「重み配分」がシート見出し（`BottomSheet-module: .header`）
直下の最初の要素になり、見出し下端との隙間が約6px しか無かった。ラベル併記で高さが
増えたドラッグ中バッジ（帯の上に浮く、必要な上方向のクリアランスは実測で約29px
[バッジ高さ約25px＋margin-bottom 4px]）が見出しへ約10px重なり、「ラベルの上部分が
見切れる」という新たな指摘を受けた。`.stackBarWrap`（`RouteSettingsPanel.module.css`）へ
`margin-top: 24px`を追加して解消した。モバイル（640px以下）では`--space-4`トークン自体が
`globals.css`のメディアクエリで0.75rem=12pxまで圧縮されクリアランスを確保しきれないため、
このケースに限りトークンを使わず固定pxにした。Browserペインでモバイル実機（375×812）の
座標を直接計測し、修正前（バッジ上端388.6px・見出し下端399px、約10px重なり）→
修正後（バッジ上端412.6px、約13.6pxの余白）を確認した。デスクトップ表示（見出しとの
隙間に元々余裕がある）への影響も実機確認済み（不自然な余白なし）。
