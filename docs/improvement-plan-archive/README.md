  分からない場合は、このファイル末尾の完了タスク一覧（旧・改善計画末尾の「記録」表を

## 現在の「正」への注意

この改善計画（本体＋アーカイブ）は**変更履歴**であり、「評価軸は現在何本か」
「地図レイヤーは何種類か」のような値は、書かれた時点のスナップショットに過ぎず
何度も更新されている（例: 評価軸は本アーカイブ内だけで7軸→8軸→9軸→8軸→7軸→6軸+windと
変遷している）。現在の値は常に一次情報（`docs/architecture.md`）を参照すること。
過去の記述をもって「矛盾している」と判断しない——それぞれの記述はその時点では正しかった。
