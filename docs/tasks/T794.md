# T794. 重みタブの見出し・合計表記・既定値ボタンを落とす

規模S。
状態: 完了（2026-09-13、[T788](T788.md)の続きの実機フィードバック。採番はT792で確保しようと
したが並行セッションが先に使ったため振り直した）

## 背景

帯グラフは色と%が入った1本で、それ自体が「重み配分」であり「全体で100%」であることを
示している。見出し「重み配分」・その脇の(i)・右端の「合計 100%」は、その言い換えでしかない。

「重みを既定値に戻す」ボタンは、いずれプロファイル機能（[T307](T307.md)）が代替する。
既定値へ戻す操作は、プロファイルの1つとして選ぶ形になる。

同じ流れで見出し行そのものの整理も入れた（ユーザー要望「条件、重み、除外を左寄せに
できる？ ルート生成となるべく区別したい。できれば見た目を変えてタブっぽくしたい」）。
タブは中身を切り替えるもの、「ルート生成」は押して走らせるもので役割が違う。

## 対応

- 見出し行（ラベル・(i)・合計表記）を撤去し、タブの先頭を帯グラフにする。
- 「重みを既定値に戻す」ボタンを撤去する（行き先は[T307](T307.md)）。
- タブ列を見出しのすぐ右（左寄せ）へ、「ルート生成」を行の右端へ分ける。デスクトップは
  `Disclosure`の`trailing`の中で左右に分け、モバイルは`BottomSheet`へ`headerLead`
  （見出しのすぐ右）を新設してタブを渡す。
- タブの見た目を下線型にして、塗りのボタンと区別する（globals.cssのbutton既定の枠・背景・
  角丸を打ち消す必要がある）。
