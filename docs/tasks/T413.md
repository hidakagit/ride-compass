# T413. サイドバー「地図の見え方」パネルの語彙をチップ側の4分類へ統一するか検討

状態: 完了（2026-08-30）

- 背景: T406（[T406.md](T406.md)）で地図オーバーレイのチップ側（`MapOverlayControls.tsx`）は
  「道路/評価軸/環境/スポット」の4分類へ再編したが、サイドバー「地図の見え方」パネル
  （`frontend/src/components/MapLayersPanel/MapLayersPanel.tsx`）は対象外のまま「観測/推定」
  の旧2見出しが残っていた（T406.md「積み残し」節参照）。同じアプリ内でチップとサイドバーの
  語彙が食い違っている状態だった。

## 実装内容

- 決定: サイドバーもチップと完全に同じ`mapOverlayGroupFor`（`frontend/src/components/Map/
  mapLayers.ts`）を単一ソースとして使う方式へ統一した（「別の統一案」は検討せず、既にチップ側
  T406が確立していた4分類へ素直に揃える最小の対応とした）。
- `mapLayers.ts`:
  - `MAP_LAYER_DATA_NATURE_LABELS`・`MAP_LAYER_DATA_NATURE_ORDER`・
    `MAP_LAYER_DATA_NATURE_CHIP_LABELS`の3定数を削除（サイドバー以外に消費者がいないことを
    grepで確認済み、T406完了時点で`MAP_LAYER_DATA_NATURE_CHIP_LABELS`は既に未使用の死んだ
    コードになっていた）。
  - `MapLayerDataNature`型自体（"raw"|"composite"|"dynamic"）は残す。(a) `mapOverlayGroupFor`が
    "composite"を「評価軸」グループ判定の入力に使う、(b) サイドバー側が"dynamic"（降水
    ナウキャスト等、帯単位の絞り込み機能を持たないレイヤー、ユーザー判断2026-08-25）を
    詳細セクションから除外する判定に引き続き使う、の2点で必要なため。
  - `MAP_OVERLAY_GROUP_LABELS`・`category`/`dataNature`フィールドのdocコメントを、
    現在の役割（グルーピングの入力）に合わせて更新。
- `MapLayersPanel.tsx`:
  - `MAP_LAYER_DATA_NATURE_ORDER.map(...)`による2グループ（観測/推定、動的は最初から除外）の
    列挙を、`MAP_OVERLAY_GROUP_ORDER.map(...)`による4グループ（道路/評価軸/環境/スポット）の
    列挙へ書き換えた。
  - 「評価軸」グループ（旧composite）は従来どおり`secondaryAxes`props駆動の並び順
    （`orderedCompositeEntries`）をそのまま使う——地図チップの評価軸グループと同じ横並び順。
  - 「道路」「環境」「スポット」グループは、`mapLayers`props全体に対し`mapOverlayGroupFor`で
    そのグループと判定され、かつ`dataNature !== "dynamic"`（絞り込み機能を持たないレイヤーの
    除外、2026-08-25の既存方針を継続）のレイヤーを、`MAP_LAYER_CATEGORY_ORDER`の順で列挙する。
  - グループの表示順は`MAP_OVERLAY_GROUP_ORDER`（道路→評価軸→環境→スポット）をそのまま使う。
    以前の「パネル内だけ観測→推定へ反転」という専用ロジックは廃止した——「道路」が
    `MAP_OVERLAY_GROUP_ORDER`上も評価軸より先に来るため、反転していた元の意図
    （観測指標を推定指標より上に）は自然に満たされる。
  - **結果として起きたレイヤーの再分類**（表示上の変化）: 従来はcar_stress（評価軸）以外の
    全レイヤーが単一の「観測データ」見出しの下に一緒くたに並んでいた。今回の統一で、
    標高図（terrain）が「道路」から独立して「環境」見出しへ、停止要因POI・補給POI・事故
    （trafficSafety/amenity）が「道路」から独立して「スポット」見出しへ、それぞれ分離された
    （道路の純粋な属性——道路種別・路面種別・指定路線・トンネル・一方通行——のみが
    「道路」見出しに残る）。表示されるレイヤー自体の増減は無い（dataNature="dynamic"の
    レイヤーは従来どおり非表示のまま）。
- CSS: `.natureGroup`/`.natureTitle`を`.overlayGroup`/`.overlayGroupTitle`へリネーム
  （旧「次数」概念がこのパネルの分類単位ではなくなったため）。
