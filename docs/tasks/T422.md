# T422. 「環境」グループに合成面データ用のプレースホルダー構造を用意する（T400節1の未実装分）

状態: 未着手（起票のみ、2026-08-30・T400.md全体の再監査で発見）

- 背景: [T400.md](T400.md)「1. パネルの最上位グルーピング」節に「『環境』グループの
  『推定』枠（対象データを軸スタジオ的に合成した面データ）は現状空だが、将来増える可能性を
  見込み構造だけ用意しておく」という決定があったが、[T406](T406.md)の実装ではこの
  プレースホルダー構造が作られていない（`mapLayers.ts`・`MapOverlayControls.tsx`の
  環境グループは標高図・降水ナウキャスト等の生データのみで構成されており、将来の合成面
  データ用の枠が無い）。T400.md本文には「（ユーザー: 『わからない。今まだ研究段階だから
  断定できない』）」という注記があり、優先度が低いまま実装時に見落とされたと見られる。
- 影響: 現時点では実害なし（環境グループに合成面データ自体が存在しないため、枠が無くても
  何も困らない）。ただし将来、環境グループ向けの合成面データ（例: 複数の気象材料を合成した
  指標等）を追加する際、この構造が無いまま「道路グループの評価軸と同じ扱いにする」等の
  場当たり対応になるリスクがある。
- 対応方針（未検討）: 優先度は低い。環境グループに実際に合成面データを追加する具体的な
  ニーズが出た時点で、改めて構造を設計するのでも間に合う可能性がある——着手前に
  「今すぐ構造だけ用意する」か「実際のニーズが出るまで待つ」かをユーザーへ確認すること。
