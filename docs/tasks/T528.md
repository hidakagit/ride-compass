# T528: 未使用依存@radix-ui/react-radio-groupの削除

状態: 未着手（2026-09-01起票、T524見送り分の追跡）

- 背景: T518で`renderRouteColorSectionBody`（RadioGroup.Rootを使った色分けモード
  選択UI）を削除した結果、`@radix-ui/react-radio-group`（`frontend/package.json`）が
  frontend/src内から一切参照されなくなった（grep確認済み）。
- 見送った理由: T524実施時、別セッションが`frontend/package.json`を並行編集中
  だった（`@vitest/coverage-v8`の追加、未コミット）ため、衝突を避けてこのタスクでは
  package.jsonへ触れなかった。
- 対応方針: `package.json`の`dependencies`から`@radix-ui/react-radio-group`を削除し、
  `npm install`で`package-lock.json`を更新する。他にfrontend/src内で参照が
  無いことを再度grepで確認してから実施する（着手時点で新たな利用が追加されていない
  か念のため確認）。規模は小さいため、他のpackage.json変更が無いタイミングで
  片付けてよい。
