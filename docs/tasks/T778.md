# T778. 下部シートの既定の高さを中身へ合わせる 規模S

状態: 未着手（2026-09-12起票、[T769](T769.md)の実測から）

## 背景

`BottomSheet`は`DEFAULT_SHEET_HEIGHT_VH = 50`で高さを固定しており（ドラッグで20〜80vhへ
変えられ、値は保存される）、**中身の量に依らない**。390×812での実測では「ルート結果」の
中身は302pxなのにシートは406pxで、104px＝画面の13%が空いたまま地図を覆っている。

[T773](T773.md)〜[T776](T776.md)で中身を444px→194pxまで削ったが、**画面上は何も変わって
いない**（空白が増えただけ）。中身を減らす作業は、この既定値を中身へ合わせない限り
利用者に届かない。

## 保留することで何が起きうる

- 中身を減らすタスク（[T760](T760.md)等）の効果が、実機では一切見えないまま積み上がる。

## 判断が要る点

- 中身へ自動追従させると、候補の切り替え・区間クリックのたびにシートの高さが動く。
  走行中に地図を見ている最中の上下動が許容できるかは実機で見ないと分からない。
- 折衷案: 開いた時点の中身に合わせ、開いている間は変えない。
- 最も単純な案: 既定値を静的に下げる（例: 50→38vh）。中身が増えたシートはスクロールになる。
