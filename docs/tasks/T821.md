# T821. 同じ規則が複数箇所へ書き写されている箇所を1つへ寄せる

規模M。
状態: 未着手（統合レビュー第8回のP2/P3を束ねたもの、2026-09-13）

## 背景

**同じ理由で変わるものが分かれて書かれている**箇所。`review_checks.py duplication`
（完全一致のクローン検出）は17件で前回23件から減っているが、**下記はいずれも1件も
捕まっていない**——値の直書き・組み立て規則の手書き・処理順序の写しは原理的に検出できない
（`complexity.md`「写経の監視」3項）。

## 対象

- `services/road_graph_engine.py:374-377`: 停止の待ちが読む材料idを`f"poi_{kind}_per_km"`と
  インラインで組み立てている。同じ規則は`domain/traffic.py:154-161 stop_count_material_ids()`が
  「単一ソース」として持つ。綴りを`traffic.py`側で変えるとここだけが`None`を引き、
  **全区間の停止の待ちが無言で0秒になる**（例外も出ず、既存テストは軸のスコアしか見ていない）
- `hooks/useDynamicWeatherLayers.ts:132-134, 383-389`: 災害グループのソースキー文字列が
  `page.tsx`の`DISASTER_SOURCE_LEGEND`（297-305）・フェッチ有効判定の配列リテラル・
  `dynamicWeather.disaster`の3箇所へ独立に手書き。`readonly string[]`なので型でも守られず、
  片方を改名すると**チェックを外しても面が消えなくなる**
- `components/WeatherPanel/amedasWeatherIcon.ts:32-59` と `weatherCode.ts:60-97`
  （＋`weatherCode.test.ts:11-22`）: 天気カテゴリの日本語ラベルと「晴れだけ昼夜でアイコンを
  替える」規則の二重化。常設ヘッダー（アメダス実測）とその真下の「今日の見通し」（MSM予報）が
  同じアイコンに別の語を出しうる
- `Map/roadFilterAxes.ts:30-33` と `page.tsx:1001-1050`: 「ROAD_FILTER_AXESへ1つ足すだけでよい」と
  書きながら、UI側は`ROAD_LINE_COLOR_AXIS_ID`/`ROAD_LINE_WIDTH_AXIS_ID`の2軸を名指しで配線し、
  summary/legendDetailsの2ブロックが丸ごと写経になっている
- `Map/staticAttributeLayers.ts:161-228`: tunnelとonewayの「真偽値プロパティ→凡例・色式・
  不透明度式」3点セットが逐語コピー。文字列列挙用の`buildCategoricalLayerDefs`に相当する
  真偽値版ビルダーが無い
- `AxisStudio/breakpointTools.ts:58` と `scoreDistribution.ts:32`: 区分線形補間（backendの
  `evaluate_breakpoint_linear`と同じ規則）が別実装で2つあり、丸め（小数1桁／丸めなし）と
  `x1===x0`時の返り値（y0／y1）も食い違う
- `domain/evaluation.py:672-689, 745-750`: `axis_weighted_sums`の項の作り方が
  `compose_costs_from_axis_matrix`の本体と同じ式で二重に書かれている（docstring自身が
  「同じ式で保つ」と手動同期を前提にしている）
- `RouteAxisProfile/RouteAxisProfile.tsx:74` と `AxisContributionBar.tsx:53-56`:
  「`axisContributions`がnullまたは0の軸を除く」判定が両方にあり、コメントが
  「判定がずれないよう同じ条件にする」と手動同期を前提にしている
- `app/page.tsx:2418-2422` と `page.module.css:227-233`: dirty印のドットが
  CSS ModulesとTailwindの任意値の2通りで書かれている（CSS側のコメントが二重管理を認めている）
- `services/healthApi.ts:4-15`: `services/`配下で唯一`lib/fetchJson.ts`の共通骨格を通らず
  素の`fetch`＋`catch {}`。backend疎通の失敗・タイムアウトがdebugLogへ一切残らない
  （`fetchJson.ts:4-12`が「骨格を写経すると非対称が静かに生まれる」と警告している当のパターン）
- `app/page.tsx:129`: `DISTANCE_TOLERANCE_KM = 5`がbackendの既定値（`routes.py:149`）の
  手書き複製。`route-generate-config.json`に対応項目が無いため生成物経由にできていない
  （**生成物側へ足すのが本筋**）
- `AxisStudio/scoreDistribution.ts:73`: `distributionWarnings`が帯を`b.label === "100点"`という
  **表示ラベル文字列**で引いている。ラベルを言い換えた瞬間に警告が一切出なくなる
