# T909. 一時停止・車止めのある無信号交差点で、待ちを二重に数える

規模M。
状態: 未着手（2026-09-16起票。[T906](T906.md)の実施中に、その場で直せない規模と分かって分離）

## 背景

ターンの費用は「信号が無いのに上位の道を渡る」ときだけ`major_crossing_seconds`を足す
（[T800](T800.md)）。信号については`road_nodes.has_traffic_signals`で除外できるが、
**一時停止・車止め（barrier）のある交差点は除外できない**——その待ちは停止密度の材料が
走行モデルへ運んでおり（`domain/traffic.py: stop_seconds`）、同じ待ちを2回数えている
（`docs/design-principles.md`構造仕様13）。

[T906](T906.md)で「そもそも待ちの要る階級か」（`MAJOR_CROSSING_MIN_RANK`）を判定へ足したため、
**生活道路・サービス道路との交差では起きなくなった**。残るのは tertiary 以上の道を
一時停止で渡る場合で、そこは実際に待つ場所でもあるため、どちらの秒数が正しいかは
較正の話になる。

## なぜT906で直さなかったか

除外には**ノード単位で「停止要因があるか」**が要る。いまあるのは`road_nodes.
has_traffic_signals`だけで、停止要因は`osm_raw_pois`にEdge単位の集計として入っている。
[T800](T800.md)が信号に対して行ったのと同じ形——**列の追加（migration）＋事前集計バッチ＋
本番バックフィル**——が必要で、コメントやdocstringの是正と同じコミットに収まらない。

## 保留することで何が起きうるか

一時停止のある交差点を渡る経路が、実際より不利に評価され続ける。**利用者からは
「なぜこの道を避けるのか」が説明できない**——どちらの秒数も画面に出ないため、内訳を見ても
二重に数えていることが分からない。

## 対応方針

### 直す場所と、そこまでの配線

除外は`domain/routing.py`の1箇所にある——`crosses_major`（自分より上位の道を渡る・かつ
待ちの要る階級）から、信号のあるノードを`& ~node_has_signal[...]`で落としている。ここへ
停止要因を足す。値がそこへ届くまでの経路は信号と同じで:

`road_nodes`の列 → `RoadNodeRow` → `domain/graph.py`のNode → リポジトリの読み出し →
`road_graph_engine.py: _node_signals_and_ranks`がノード順の配列にする → `routing.py`

### 判定する種別は手書きしない

停止要因の種別は`domain/traffic.py: POI_COUNT_KINDS`（`StopPoiKind`）が単一ソースで、
1回あたりの秒数は`stop_seconds(kind)`が宣言から引く。**種別名をSQLへ並べ直さない**
——並べた側だけが古くなり、種別を1つ足したときに「材料としては数えるが交差点では除外
されない」という食い違いが静かに生まれる。既存の信号判定SQL
（`road_graph_repository.py`）は`traffic_signals`と信号付き`crossing`を見ているので、
新しい判定は**そこから漏れる種別のうち秒数を持つもの**を対象にする。

### 未決（着手時に決める）

1. **列を足すか、既存列の意味を広げるか**。`has_traffic_signals`は現状このターン費用の
   除外にしか使われていないため、「待ちが停止密度の材料として既に数えられているか」という
   1つの意味へ広げれば列は増えない。別の意味で使う予定があるなら列を分け、
   `_node_signals_and_ranks`の側で論理和にして`routing.py`へは1配列だけ渡す
   （`routing.py`が2つのフラグを知る必要は無い）。
2. **どちらの秒数を残すか（較正）**。停止密度側の`stop_seconds`が正で交差点側を落とす、が
   自然だが、実走の感覚と突き合わせてから決める（[T805](T805.md)が管理画面から値を変え
   られるようにする話と関わる）。**この判断は実装の構造を変えない**——上記1の配線は
   どちらに決まっても要る。

### 完了条件

- migration（列追加）・バッチ（`precompute_road_node_intersections.py`が同じ経路で埋める）・
  除外条件の配線
- **本番バックフィル**（[T800](T800.md)が信号に対して行ったのと同じ。列を足しただけでは
  全ノードが既定値のままで、除外は一切効かない）
- 二重計上が消えたことを、tertiary以上を一時停止で渡る実在の経路で確認する
