# T956: 材料の受け取りを行から列へ寄せ、Python側の組み立てを無くす

状態: 未着手（2026-09-19起票）

## 背景

材料は列指向（`EdgeMaterialTable`）で持つのに、DBからは1行ずつ受けてPythonで列へ詰めている。
`array_agg`で列ごとの配列として受ければ、Pythonが触るのは区間数×列数ではなく列数になる。

本番コンテナ内の実測（z12/3638/1612、42,144区間・25列）:

| | 取得 | Python側 | 合計 |
|---|---|---|---|
| 行で受ける（現行） | 2,033ms | 849ms | 2,883ms |
| 配列で受ける | 1,956ms | **22ms** | 1,978ms |

Python側が38倍速くなる。取得は変わらない（DB側の仕事が増えるぶんと転送が減るぶんが相殺）。

**これは[T955](T955.md)の主犯ではない。** 本番のログは1タイル8〜10秒で、この経路は2.9秒。
性能の解決策としてではなく、**Pythonが持つ複雑さを減らす**ものとして起票する
（ユーザー方針「DBから返す値をPythonで扱いやすい形にする」「Pythonの領域を減らす」）。
