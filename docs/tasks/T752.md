# T752. 周期レビューの個票を、起票したタスクが参照できる形で残す

規模S。
状態: 未着手

## 背景

統合レビュー第7回は、P2（28件）・P3（40件）について「件数が多いため分類のみを示し、
個票は各シャードの出力に残る」と書いた。しかしシャードの出力はAgentの実行結果で、
ファイルとして残っていない。結果として、起票した束ねタスク
（[T735](T735.md)〜[T742](T742.md)）の**対象を後から復元できない**——全体の要約に名前が
挙がった数件だけが手掛かりで、残りは件数しか分からない。

「何件ある」と書いてあるのに中身が無い状態は、タスクを閉じるときに「全部やった」と
言えるかどうかを判定できないという形で効く。

## 対応方針

`.claude/commands/review/all.md`は「allの結果ファイル内には実測値のサマリのみを含める」
「個別ファイル5本を別途保存する必要はない」と述べているが、**起票の根拠になる個票は
サマリではない**。P0/P1と同じ粒度で全件を残すか、P2/P3はシャード出力をそのまま
`history/YYYY-MM-DD_all_shards.md`等へ連結して保存するかを決める。

分量が理由なら、後者（生の連結）でよい——読み物として整える必要は無く、起票したタスクが
「対象はこれ」と指せれば足りる。
