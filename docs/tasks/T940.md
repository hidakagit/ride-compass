# T940. 較正値`evaluation.penalty_strength`の`RESTART`が実現不能で、管理画面は効かない値を「効いている」と表示する 規模S

状態: 完了（2026-09-19起票・完了、統合レビュー第11回）

## 背景

`DEFAULT_PENALTY_STRENGTH`はモジュールimport時に1回だけ評価されるが、DBの上書きを重ねる
`refresh_tuning_values`はlifespan（全import完了後）で走る。再起動しても同じ順序を繰り返すため、
`TuningEffect.RESTART`という宣言がこの起動順序では実現できない。

詳細は[history/2026-09-19_all.md](../../.claude/commands/review/history/2026-09-19_all.md)。

## 対応方針

`TuningEffect`の宣言そのものは正しい設計で、問題は`RESTART`という効き方がこの起動順序では
実現できない点にある。

1. `evaluation.penalty_strength`を`IMMEDIATE`へ移し、**リクエスト処理時に`tuning_value()`から読む**。
   APIスキーマの既定は未指定を許し、サービス側で解決する。
2. フロントが送る値は現在ビルド時生成物の既定（0.7固定）。`CLIENT_RELOAD`として配るか、
   そもそもフロントから送らないかを決める。
3. **`TestReachesTheConsumers`の母集団を`TUNING_PARAMETERS`から導出する**。このテストは
   docstringで「届かない値が混ざっていると、管理画面から変えても何も起きない」とこの欠陥を
   目的として宣言しているのに、検証する消費者が手書きの6ケースだったため、
   **唯一実際に届かない1件だけがテストの外**にあった。

## 実装メモ

`RESTART`は`TuningEffect`から削除した。「プロセスを入れ替えれば効く」は**この起動順序では
どの値についても成立しない**ため、効き方の選択肢として残すと次に同じ宣言が書かれる。

`DEFAULT_PENALTY_STRENGTH`（モジュール直下の束ね）を`resolve_penalty_strength(requested)`へ
置き換え、省略されたときだけ`tuning_value()`を読む。解決はDI工場（`_assemble_route_generation_setup`）で
1度だけ行い、探索へ渡す値とレスポンスの`conditions`へエコーする値を同じにした（画面が見る値と
探索が使う値を分けない）。APIスキーマは`float | None = None`になり、生成型でも省略可能になった。

**フロントは値そのものを送るのをやめた**。`route-generate-config.json`の
`default_penalty_strength`を経由して既定値を送り返していたため、backendを直しただけでは
解決の道が塞がれたままだった——CLAUDE.md「共有フィールド・パターンを変更したとき」の
②「残る消費者が変更後の契約と両立するか」に当たる。画面から変える手段ができるまでは載せない。

`TuningPanel`の「再起動まで効かない」見出しも落とした（`OTHER_GROUP`のフォールバックが
あるため、宣言に無い効き方が残っても項目は消えないが、空の見出しだけが残る）。

### テストの母集団を導出へ

- `tests/test_tuning.py: CONSUMER_PROBES`（較正値id →（上書きする値, 観測する読み出し））を
  置き、`TUNING_PARAMETERS`の全idがそこに在ることを別のテストで要求する。`turn.*`は
  `turn_parameter_ids()`、`stop.*`は`POI_COUNT_KINDS`＋`stop_seconds_parameter_id()`から
  導くため、宣言を足せばプローブの側も自動で対象になる。
- **そのまま読み返せない値がある**。`speed.walking_kmh`・`speed.max_descent_kmh`は
  二分法の探索範囲の下限・上限として効くため、解が範囲の外へ出る勾配（±100%）を1つ
  通して頭打ちの値を観測する。`speed.climb_power_per_grade`は上限（既定2.5）へ届かない
  係数を入れて係数の側を見る。
- `tests/test_routes_generate.py: TestPenaltyStrengthDefault`（T817が置いた「正本1つから
  届く」テスト）も、手書きの2工場ではなく`dependencies`の署名から母集団を導く形へ変えた。
  導出が空振りしたときに「0件だから通った」にならないよう、件数の下限も併せて置く。
