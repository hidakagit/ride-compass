# T961: 土地被覆の読み出しで、発火しないフォールバックのJOINを毎回引いている

状態: 未着手（2026-09-19起票）

## 背景

探索の材料取得は`COALESCE(edge_landcover.x, way_landcover.x)`で区間→wayへ落とす形だが、
本番では`edge_landcover`が`road_edges`の**100%（5,065,850件）をカバー**しており、
way側へ落ちる区間は**0件**だった。406MBのテーブルへのJOINが毎回走って何も寄与していない。

地図配信（way単位のズーム）はway側を使うため、テーブル自体は要る。外せるのは
探索の読み出し経路のJOINだけで、カバレッジが100%であり続ける保証が要る。
