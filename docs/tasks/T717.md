# T717. 本番へprecompute_edge_curvatureを適用し蛇行軸の欠損を解消する 規模S

状態: 完了（2026-09-10起票、[T699](T699.md)から分離／2026-09-11完了）

## 背景

[T699](T699.md)で`precompute_edge_curvature`を`refresh_derived.py`の⑫段へ配線したが、
**本番DBの既存`road_edges.curvature_deg_per_km`はNULLのまま**である（コードの配線と
バッチの適用は別）。適用するまで、`build_road_graph`がsplit時に埋めた新規Edge以外の
区間では蛇行軸（`curvature`、`default_weight=0.1`、公開済み）が欠損扱いになり、
重み再正規化で薄まって無警告のまま評価から抜ける。

## 対応方針

1. 本番へ`python -m app.batch.precompute_edge_curvature`（または
   `python -m app.batch.refresh_derived`）を適用する。
2. あわせて`infrastructure/graph_material_cache.py: TILE_MATERIALS_CACHE_VERSION`を
   上げる。上げないと既にディスクキャッシュへ載っているタイルは古い材料のまま
   復元され続ける（[T574](T574.md)と同型）。
3. 適用後、軸スタジオ管理画面の「材料」タブで`curvature_deg_per_km`の欠損割合が
   下がっていることを確認する（T699でこの画面は`road_edges`側を数えるようになった）。
4. 完了扱いにする条件は[deployment-sync.md](../deployment-sync.md)に従う
   （開発DBのみの反映で完了扱いにしない）。

## 結果（2026-09-11）

### バッチは適用済みだった

着手時に本番DBを直接数えたところ、**既に計算済み**だった。起票から着手までの間に
適用されたもので、コミットとしては記録が残っていない。

```
road_edges 全件      : 5,047,354
  curvature NULL     : 2（いずれもdistance_m = 0 ＝ 度/kmを測れず対象外）
  対象(distance_m>0) : 5,047,352
  うち未計算         : 0
```

値の分布も妥当だった（最小0.0・p50 1.8・p90 770.6・最大89,242.9 度/km）。
ちょうど0が45.8%あるのは、頂点が2つだけのEdge（方位変化が1つも無い＝直線）が
多数あるためで、`_curvature_total_cte_sql`の定義どおり。

### キャッシュ世代は上げた（10→11）

**バッチの適用時刻を特定できなかったため、上げる側に倒した。** 本番の
`track_commit_timestamp`が`off`で行の更新時刻を引けず、`road_edges`は
`precompute_edge_curvature`の`UPDATE`が`updated_at`を触らないため、
「[T712](T712.md)が別の理由で9→10へ上げた（2026-09-10 18:36）のより前に走ったのか後か」を
判定できない。後だった場合、上げないとバッチ前にキャッシュ済みだったタイルだけが
古い材料（curvatureが全てNaN）のまま復元され続け、**一部のタイルでだけ蛇行軸が効かない**
という局所的で気づきにくい形になる。一度ぶんの温め直しと引き換えに、この不確かさを消した。

### 欠損割合の確認

管理画面の「材料」タブは本番のBasic認証（手元の開発用資格情報とは別）で保護されており
401のため、画面ではなく**画面と同じSQL**（`infrastructure/material_coverage.py`:
`SELECT count(*) FROM road_edges WHERE curvature_deg_per_km IS NOT NULL`）を本番DBへ
直接投げて確認した。上記のとおり対象5,047,352件すべてが計算済みで、欠損は
「測れない」2件（`distance_m = 0`）のみ。

## 残っている作業

無し。`road_edges`が変わる操作（PBF再取込・再split）を行った場合は、この
バッチの再実行とキャッシュ世代の引き上げが再び必要になる
（`graph_material_cache.py`の一覧に`precompute_edge_curvature.py`が載っている）。
