# T784. ルート設定パネルを「生成条件／重みづけ／除外」の3タブへ

規模M。
状態: 着手（2026-09-13）

## 背景

ルート設定パネルは、生成条件・軸の重みづけ・除外道路が1枚の縦並びに積まれており、
軸が増えるほど縦へ伸びる。走行中のスマホで扱う前提では、重みづけの調整だけで
画面を何度もスクロールすることになる。除外道路も「未舗装を除外」等を足す予定があり、
同じ面に混ぜると更に伸びる。

## 対応方針

- パネルを3タブ（生成条件／重みづけ／除外）へ分ける。
- 重みづけタブは内部で縦タブにし、左に軸の一覧（チェックで有効／無効、アイコン＋略名）、
  右に選択中の軸の重み調整と説明を置く。ルート結果パネルと同じ「左に一覧・右に中身」。
- 重み配分の帯グラフは重みづけタブの中に残す。
- 除外タブはハードフィルタの置き場とし、将来の除外条件をここへ足せるようにする。
