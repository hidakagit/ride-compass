# T389. MSM（5kmメッシュ）GRIB2パーサーの本実装 規模M〜L

状態: 保留（トリガー未成立、2026-08-29ユーザー判断）

- **2026-08-29、ユーザー判断で保留を決定**: 「今は無償範囲での実施とする。将来的に
  正式サービス化すれば考える」。下記のJMBSC契約費用（月額約13,500円＋初回50,000円、
  税別）を払ってまで導入する段階ではないという判断。トリガー: RideCompassが正式
  サービス化（課金・組織運営化等）された時点で改めて着手を検討する。

- 背景: T387（JMA気象データ連携基盤）でRedis保存インターフェース・データ構造の
  スケルトン（`app/services/jma_msm_service.py: parse_grib2_stub`）のみ用意し、実際の
  GRIB2バイナリ解析は「pygrib/cfgrib等のネイティブ依存を伴う新規ライブラリ導入の判断が
  必要」という理由で意図的に未実装のまま残した（ユーザー指示2026-08-29「MSM本実装は
  別タスクとして切り出して」を受け本タスクとして分離）。
- 対応方針（着手時に確定）: GRIB2デコードライブラリの選定（pygrib vs cfgrib vs 他）、
  MSMデータの取得元（気象業務支援センター経由か、気象庁の公開GPVエンドポイントかを含む
  入手経路の確認・認証要否の確認）、5kmメッシュ→ルート上の任意地点への空間補間方法、
  予報時間解像度（直近は1時間毎、先は3時間毎）の扱いを決める必要がある。
- 関連: T387（Open-Meteo代替可否の検討）で、ルート評価（WindService、区間ごと・将来時刻の
  風速風向）と風の格子点マップ（関東本土624地点・2日先まで）はOpen-Meteoの代替として
  MSMが理論上唯一のJMA候補と判定されたが、本タスク完了までは検証不能。
- **JMBSCとの契約が必須（2026-08-29、実機調査で確定）**: JMBSC「情報提供負担金」ページ
  （`jmbsc.or.jp/jp/online/c-onlineF.html`、2024年4月改定・気象庁認可の正式料金表）に
  「メソ数値予報モデルGPV（MSM）」が明記されている。**無料枠は無い**。
  - 開設時負担金（ファイル形式データ区分、初回のみ）: 50,000円（税別）
  - 基本負担金（月額、事業所単位）: 4,200円（税別）
  - MSM情報別負担金（月額）: 7,800円（税別）
  - 通信設備負担金（月額、インターネット回線の場合）: 1,500円（税別）
  - **月額最低合計 約13,500円（税別）＋初回50,000円（税別）**
  - 契約は自己サインアップ不可。配信事業部 契約担当（`haisin@jmbsc.or.jp`）への
    問い合わせ→書類審査→正式契約が必要（即時利用開始はできない）。
  - 同じ料金表に「紫外線情報」（3,000円/月）・「地域気象観測報（アメダス）」
    （5,400円/月）・「高解像度降水ナウキャスト」（7,200円/月）も掲載されている。
    後2者は本プロジェクトが既に無料のbosai公開JSONで実装・稼働確認済みのため
    （T387）、JMBSC経由へ切り替える必要はない。UV指数はbosaiに無料の代替が
    見つかっていないため、JMBSC経由（3,000円/月）が唯一の入手経路と見られる。
  - **着手前の意思決定事項**: 月額1万円超＋初回5万円の費用を払ってMSMを導入するか、
    Open-Meteo依存を継続するか、ユーザー（プロジェクトオーナー）の判断が必要。
    この判断が下るまでGRIB2パーサー実装（本タスク本体）には着手しないこと。
