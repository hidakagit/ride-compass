# T589: 迂回率（道なり距離÷直線距離）を定数から実測値へ——復路は往路木の実測中央値、往路は探索範囲ごとの学習値を使う

状態: 未着手（2026-09-05起票。[T532](T532.md)の本番実測で定数1.3に対し中央値1.19だったことを受けたユーザー判断）

## 背景

[T532](T532.md)は各Edgeの通過予定時刻を「基準点からの直線距離×`ROUTE_DETOUR_RATIO`（1.3）÷
仮定速度」で推定する。本番（東京駅25km）の往路木から測った実測中央値は1.19で、差は約9%。
25kmでは最大8分程度で風予報の1時間刻みより小さいが、100km（5時間）では約27分になり
無視できない。定数のままにする必然性は無い。
