# T613: モバイルの「ルート設定」タブに周回/目的地選択（RouteForm）が入っていない問題を是正する

状態: 起票（2026-09-06、ユーザー指摘を受け着手中）

## 背景

T597（デスクトップのサイドバーをモバイルと同じ3区分にする）の完了条件は「デスクトップと
モバイルで区分の名前・順序・中身が一致する」だったが、実際にはデスクトップの
「ルート設定」Disclosure（`renderRouteSectionBody`）が`RouteForm`（周回/目的地トグル・
距離・生成ボタン）と`RouteSettingsPanel`を続けて描画するのに対し、モバイルの
「ルート設定」BottomSheetは`renderRouteSettingsSectionBody(false)`のみで`RouteForm`を
含まない。`RouteForm`はT250由来の常時表示バー（`mobileActionBar`、天候ヘッダー直下）に
取り残されたままだった。

## 対応方針（ユーザー確認済み）

常時表示バー（`mobileActionBar`）を廃止し、モバイルも「ルート設定」タブ一本化する
（`renderRouteSectionBody()`をデスクトップ・モバイル双方から呼ぶ）。design-principles.mdの
「1つの状態は1つの場所でだけ操作する」原則に従う。生成ボタンを押すにはタブを開く必要が
生じる（T250が解消した「タブを開かないと生成できない」という遠回りさが復活するが、
3区分に統一する一貫性を優先する）。
