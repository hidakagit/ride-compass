# T943. トリガー付きタスク6件の前提が、この期間の完了タスクで無効化された 規模S

## 背景

トリガー付き未完了タスク22件を全件棚卸しした結果、発火は0件だが6件の本文が実装とずれていた。
とくにT629はトリガーが名指しする`MapLayersPanel`がT769で撤去済みのため永久に発火しない。

詳細は[history/2026-09-19_all.md](../../.claude/commands/review/history/2026-09-19_all.md)。

## 対応方針

トリガー付き未完了タスク22件を全件棚卸しした結果（全件の判定と根拠は
[history/2026-09-19_all_shards.md](../../.claude/commands/review/history/2026-09-19_all_shards.md)
のシャードP A節）、発火0件・是正が必要6件だった。次の6件の本文を直す。

- **T629**: トリガーが名指しするコンポーネントが[T769](T769.md)で撤去済みのため**永久に発火しない**。
  トリガーを現行の構造で言い直すか、見送り確定にする。
- **T389**: 本文が起点とする実装がすべて消滅し、MSMは[T645](T645.md)で本番稼働中。
  「本タスク完了までは検証不能」が成立しないため、射程を書き直すかクローズする。
- **T640**: 本文が「レイヤーごとに独立して持てる形を維持する」と書く2定数を[T848](T848.md)が撤去済み。
- **T714**: 対応方針の前半「まず観測を足す」は[T840](T840.md)が実質達成済み。さらに[T919](T919.md)が
  同じ方式の3本目を足し本番で実走したのに、誰も観測していない。
- **T715**: 本文が名指しする行が別のコードになっており、対象は`AxisFormFields.tsx`へ移設済み。
- **T127**: 容量試算がその後の14本のmigrationで陳腐化（2巡目）。

## 再発防止

**自己申告のチェックを増やさない。** 今回の6件はいずれも「**かつて存在して撤去された**」名前を
指しており、「これから作るもの」の名前とは区別できる。撤去済み識別子の履歴と未完了タスク本文の
突き合わせを検知器にできないかを、**まず実測してから**決める（現在の未完了36件で何件出て、
そのうち何件が真の違反かを数える）。届かなければ周期レビューの手順として残す。
