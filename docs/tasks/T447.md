# T447. secondaryAxes.tsのコメントがwindのcategory/show_map_icon除外機構を逆に説明している

状態: 完了（2026-08-31）

- 背景: `統合レビュー第2回`（`.claude/commands/review/history/2026-08-30_all_2.md`P2-3）の
  指摘。`frontend/src/components/Map/secondaryAxes.ts`のコメント（`7f68838`、
  "2026-08-30訂正"）が「windの`category`は`"推定"`であり`category !== "動的"`は
  デッドフィルタ、実際の除外機構は`show_map_icon`」と主張するが、実際の
  `backend/fixtures/axis_definitions_snapshot.json`（`63d959c`で再生成後）では
  windの`category`は`"動的"`・`show_map_icon`は`true`——**主張と逆**（`category`
  フィルタの方が実際の除外機構）。`frontend/src/components/RouteSettingsPanel/
  RouteSettingsPanel.test.tsx:230-234`のコメント/モックにも同じ誤りが複製されている。
- 影響: 現状の挙動（windが正しく除外される）自体は壊れていないが、このコメントを信じて
  「デッドフィルタだから削除」する変更をすると実際に壊れる。
- 対応方針: `secondaryAxes.ts`と`RouteSettingsPanel.test.tsx`のコメントを実態
  （`category`フィルタが除外機構）へ訂正する。加えて、コメントの正確性に依存しない
  形でこの除外挙動を直接検証する単体テストを新設する（category除外の振る舞いをテスト
  自体が保証すれば、将来同種のコメント誤りが実害を生まない）。
- Confidence: High（frontend/その他シャードが実際のsnapshotファイルと突き合わせ確認）。
- 規模S。

## 実施記録（2026-08-31完了）

- **コメントの訂正**: `secondaryAxes.ts`のコメントを、実態（windは`category="動的"`が
  除外機構、`show_map_icon`は`true`で除外に寄与していない）へ書き換えた。
- **`RouteSettingsPanel.test.tsx`の複製訂正**: 同じ誤りを引き継いでいたモック
  （`category: "推定"`・`show_map_icon: false`）を実態（`category: "動的"`・
  `show_map_icon: true`）へ修正し、コメントも訂正した。
- **除外挙動の直接検証**: 対応方針が求めていた「コメントの正確性に依存しない単体テスト」は
  既に`secondaryAxes.test.ts`（`describe("「動的」軸除外フィルタ」")`）に存在していた
  （`category=動的の軸は推定指標グループの一覧から除外される`・`既存軸（静的
  フォールバック）にはcategory=動的の軸が含まれない`の2件、コードレビュー指摘対応時に
  新設済み）。新規追加は不要と判断した。
- **横展開チェック**: 同種の誤り（「windはcategory="推定"」「show_map_iconが除外機構」）が
  他ファイルに複製されていないかgrepで確認し、上記2ファイル以外に無いことを確認した。
- **検証**: `tsc --noEmit`・eslint・vitest（secondaryAxes.test.ts・
  RouteSettingsPanel.test.tsx、計18件）すべて通過。
