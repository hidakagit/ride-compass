# T442. axis_definitions_snapshot.jsonがT440の軸変更に追従しておらず、fresh bootstrapと乖離している 規模S

状態: 完了（2026-08-30）

- 背景: T441（2026-08-30）の作業中、`export_openapi.py`をfresh bootstrap
  （`backend/scripts/bootstrap_fresh_db.py`、`backend/fixtures/axis_definitions_snapshot.json`
  読み込み）したDBに対して実行したところ、`frontend/src/types/generated/axis-catalog.json`が
  T440実装時にaxis_admin API経由（unpublish→PUT→republish）で設定したはずの値から
  巻き戻る差分が生成された。CLAUDE.mdが警告するT353/T360と同型の問題
  （「変更経路がmigrationとAPIの2つ存在する限り同期漏れが構造的に再発する」を受けて
  T361で行データの変更経路をAPIへ一本化したが、API変更後のスナップショット再ダンプ
  [`dump_axis_definitions_snapshot.py`]は手動運用のため、今回も実施漏れが発生したと推測）。
- 対応: チェック済みの`frontend/src/types/generated/axis-catalog.json`（T440実装時に
  意図した値の「答え」として現存）と、fresh bootstrap直後のDBの差分を比較し、
  ズレが以下3軸3フィールドに限定されることを確認した（他10軸のフィールドは
  スナップショットに元から正しく反映済み）:
  - `gradient`: `supports_route_coloring` false→true、
    `display_thresholds_override` null→`[-2.0, 2.0, 6.0, 10.0]`、
    `dedicated_way_value_layer`（migration 0027で新設、既定false）false→true
  - `wind`: `dedicated_way_value_layer` false→true
  - `surface_q`: `supports_route_coloring` false→true

  `AxisRegistryAdminService`（`unpublish`→`get`→対象フィールドのみ更新した
  `AxisDefinition`を`update`）を直接呼ぶ一時スクリプトで、fresh bootstrapしたDBへ
  上記3軸の値を再現し、`dump_axis_definitions_snapshot.py`で
  `axis_definitions_snapshot.json`を再ダンプした（`revision`が22→28、DB上の実際の
  API操作回数の履歴を反映）。再度`export_openapi.py`→`npm run generate:api`を実行し、
  `git diff -- frontend/src/types/generated/`が完全にクリーン（axis-catalog.json含む）
  になることを確認——これはfresh bootstrapの結果が現在のチェック済み生成物と
  完全一致した、つまりスナップショットが正しく最新化されたことの直接的な証拠。
  合わせて`dedicated_way_value_layer`フィールド自体が旧スナップショット全体に
  存在しなかった（migration 0027より前のダンプのため）ため、他10軸にも
  `"dedicated_way_value_layer": false`が新規追加される差分になっている
  （値は変わらず、フィールドの存在自体の追従漏れ分）。
- 検証: `pytest -q`（`test_import_pbf.py`・`test_pbf_source.py`除く、osmiumモジュール
  未導入の環境要因でこの2ファイルのみ対象外）1452件成功（`test_evaluation_bulk.py`の
  風関連4件は環境のnumpyバージョン相違による既知の無関係な失敗、T441と同様に
  git diffで無変更を確認済み）。`test_migrate.py`（fresh bootstrapの一連の流れを
  検証するテスト）8件成功。`npx vitest run`838件・`tsc --noEmit`・`eslint`とも
  問題なし。
