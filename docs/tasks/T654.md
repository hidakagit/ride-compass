# T654. OSM取込対象（層0）へ自転車の停止要因を追加する 規模S

状態: 未着手

## 背景

`osm_raw_pois`へ取り込むノードの種類は`backend/app/batch/import_profile.yaml`が宣言する。
現在の対象は信号・横断歩道・一時停止・徐行（`highway=*`）と車道用踏切
（`railway=level_crossing`）だけで、**車止め（`barrier=*`）が入っていない**。
河川敷サイクリングロード等で自転車を停止・降車させる最大の要因が、DBに存在しない。

取込対象はPBF再取込（数時間）でしか変えられないため、次回の地図データ更新に相乗りさせる。
