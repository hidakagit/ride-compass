# T791. 画面のベタ書き説明文を情報アイコンの奥へ寄せる

規模S。
状態: 着手（2026-09-13、ユーザー要望「説明文がべた書きに書いてある、とかただでさえ
スペースがないのに無駄。UI全般からなるべくなくしてほしい」）

## 背景

[T788](T788.md)で「重み」「除外」タブのベタ書き説明を情報アイコンの奥へ移した。同じものが
他の画面にも残っている。設計原則「冗長なものは削る」（docs/design-principles.md）に従い、
**操作の仕方を説明する文**を情報アイコンの奥へ寄せる。

状態・結果を伝える文（生成中・条件が変更されている・補正した・候補が無い等）は対象にしない
——それが無いと今どうなっているかが読めなくなる。

## 対象と判断

| 場所 | 文 | 判断 |
|---|---|---|
| 区間の乗り換え（見出し直下） | 他の候補が別の道を通る区間を、このルートに取り込めます | 見出し脇の(i)へ |
| 同（相手未選択時） | 比較相手を選ぶと、その候補が別の道を通る区間が地図にオレンジの帯で出ます | 同上へ集約 |
| 同（区間あり） | 地図のオレンジの帯が乗り換えられる区間です。選ぶと実線に変わります | 同上へ集約 |
| ルート結果 | 条件が変更されています。「ルート生成」を押すと反映されます | 後半（押し方）を落とす |
| ルート結果・ルート編集の空状態 | 「ルート生成」を押すと候補がここに並びます 等 | 残す（空の面に出る唯一の手掛かり） |
| 目的地の補正 | 指定した地点は自転車で行けない場所だったため〜 | 残す（起きたことの通知） |
