# T786. GPX出力の間引きで細かい曲がりが消える

規模S。
状態: 未着手（2026-09-13起票）

## 背景

実走後のユーザー報告「gpx出力して他ナビに読み込ませたところ、道が繋がっていないように
見える場所があった。出力点と点の間隔よりも狭い曲道が無視されて、道もないのに直線に
つながれていた」。

`frontend/src/lib/gpxExport.ts: decimateCoordinates`は`stride = ceil(点数 / 上限)`の
等間隔ストライドでn点ごとに拾う。残す点を折れ線の形から選ばないため、ストライドより
短い区間に収まった曲がりは前後の点ごと落ち、直線で結ばれる。

## 調査項目

- 形状を基準に残す点を選ぶ間引き（垂線距離ベース）への置き換えと、`MAX_GPX_TRACK_POINTS`
  （Suunto互換のため維持）の両立のさせ方
- 実データの点数・点間隔（都心の目的地ルートで何点になり、何mおきになるか）
