# T588: `test_lifespan_registers_jma_tile_prewarm_job_with_immediate_next_run_time`がフルスイートでのみ失敗する

状態: 未着手（2026-09-05起票。[T532](T532.md)の最終検証で発覚、ユーザー指示で起票）

## 背景

`backend/tests/test_main_lifespan.py::test_lifespan_registers_jma_tile_prewarm_job_with_immediate_next_run_time`
が、`pytest -q -m "not postgis"`（全件）およびファイル単位（`pytest tests/test_main_lifespan.py`、
4件で約40〜50秒）では失敗し、同じテストを単体指定で実行すると成功する（約6秒）。T532の
変更前のmaster（e9951eb〜d5d209b）でも同じ結果で、T532とは無関係の既存の不安定化。
JMAタイル予熱ジョブを`next_run_time=datetime.now()`で登録し即時実行を期待する検証が、
先行テストの負荷でlifespan起動に時間がかかると許容差を超える（時間依存）疑いがある。
未調査のため原因は確定していない。

## 放置した場合の影響

フルスイートが常に赤1件になり、他タスクの回帰検知の信頼性が下がる（「既知の1件」として
読み飛ばす運用が定着すると本物の失敗を見落とす）。
