# T512: 風の評価軸凡例に体感ラベル（強い向かい風/軽い追い風等）を追加

状態: 完了（2026-08-31）

## 背景

ユーザー指摘: 降水ナウキャストの凡例（`PRECIPITATION_INTENSITY_LEVELS`）は「ポツポツ」
「ザーザー」等の体感で分かるラベルを手打ちで持つ実績がある。風の評価軸凡例
（`windAxisLegend`）は数値レンジ表記（例:「-2〜2m/s」）のみで同種の体感ラベルを
持たない。降水と同じ体感表現を風にも追加したいが、色の手打ち指定までは不要
（`rampColorForBand`による自動生成のままでよい）。

## 対応方針（ユーザー承認済み、2026-08-31）

`mapColorLegend.ts: buildRangeLegendBands`に任意の`labels`引数を追加し、渡された場合は
数値レンジ表記の前に体感ラベルを添える（例:「強い向かい風（6m/s以上）」）。色は引き続き
呼び出し側の既存ロジック（`rampColorForBand`自動生成）のまま——降水・矢印の風速凡例
（`WIND_SPEED_LEGEND_LEVELS`）のような色の手打ち指定機能は追加しない。

`windAxisLayer.ts`に`WIND_PENALTY_FEEL_LABELS`（5段階、既定の`WIND_AXIS_THRESHOLDS`と
1:1対応）を新設し、`windAxisLegend`が段階数（`boundaries.length+1`）がこの固定ラベル数と
一致する間だけ体感ラベルを付ける。軸スタジオの`display_thresholds_override`で段階数
（配列長）自体を変えた場合は固定ラベルとの対応が崩れるため、数値レンジのみへ
自動的にフォールバックする（境界値だけの調整であれば段階数は変わらないため体感ラベルは
付いたまま）。

`gradientAxisLegend`には同種のラベルを追加していない（未依頼、必要になれば同じ仕組みで
追加できる）。

## 実装メモ

- `frontend/src/components/Map/mapColorLegend.ts`: `buildRangeLegendBands`に
  `labels?: readonly string[]`引数を追加。
- `frontend/src/components/Map/windAxisLayer.ts`: `WIND_PENALTY_FEEL_LABELS`定数を新設、
  `windAxisLegend`が段階数一致時のみ`labels`を渡す。
- `frontend/src/components/Map/windAxisLayer.test.ts`: 既定段階数(5)での体感ラベル付与・
  `display_thresholds_override`相当の境界値調整（段階数維持）でも体感ラベルが付くこと・
  段階数が既定と異なる場合は数値レンジのみへフォールバックすることの3テストを追加。
- `docs/modules/frontend/map-axis-coloring.md`: `windAxisLegend`の体感ラベル仕様を追記。
  ついでに`MapColorLegend.tsx`の配置説明が「地図左下」のまま古くなっていたドキュメント
  ドリフト（実際は地図上部中央、モバイルBottomSheet対応で移設済み）を是正した。
