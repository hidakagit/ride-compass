# T733. identifier_existsの小文字化緩和をSettingsフィールドへ限定する 規模S

状態: 完了（2026-09-12。起票は2026-09-11、統合レビュー第7回 I-11（P2））

## 背景

SCREAMING_SNAKE定数173件中32件が、同名の小文字（モジュール名・DB列名）の存在により撤去されても検知されなくなった。緩和で救済されているのは10件のみ。

詳細な指摘（Evidence・Impact・Root Cause・Recommendation）は[history/2026-09-11_all.md](../../.claude/commands/review/history/2026-09-11_all.md)を参照。

## 対応

緩和の条件を「小文字形がcorpus全体のどこかにある」から「小文字形が`backend/app/config.py`の
`Settings`フィールドとして定義されている」へ絞った。救済が要るのは`.env`で設定する環境変数名
だけで、それらは実装側にpydantic `Settings`の小文字フィールドとしてしか現れない。

## 実測（緩和の影響）

測るのは「その定数を撤去したとき、検知器が鳴るか」である。

| 緩和の条件 | 撤去しても検知されない定数 |
|---|---|
| 旧: corpus全体に小文字形がある | 31/172（18%） |
| 新: Settingsフィールドに小文字形がある | 15/172（8%） |

検知力が戻ったのは16件（`AXIS_DEFINITIONS`・`MATERIAL_CATALOG`・`MAX_ROUTES`・
`ALGORITHM_VERSION`・`CHUNK_SIZE`等）。いずれもモジュール名や無関係な小文字識別子と
偶然一致していたもの。残る15件は全て実在の環境変数名
（`*_RATE_LIMIT_PER_MINUTE`・`DATABASE_URL`・`ADMIN_BASIC_AUTH_*`等）で、意図どおりの救済。

**現時点で新たに違反として鳴る件数は0件**（大文字の綴りが実装に無い21件のうち、救済対象から
外れたものが無かった）。効果は「これから撤去したときに鳴るようになる」という形で出る。

## 検証結果

- 単体テスト2本を追加: 環境変数名がSettingsフィールドで救済されること、
  `AXIS_DEFINITIONS`がモジュール名`axis_definitions`に一致しても救済されないこと。
- `pytest scripts/tests/test_review_checks.py` → 59 passed。
- `python scripts/review_checks.py mutate` → 全22件PASS。
- `python scripts/review_checks.py docs` → 違反なし。
