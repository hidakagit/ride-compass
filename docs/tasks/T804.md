# T804. 地点のピンを3つとも「つかんで動かせる」形に揃え、地図の操作ボタンをシートの上へ出す

規模S〜M。
状態: 完了（2026-09-13、ユーザー要望「目的地マークも同じく持ち上げて移動できるように。
後マークが対応していないので、見た目も揃えて」「現在地に移動するアイコンが、下部パネルを
持ち上げると隠れてしまう」）

## 背景

[T797](T797.md)で3つの地点を同じ形の行に揃えたが、地図側のピンは揃っていなかった。

- 出発地: 丸い白バッジ、つかんで動かせる
- 経由地: 24pxの青い円（番号）、動かせない
- 目的地: 🏁の絵文字だけ、動かせない

地図の操作ボタン（現在地へ移動・気象タイムライン等）は画面の下端からの距離で置いており、
下部シートを持ち上げるとその裏へ隠れていた（タブバーの高さは足していたが、シートの高さは
知らなかった）。

## 対応

- ピンの見た目を`createPointMarkerElement`（26pxの丸バッジ＋白縁＋影）へ揃え、経由地は番号、
  目的地は旗（⚑）を中身にする。設定パネルの行頭の印も同じ色・同じ字にする。
- 経由地・目的地とも`draggable`にし、`dragend`で座標を置き換える。**つかんで動かした直後の
  clickは読み飛ばす**（`bindDragAwareClick`）——同じ操作の終わりにclickが飛ぶため、動かした
  だけで削除・解除が起きてしまう。
- 下部シートが占める高さを`--mobile-sheet-height`として`.mapPane`へ渡し、下端からの距離を
  `max(元の位置, シートの上端のすぐ上)`にする。シートが閉じている間は0で従来どおり。

## 検証

Playwright（e2eのモック環境、390px）:

- 目的地ピンをドラッグ (187,269)→(234,216)、経由地ピンを (137,319)→(74,336)。どちらも
  ドラッグ後に地点は消えない（行の値が「地図で指定」「1地点」のまま）
- 動かさずにクリックすれば従来どおり消える（経由地が「なし」へ）
- シート70vhのとき、現在地ボタンの下端190px＜シート上端197pxで隠れない（従来は543pxで裏）
