# T938. 軸カタログの取得が失敗すると、静的な道路レイヤーが全部消え、理由が画面に出ない 規模S〜M

状態: 完了（2026-09-19起票・完了、統合レビュー第11回）

## 背景

T848（タイル世代の実行時配信）とT918（世代ゲート）の帰結として、`GET /api/axis-catalog`の失敗が
路面・道路種別・POI・事故などのソースを1つも作らせなくなった。状態ドットも出ないため、
利用者からは「この地域にデータが無い」と見える。

詳細は[history/2026-09-19_all.md](../../.claude/commands/review/history/2026-09-19_all.md)。

## 対応方針

**フォールバックは戻さない**——ビルド時生成物の世代へ落とすと、世代の違う中身がブラウザの
キャッシュへ載って以後ずっと残る（それが撤去した理由で、`hasTileVersions()`のコメントが明記している）。
地図が出ないこと自体は正しい挙動で、問題は「出ない理由が画面のどこにも無い」ことだけである。

1. **再試行の配線**: `page.tsx`の`tileVersionsReady`を`axisCatalog.loaded`ではなく
   `hasTileVersions()`由来にする。これでカタログ失敗の経路と、「世代を返さない版のbackendが
   応答した窓」の両方が同時に解消する。
2. **縮退状態を見せる**: 世代が無い状態を`LayerDataStatus`の1状態として扱い、チップに理由を出す。
   ズーム不足の案内（[T888](T888.md)段階2）と同じ仕組みに乗せる。
3. **ガードの置き場所を揃える**: `ensureRoadSurfaceTileLayer`は`runWhenStyleReady`の中、
   `ensureAccidentTileLayer`・`ensurePoiTileSource`は外で判定しており、兄弟間で不揃い。
4. **`RouteSettingsPanel`の告知**が述べる影響範囲（「重み配分が反映されない」）を実態へ合わせる。
5. `MapView.tsx`のタイル世代到着effectが`map.isStyleLoaded()`で早期returnしている点も併せて直す
   （`mapStyleOps.ts`が「それをガードに使うと二度目以降の描画が永久にスキップされうる」と
   明記している形）。

## 実装メモ

### 世代が揃ったかを、カタログの取得完了で代用するのをやめた

`setTileVersions`が購読できるようになり（`regionApi.ts: subscribeTileVersions`）、
`useTileVersionsReady`がそれを`useSyncExternalStore`で読む。これでカタログ失敗の経路と、
「世代を返さない版のbackendが200で応答した窓」（カタログは取得済みなのに世代は無く、
URLを組み立てた側が例外になる）の両方が同時に解消する。

### 縮退の宣言は、レイヤーカタログの記述子へ置いた

最初は`MapView.tsx`のソース対応表（`buildLayerDataSources`）から導いたが、**`page.tsx`が
重いモジュールから純関数を借りると、`page.test.tsx`にあるMapViewのスタブ3箇所すべてが
その関数を持つ羽目になる**（1つでも欠けると本番コードが実行時に落ちる）。記述子の
`tileNeedsVersion`宣言へ移し、`mapLayers.ts: tileVersionGatedLayerIds`が引く形にした。
ズーム不足（`tileMinZoom`）と同じ形で、判定も配線も1箇所。

宣言が2箇所（`MapView.tsx: TILE_VERSION_GATED_SOURCE_IDS`と記述子）になるため、
**両者を突き合わせるテスト**を置いた——ずれると「描けていないのにチップが黙る」という、
画面を見ても気づけない形でしか出ない。

### 既存テストが縮退状態を正常だと思い込んでいた

`page.test.tsx`のカタログのフィクスチャが`tile_versions: {}`（＝世代を返さない版が応答した
状態）で、ズーム案内のdescribeはカタログを**故意に失敗させて**いた。縮退を正しく出すように
した途端に15件が落ちたが、これは直した側の誤りではなく、**フィクスチャが「地図が1つも
描けない状態」を既定にしていた**ことが表に出たもの。フィクスチャへ実際の世代を入れ、
ズーム案内のdescribeはカタログを成功させる形へ直した。
