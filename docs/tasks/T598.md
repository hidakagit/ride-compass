# T598: 軸スタジオの折れ点編集を参考点・自動生成・効き目プレビューで省力化する

状態: 1番（参考点配信）実装済み、2〜5番は未着手（分割元は[T590](T590.md)）

## 背景

折れ点はほぼ全て手入力で、曲線エディタ（`AxisComposer.tsx: BreakpointCurveEditor`）は
軸が現在の折れ点だけから自動スケールし、目盛り・格子線・スナップ・ドラッグ中の値表示が
無い。「折れ点を追加」は末尾に`[0,0]`を足すだけで昇順制約に即座に違反する。材料の値域の
情報が画面に無く、二乗則材料（[T591](T591.md)）のように単位が直感的でない場合は換算表を
外部で持たなければ編集できない。

## 対応方針

1. 材料カタログに参考点（ラベル＋値の一覧）を持たせ`GET /api/material-catalog`で配信する。
   風の新材料なら「時速20km・向かい風2m/s → 0.85」「向かい風8m/s → 4.95」「追い風で速度と
   同じ → -1.0」、勾配なら「緩い坂3%」「きつい坂9%」等。換算式はbackendだけが持つ
   （設計原則1）。
2. 範囲と形から折れ点を自動生成する入力方式。「0点にする値」「100点にする値」「形
   （一定／後半で急／前半で急／S字）」の3入力から5〜7点を生成し、通常の折れ点として保存する
   （backendのshape契約は不変）。0点・100点の値は参考点から選べる。生成後の個別調整
   （既存の数値行）は残す。
3. 効き目プレビュー表。折れ点を変えるたびに各参考点が何点になるかを表で即時表示する。
4. エディタ操作改善。目盛りと格子線、ドラッグ中の値ラベル、参考範囲に基づく固定の軸レンジ、
   刻み幅スナップ、矢印キー微調整、追加時は隣接点の中間へ挿入して自動ソート。
5. 参考点はT592の区間詳細の参考換算、T593の凡例補助にも同じ配信を使う。

## 実装メモ（1番backend）

`MaterialSpec.reference_points: list[MaterialReferencePoint]`（`label: str`, `value: float`、
既定空list）を追加し、`GET /api/material-catalog`の`MaterialCatalogEntry.reference_points`
として配信する（`MaterialReferencePointEntry`、`tile_property`等と異なりこちらは公開
フィールド）。値を持たせたのは`wind_penalty`（風、5点、`WindCalculator.wind_penalty`の
計算値を小数2桁丸め）・`gradient_percent`（勾配、4点）・`stop_count_per_km`・
`intersection_count_per_km`・`accident_count_per_km_year`・`maxspeed_kmh`・`lanes_count`
（各2〜4点、常識的な目安の静的値）。真偽値・categorical材料は空リストのまま。

**base branchの状態に関する注記**: 本タスクの記述は[T591](T591.md)（風の二乗則材料
`wind_drag_ratio`、`domain/wind.py: wind_drag_ratio`）が既に存在する前提で書かれているが、
本実装に着手した時点でこのworktreeのbranch元（master）にはT591がまだマージされておらず
（T591は別branchで完了しmasterへ未マージ）、`domain/wind.py`は旧`WindCalculator.wind_penalty`
（走行速度を考慮しない単純な向かい風成分m/s）のままだった。T591の作業branchを未マージの
まま取り込むと大量の無関係差分を抱え込むため行わず、**現行の`wind_penalty`材料に対して
`WindCalculator.wind_penalty`の計算値で参考点を持たせた**（向かい風2/4/8m/s・追い風4m/s・
真横4m/sの5点、走行速度非依存のため「走行速度と同じ追い風」点は成立せず含めていない）。
T591がmasterへマージされ材料が`wind_drag_ratio`へ置き換わったら、参考点も
`wind_drag_ratio()`ベースへ同一コミットで移行すること（`_wind_penalty_reference_points`を
`wind_drag_ratio`向けに書き換え、走行速度20km/hでの6点（向かい風2/4/8m/s・追い風4m/s・
真横4m/s・走行速度と同じ追い風）を計算し直す）。
