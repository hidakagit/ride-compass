# T859. 動的気象レイヤーの共有時刻が「今」に追従せず、降水が黙って消える

状態: 未着手（2026-09-15起票）

## 背景

本番で「雨が降っている地域があるのに、降水レイヤに何も描画されない」という報告があった。
時刻スライダーを動かすと描画される。

共有時刻`dynamicLayerTargetTime`は画面を開いた時刻で固定され、時間の経過で進まない。
一方、降水ナウキャストのフレーム列は`trimToCurrentAndFuture`で先頭を最新の実況フレームへ
切り詰めており、5分ごとの再取得でその先頭が前進する。`frameIndexForTime`は範囲外で`null`を
返す設計のため、開いてから最初の再取得で共有時刻がフレーム列の過去側へ落ち、降水レイヤーは
何も描かなくなる。利用者からは「雨が降っていない」と区別がつかない。

同じ性質を持つのは実況由来のフレーム列を使う要素（降水ナウキャスト・雷・竜巻・雷放電）。
線状降水帯は`isWithinFutureWindow(target, new Date(), ...)`の`new Date()`がuseMemoの内側に
あり依存が`[dynamicLayerTargetTime]`だけのため、比較相手の「今」も一緒に凍結して常に可視に
なる——向きは逆だが同じ欠陥。本番VMのnginxログで、同じ「降水」チップ配下の
sjfcstmapがタイルを要求し続ける一方hrpnsがほぼ要求していなかったのはこの非対称による。
