# T858. 線レイヤーの視覚言語を「意味を運ぶのは色だけ」へ揃える

状態: 未着手（2026-09-15起票）
規模: M

## 背景

道路グループの色分けが読みにくい（ユーザー指摘「道路種別とか、太さで言われても他とズレて
いる。線レイヤ全般の凡例色分けを見直してほしい。シンプルなルールにして」）。線レイヤーに
4つの視覚言語が同時に走っている: 道路の種類だけが太さ（6/4.5/3/1.75px）と破線で意味を運び、
他はすべて色で運ぶ。さらに道路の種類の色は、路面の種類がONの間は使われない（同じレイヤーの
色の意味が、別レイヤーのON/OFFで入れ替わる）。

## ルール（ユーザー承認済み）

1. 意味を運ぶのは色だけ。太さと線種は情報を持たない。
2. 1レイヤー＝1つの色の意味。他レイヤーのON/OFFで色の意味を変えない。
3. 色の体系は3つ: 評価に効く順序＝緑→赤／順序のない分類＝レイヤーごとの色相の濃淡／
   該当・非該当＝そのレイヤーの色と灰色（非該当は薄く）。
4. 同時にONのレイヤーは並列トラック（`line-offset`）で分ける。
