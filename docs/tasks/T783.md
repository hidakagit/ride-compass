# T783. 有効な軸のアイコンが白く、無効な軸だけ色が残る

規模S。
状態: 完了（2026-09-13、本番実機フィードバック「有効にしている軸色が白なのは嫌。無効に
している軸色はやっぱり非表示、有効にしている軸色は重み付け横棒グラフと色を合わせて」）

## 背景

[T782](T782.md)で凡例をアイコンにしたところ、本番では**評価に使った軸（押せるチップ）の
アイコンだけが白**になり、使っていない軸（押せないチップ）は色が付いて見えていた。

原因は`.legendTrigger svg { color: var(--color-muted) }`——(i)アイコンを弱めるための指定が、
子孫セレクタで軸アイコンのSVGまで巻き込んでいた。押せないチップは`<button>`を通らないため
影響を受けず、色が残っていた。

## 対応

- `(i)`だけを弱めるよう直下セレクタ（`.legendTrigger > svg`）へ変える。軸アイコンは
  `.legendIcon`配下のsvgのため巻き込まれない。色は重み配分の帯グラフと同じ
  `stackBarColorForIndex`由来（`page.tsx: axisChipColors`）で、両パネル・帯・チップが揃う。
- 評価に使っていない軸（重み0＝詳細を持たない軸）のチップは**出さない**。薄く残す扱い
  （[T776](T776.md)）はユーザー判断で撤回した——軸の一覧はルート設定側が持ち、結果側は
  「このルートの評価に効いた軸」に絞る。

## 検証

Playwright（390x812、重みのある軸に寄与値を入れた応答）で、チップのインラインcolorと
computed colorが軸の配色（`rgb(211,69,69)`等）になり、白（`--color-muted`）へ落ちていない
ことを確認した。無効な軸のチップは描画されない（`npx vitest run` 137ファイル全緑、
凡例のテストは「評価に使った軸だけを並べる」へ更新）。
