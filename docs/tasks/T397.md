# T397. 軸スタジオUIの3カード再設計（なめらか/ぴったり/かけあわせ） 規模M

状態: 設計確定・実装中（2026-08-29）

- 背景: T396（軸スタジオ合成ロジックの2プリミティブ化）に合わせ、`AxisComposer.tsx`の
  UIも4枚のカード（「数値の大きさに応じて」「はい/いいえ、または種類ごとに」「複数の
  要素の有無を数えて」「他の軸を重みで足し合わせて」）を「なめらか評価」「ぴったり評価」
  「かけあわせ評価」の3枚へ再設計する。ウィジェットもパラメータの性質に合わせて使い分ける
  （係数はスライダー、そのまま/絶対値はラジオボタン、折れ点はドラッグ式曲線エディタ、
  かけあわせは折れ点編集UIを出さず純粋な重み付き結合のみに絞る）。詳細は後続コミットで
  追記する。
