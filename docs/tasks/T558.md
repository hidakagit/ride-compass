# T558: 周回ルートの進行方向矢印（T293）が区間色分け線に隠れて見えない問題の修正

状態: 着手中・実装済み・最終検証前で中断（2026-09-03起票、ユーザー報告「ルート生成の結果、
向きの矢印が描画されていない」。セッション上限のため同日、下記「残作業」を残して一時停止）

## 背景

[T293](T293.md)で追加した選択中候補の進行方向矢印（`route-arrow-halo`/`route-arrow`、
`MapView.tsx: ensureRouteArrowLayer`）が実機で見えない。矢印の機能・コード自体は残っており
（削除・撤去されたコミットは無い）、「復元」ではなく表示条件の不具合修正が対象。

## 原因（Playwright headless診断、dev backend＋frontend、現在地=東京駅・20km・8候補）

診断スクリプト（scratchpadの`arrow_check2.mjs`、React fiberから`maplibregl.Map`を取り出して
`queryRenderedFeatures`とレイヤー順を出力）で次の3点が重なっていると判明した。

1. **白い縁取り（ハロー層）が1つも配置されていなかった**（`route-arrow-halo` rendered=0、
   `route-arrow` rendered>0）。MapLibreのシンボル衝突判定はレイヤーの上から順に配置するため、
   先に置かれた主層（上）の矢印と同じアンカー・1.4倍サイズのハロー層（下）が「衝突」として
   全て落とされる。`icon-allow-overlap:false`だったT293当初からの潜在バグ。
2. **矢印層が区間色分け線（`route-detail-segments-line`、幅6px・不透明）の下にあった**。
   矢印層はページ表示直後（routes=[]での`drawSelectedOutline`）に、色分け線は最初の生成後に
   `beforeId`無しで作られるため、作成順で常に色分け線が上になる。T293当初から同じ構造。
3. **既定の色分けモード（勾配）の色が矢印と同系の紺**（`#0a09ce`等、軸スタジオ由来の配色）。
   縁取りが無く、線の下にあり、同色——の三重で完全に沈んだ。T293の実機確認時は既定モードが
   風（配色が異なる）だったため、1・2の潜在バグがあっても紺の矢印が線から覗いて見えていた。
   その意味で「見えなくなった」契機は既定モードの変更（T433以降のカタログ駆動化・T549）だが、
   根本原因は1・2。

診断の副産物: devDBの道路データはz12タイル16枚（緯度35.53〜35.82、経度139.57〜139.92）のみ。
既定起点（35.7597,139.7387）で20kmはbboxが範囲外で「道路データ未整備」、都心（35.675,139.746）
10kmは折返し点15件すべて「no return path found」で候補0件（原因未調査、T531側の課題として別途）。
東京駅（35.6817,139.7634）20kmは8候補生成できる。

## 対応（実装済み、`frontend/src/components/Map/MapView.tsx`）

- `ensureRouteArrowLayer`: ハロー層・主層とも`icon-allow-overlap: true`・
  `icon-ignore-placement: true`へ変更（衝突判定を無効化し、縁取りが必ず主層と同じ位置に出る）。
  作成後に`keepRouteArrowsAboveDetailSegments`（新設）で、既存の色分け線・当たり判定線を
  矢印ハローの直下へ`moveLayer`。
- `drawDetailSegments`: 色分け線（`DETAIL_LAYER_ID`）・当たり判定線（`DETAIL_HIT_LAYER_ID`）の
  作成時に`beforeId=ROUTE_ARROW_HALO_LAYER_ID`（存在すれば）を指定。
- 結果の重ね順: `route-detail-segments-line` → `route-detail-segments-hit` →
  `route-arrow-halo` → `route-arrow`。

## 検証結果（Playwright `arrow_verify.mjs`、修正後）

- レイヤー順が上記のとおりになり、ハロー層がズーム15で6件・主層5件配置（修正前はハロー0件）。
- ズーム15のスクリーンショット（scratchpad `verify_zoom15.png`）で、紺色の区間色分け線上に
  白縁取り付きの矢印が約80px間隔で並ぶことを目視確認。
- 「ルート」チップOFF→ONで矢印の`visibility`がnone→visibleへ戻る（T518/T524の回帰なし）。
