# T921: 勾配レンズの段階を1%刻みへ細かくし、配色を0（平坦）を境に分ける

状態: 未完了（2026-09-17起票。コード側は実装済み、残りは軸スタジオ経由のDB反映）

## 背景

勾配レンズの段階は`[-2,2,6,10]`の5段階で、クライマーが気にする1%単位の差が1つの帯に
潰れている。配色も青→赤の2色補間のため、平坦帯（-2〜2%）が濃い青になり「ほぼ平坦な
道が全部青く塗られる」状態になっている。段階を細かくするだけでは隣り合う帯の色が
見分けられないため、配色（0を境に下り／平坦／上りへ分ける）とセットで扱う。

## 対応方針

- 段階の境界は`axis_definitions.display_thresholds_override`（DB行データ）が正本のため、
  値そのものの変更は軸スタジオのAPI経由で行う（CLAUDE.md「コミット時の同期ルール」）。
  コード側は同じ刻みを`valueScale.ts: SIGNED_MATERIAL_BOUNDARIES`（上書きが無い軸の
  既定値）へ揃えるだけにする。
- 配色は`bandColorsFor(kind, boundaries)`1本へ集約し、符号付き材料は**0を含む段階を境に
  下り側（青→平坦色）と上り側（平坦色→黄→赤→暗赤）で別々に補間**する。0の位置は
  `boundaries`から求めるため、しきい値を変えても配色の分かれ目が追従する。
- ルート確定後のルート線も同じ`bandColorsFor`を通す（従来はルート線側が自前で2色補間して
  おり、同じ軸の同じ段階が別経路で色付けされていた）。

## 実装メモ（2026-09-17）

- 既定の刻みは`[-10,-5,-1,1,2,3,4,5,6,7,8,10,13]`。上り側は1〜8%を1%刻みにし、それ以上は
  10・13で区切る。下り側は3段階（踏まずに済む側は1%の差の意味が小さい）。配信値は0.1%まで
  保持しているため1%刻みは表現できる（`services/gradient_way_service.py`の`round(..., 1)`）。
- 隣接段階のΔE（CIE76）は最小9.7・最大46.3。最小は上り8%以上の暗赤側3段階
  （色相を動かせず明度だけで分ける範囲）。
- 中継点を通る補間（`interpolateColorStops`）を足した。2色補間のままでは段階を増やすほど
  隣同士が近づき、1%刻みの意味が無くなる。

## 残り（完了条件）

1. 勾配軸の`display_thresholds_override`を上記の刻みへ変更する。**開発DB・本番DBの両方**へ
   反映する（[docs/deployment-sync.md](../deployment-sync.md)）。
   `display_thresholds_override`は`_COSMETIC_ONLY_FIELDS`（`domain/axis_definitions.py`）の
   ため、**公開したままPUT 1回で更新できる**（unpublish→republishの間、本番の軸カタログから
   勾配が消える時間を作らずに済む）。軸スタジオのGUIからでも、次のようにAPIを直接叩いても
   よい（`display`はレスポンス専用フィールドで、書き込みのStrictModelが弾くため落とす）:

   ```bash
   BASE=<backendのURL>; AUTH=<ADMIN_BASIC_AUTH_USERNAME>:<ADMIN_BASIC_AUTH_PASSWORD>
   curl -sS -u "$AUTH" "$BASE/api/admin/axis-definitions/gradient" \
     | python3 -c 'import json,sys; d=json.load(sys.stdin); d.pop("display",None); \
       d["display_thresholds_override"]=[-10,-5,-1,1,2,3,4,5,6,7,8,10,13]; print(json.dumps(d))' \
     | curl -sS -u "$AUTH" -X PUT "$BASE/api/admin/axis-definitions/gradient" \
       -H 'Content-Type: application/json' --data-binary @-
   ```
2. `backend/scripts/dump_axis_definitions_snapshot.py`で
   `backend/fixtures/axis_definitions_snapshot.json`を再ダンプしてコミットする。
3. 本番で勾配レンズを開き、平坦帯が緑・上りが黄〜赤・下りが青で塗り分かれること、
   凡例のチェックで平坦帯を消せることを実機で確認する。
