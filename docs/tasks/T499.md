# T499: 地図上の色分け凡例を追加（勾配・風・ramp軸）

## 状態

完了(2026-08-31)

## 背景

ユーザー要望「地図上の色付の凡例が欲しい。例えば、勾配ONにした時に青くなる道路は何なのか、
その度合いが分かればいい」。ルート設定パネルの凡例チップの「地図で色分け」アイコンを
ONにすると地図の道路が色分けされるが、色→値の対応を示す凡例が地図上のどこにも無かった。

## 対応方針

AskUserQuestionで確認し、「色分けON中は地図の隅に常時小さく表示（複数軸同時ONなら
積み重ね）」を採用した。色・しきい値のデータ自体は既存の色分けロジック
（windAxisLayer.ts/gradientAxisLayer.ts/axisLayers.ts）に既にあるため、そこから凡例
（色→ラベル）を組み立てて表示するだけでよいと判明した。

## 実装

- `frontend/src/components/Map/mapColorLegend.ts`（新規）: `MapColorLegendBand`型
  （`{label, color}`）・`rangeStepLabel`（axisLayers.ts: `axisRampBandLabel`と同じ
  「未満/以上/〜」表記規則）・`buildRangeLegendBands`（boundaries配列+colors配列→
  ラベル付き凡例段階）を持つ共通ロジック。ramp軸の凡例（`axisLayers.ts:
  buildAxisRampLegend`）はMapLayersPanel等の絞り込みフィルタと共有する`LegendEntry`
  （`filter`必須）を返すが、windAxis/gradientAxisには絞り込み機構自体が無いため、
  意味の無い`filter`を捏造せずに済むこの軽量な専用型を新設した。
- `frontend/src/components/Map/gradientAxisLayer.ts`: `gradientAxisLegend(boundaries?)`
  を追加。`buildGradientColorExpression`と同じ配色（COLOR_DOWNHILL→GRADIENT_COLOR_HARD）・
  しきい値（未指定時GRADIENT_BOUNDARIES）から凡例を組み立てる（値は符号付き%）。
- `frontend/src/components/Map/windAxisLayer.ts`: `windAxisLegend(boundaries?)`を追加。
  `buildWindPenaltyColorExpression`と同じ配色（`rampColorForBand`、ramp軸と共通の
  緑→赤系統）・しきい値（未指定時WIND_AXIS_THRESHOLDS）から凡例を組み立てる
  （値は符号付きm/s）。
- `frontend/src/components/MapColorLegend/MapColorLegend.tsx`（新規）+
  `MapColorLegend.module.css`（新規）: 凡例を地図左下に表示するUI部品。`.locateButton`/
  `.locateError`（page.module.css、地図右下）と同じ間隔・見た目の慣習（position:
  absolute、MapLibre帰属表示と重ならない間隔、box-shadow）に揃えた。複数軸同時ONの
  場合は縦に積む。
- `frontend/src/app/page.tsx`: `mapColorLegendGroups`（useMemo）を新設。ramp軸
  （`axisVisibility`、既存の`buildAxisRampLegend`を流用）・windAxis/gradientAxis
  （`showWindAxis`/`showGradientAxis`、新設の`*Legend`関数）の3系統を横断して
  「今ONになっている軸の凡例」を集める。`<MapColorLegend groups={...} />`を
  `mapPane`内（MapView・MapOverlayControlsと同じ階層）へ追加。

## 検証結果

- `npx vitest run`: フロントエンド全体99ファイル887件全て成功（新規テスト2ファイルぶん
  [gradientAxisLayer.test.ts/windAxisLayer.test.ts]の`*Legend`関数テストを含む）。
- `npx tsc --noEmit`・`npx eslint src/`: エラーなし（`.next/dev/types`の既知の
  自動生成物起因の無関係なエラーを除く）。
- Browserペインで実機確認: デスクトップ・モバイル(375x812)いずれも、勾配の色分けを
  ONにすると地図左下に「勾配」見出し+5段階（-2%未満〜10%以上、青→赤）の凡例が
  表示されることを確認。風も同様（-6m/s未満〜6m/s以上、緑→赤）。両方同時ONにすると
  2つの凡例が縦に積み重なって表示されることも確認した。

## 残課題

- ramp軸（surface_q等）の凡例は今回のBrowserペイン実機確認では別軸（勾配・風）の
  確認を優先し個別確認していないが、`buildAxisRampLegend`を流用しているだけで
  新規ロジックを追加していないため、既存のramp軸凡例（MapLayersPanel等）と同じ
  正しさで動作するはずである。
