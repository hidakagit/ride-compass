# T206. 積雪・凍結情報（JMA「今後の雪」タイル） 規模S〜M — トリガー: 冬季前（毎年11月）またはユーザーからの着手指示

状態: 未完了


- 発端: ユーザー要望（2026-08-22）。JMA「今後の雪」タイル配信
  （`https://www.jma.go.jp/bosai/jmatile/data/snow/targetTimes.json`、200 OK実機確認済み。
  `snowd`積雪深・`snowf01h`〜`snowf72h`各時間降雪量を含む）が候補。関東平野部では対象日が限定的だが、山間部ロングライドでは凍結・積雪が
  「回避一択」の危険になりうる。
- 対応方針（トリガー到達時）: 表現形式（rasterTileの面表示 vs 警告バッジ）・評価軸に
  組み込まない方針（凍結は危険側、警告表示のみ）を含めて着手前に再検討する。
  当初想定していたOpen-Meteo経由の積雪変数（`snowfall`・`snow_depth`・
  `freezing_level_height`）への相乗りは、[T645](T645.md)で予報がMSMのローカル同期へ
  移行したため成立しない——MSMの配信変数（`msm_client.py: FORECAST_VARIABLES`が選ぶ
  地上要素）に積雪・凍結高度は無い。取りうる経路は(1) JMAの雪タイル、
  (2) 降水量と気温から雪を判定する（`domain/weather.py: derive_weather_code`と同じ考え方）、
  (3) `jma_msm_upper_level`の気圧面気温・ジオポテンシャル高度から凍結高度を自前計算する、
  のいずれか。着手時に選ぶこと。
- 完了条件（着手時に確定）: 積雪・凍結の警告が該当時期・該当地点で表示され、対象外
  シーズンは取得自体を行わずUIにも出ないこと。
