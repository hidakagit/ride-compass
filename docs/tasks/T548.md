# T548: おすすめ度（total_score）システムの全面撤去、候補タブ並び順をoverall_difficulty基準へ

状態: 完了（2026-09-03）

## 背景

ユーザーから「おすすめ度の数字が極端。ルート生成ロジックの距離誤差でほぼ決まっていて
参考にならない」と指摘を受け、まず`normalize_min_max`（`domain/scoring.py`）へ
`min_meaningful_range`（候補間の実差が小さければ0/100への誇張を抑える）を導入する
対応を行った（[T548着手前の別コミット](../../CHANGELOG的な位置付けは無いためコミット
ハッシュ5d5ff43参照)、`scoring.yaml`の`difficulty_min_meaningful_range`で設定）。

その後のやり取りで、根本的には「おすすめ度（total_score）自体を無くし、候補タブの
並び順を`overall_difficulty`（絶対基準0-100、distance_toleranceで既に絞り込み済みの
候補間を難易度昇順）で決めればよいのでは」という提案があり、ユーザーが明示的に選択：

- 候補タブの並び順: `total_score`降順 → `overall_difficulty`昇順（易しい候補が先頭）
- 「おすすめ度」の数字表示: 削除
- 研究モードの距離/難易度重み設定UI（WeightPanel）: `total_score`が無くなり意味を
  持たなくなるため、ユーザー指摘によりあわせて削除
