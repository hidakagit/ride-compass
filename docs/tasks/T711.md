# T711. UI/CSSの重複と未定義トークンを是正する 規模M

状態: 未着手（2026-09-10起票、統合レビュー第6回 P2/P3の束ねE。対象11件）

## 背景

[T676](T676.md)（UI/CSSの重複と不整合を解消）・[T675](T675.md)（未定義CSSトークン検知）の
**取り残しと、検知をすり抜けた新規分**が11件。すり抜けの原因はフォールバック付き参照
（`var(--x, 既定値)`）が検知対象外であること（パターン側の修正は[T705](T705.md)）。

## 対象

### 未定義トークン（フォールバック付きのため検知をすり抜けた）

| 参照 | 場所 | 状態 |
|---|---|---|
| `--shadow-md` | `RideConditionBar.module.css:28` | 未定義（定義は`--shadow-float`のみ）。出発時刻ポップオーバーだけ他の浮きパネルと異なる濃い影 |
| `--font-size-xs` | `LensControl.module.css:119`（0.72rem）／`AxisStudio/DerivedDataFreshnessPanel.module.css:81`・`MaterialCoveragePanel.module.css:82`（0.75rem） | **参照3箇所・定義0件・実効値2種**。定義した瞬間に3箇所の見た目が同時に変わる |
| `--color-warning-soft` | `RouteAxisProfile.module.css`・`LensControl.module.css` | 未定義（`rgba(217,119,6,0.15)`の直値が2ファイルへ複製） |

`--color-warning-strong`（`#b45309`）は`:root`のみでダークの`@media`ブロックに再定義が無く、
ダークテーマでパネル面（`#2a2a2d`）上のコントラスト比が**約2.85:1**（WCAG AA 4.5:1未満、
0.65remの小さい文字）。T676が`error.tsx`の`#666`（約3.4:1）として直した欠陥と同型。

### 重複

- 「未使用」バッジのスタイルが`RouteAxisProfile.module.css:82-89`と
  `LensControl.module.css:155-162`にほぼバイト単位で重複し、**本範囲でRouteAxisProfile側だけ**
  `font-size: 0.68rem→0.65rem`・`padding: 0 0.35rem→0 0.25rem`へ変更されて食い違った。
- `MapOverlayControls.module.css:523-541` `.visibilityInfoButton`が
  `ui/roundIconButton.module.css`と同じ宣言をサイズ違いで手書き（同ファイルの`.expandToggle`は`composes`済み）。
- `MapOverlayControls.module.css:490-545` `.visibilityCheckbox`系が共有`ui/Checkbox/Checkbox.tsx`と
  同一の見た目仕様をCSSで再実装。正当化コメント「MapOverlayControls全体がネイティブフォーム
  コントロールを使わずbutton+aria-pressedで統一している」は、**同ファイルの
  `MapOverlayControls.tsx:269`が既に共有Checkboxを使っているため成立しない**。
  同じパネル内にRadix Checkboxと文字「✓」ボタンの2種類が並ぶ。
- `LensControl.tsx:155-162`が`<input type="checkbox">`を直接使う。
  リポジトリ全体でネイティブcheckboxを残す唯一の箇所（他5ファイルは`ui/Checkbox`）。

### 語彙・配色の不整合

- `staticAttributeLayers.ts:298` — 新規追加した停止要因POIカテゴリ`barrier`にオレンジ`#ea580c`。
  同ファイル`:39-46`が「停止要因POIの種別は評価配色（緑・アンバー・オレンジ・赤の系統）を避けた
  中立色を使う」と定めている。`AXIS_RAMP_COLORS[2]`（`#fb8c00`）と同系のため
  「車止め・ゲート」が危険側の色に読める。`traffic_calming`の`#0d9488`（`:299`）は
  補給休憩POIの「給水」（`:322`）と同一色で、両レイヤーは同時ONにできる。
- `WeatherPanel/weatherCode.ts:109-116` — `CATEGORY_LABEL`/`ICON_BY_CATEGORY`/`get*Display`の構造が
  `WeatherPanel/amedasWeatherIcon.ts:32-58`とほぼ同一で、**同じ`"clear"`カテゴリ・同じ`SunIcon`に対して
  ラベルが「快晴」と「晴れ」で食い違う**。ヘッダー（アメダス実測）が「晴れ」、
  真下の「今日の見通し」（MSM予報）が同じアイコンで「快晴」と出る。
- `ui/statusDot.module.css:10` — 本範囲で新設したこのファイルに「（設計原則8）」が残り、
  `frontend/src`全体で番号付き「設計原則N」を含む唯一の箇所。
  同じ範囲の[T671](T671.md)が6ファイルから平文表現へ置換している最中に、移設元の文言を
  そのままコピーして持ち込んだ。`設計原則8`は`docs/design-principles.md`の現行番号体系に存在しない。
- `app/global-error.tsx:28` — `error.tsx`は本範囲で`#666`→`var(--color-muted)`へトークン化されたが、
  対の`global-error.tsx`は`#666`のまま。`globals.css`を読まないためトークン化できないという事情が
  ありうるが、その理由がどちらのファイルにも書かれていない。
- `MaterialRangeHint.tsx:12-19` — docsは「材料選択行の**下**に出す1行表示」と述べるが、
  実装は`.termRow`（`flex-wrap: wrap`）の子としてⓘボタンと係数スライダーの**間**にインライン配置。
  狭幅では「select / ⓘ / 実データ: p50=… / スライダー / 数値 / 必須 / ⓘ / 削除」が不規則に折り返す。

### 規約違反（同じコミット範囲で新設された規約に対して）

- `app/page.tsx:62` — `@/components/MapLayersPanel/MapLayersPanel.module.css`を直接importし
  `:1523`で`layerPanelStyles.group`を使う。本範囲で新設された
  `docs/frontend-design-system.md:100-103`が「別コンポーネントの`*.module.css`を直接importして
  借りない（CSS Modulesは存在しないクラス名に`undefined`を返すため、貸し手側の改名が
  無スタイルのまま本番へ出る）」と禁じている**唯一の違反**で、
  しかも「問題なく使える」と正当化するコメントが付いている。
  `components/ui/*`を借りる他2ファイルは規約が認める共有先。
