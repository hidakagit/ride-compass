# T849. 鮮度台帳が、バッチの対象外の行を「未計算」と数え続ける

規模S〜M。
状態: 着手（2026-09-14起票。ユーザー報告「鮮度台帳をつくり直しても未計算が残っている」から）

## 背景

本番で`refresh_derived`を完走させても`road_edges.curvature_deg_per_km`の未計算が
5,047,354件中2件残る。これは作り直せば消える取りこぼしではなく、**バッチが永久に対象外に
している行**である——`precompute_edge_curvature`の対象は`distance_m > 0`に絞られ（長さ0では
度/kmを測れない）、台帳側の判定は`curvature_deg_per_km IS NULL`のため、計算されない行を
未計算として数え続ける。

結果として台帳は「すべて最新」へ到達できない。常に「N件が作り直し待ち」と出続ける表示は、
そのうち誰も読まなくなる。

way単位では同じ問題が既に解かれている（`WayGeometryRow`が「行が無い＝未計算、列がNULL＝
算出不能」の2状態を持つ）。road_edgesの列は1つしか無く、その区別を表せない。
