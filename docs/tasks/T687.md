# T687. 軸単体で経路を評価できるよう、得点の隣に物理量を出す 規模M

状態: 未着手

## 背景

ルート結果の軸の値（0〜100）だけでは、その軸単体で経路の良し悪しを判断できない。
実際に走ってストレスのあった経路が停止密度10と出て「楽に見える」という報告があった
（2026-09-08）。

原因は目盛りの引き方ではなく、**同じ生値が区間とルートで意味が変わる**こと。

| 生値 | 区間として見ると | ルート平均として見ると |
|---|---|---|
| 0.8回/km | 静かな裏道（幹線は4.8〜7.4回/km） | 32kmで26回止まる＝多い |

区間の分布に合わせて目盛りを引くとルート値は低く出る。ルートの分布に合わせると区間側で
幹線がすべて満点に潰れ、ルーターが最悪の道を選り分けられなくなる。**1つの目盛りで両方を
正直にはできない。** さらにルート値は重みを上げるほどルーターがそれを最小化するため、
目盛りをどう引いても低い値へ戻る（[T655](T655.md)の再較正で実証: 4.1→2.9）。

「他の軸（自転車インフラ91.5・車の圧迫感59.3）を見れば悪い経路だと分かる」という説明は、
**軸を独立して扱えるという設計の否定**になるため採らない（ユーザー判断、2026-09-09）。

## 対応方針

得点（相対評価）の隣に**絶対の事実**を併記する。「約26回」と言われれば、他の軸を見ずに
判断できる。
