# T627. 「ルート結果」の情報アイコンを総合難易度の隣へ移設 規模S

状態: 完了（2026-09-06）

## 背景

ユーザー指摘: 「ルート結果パネルのタイトルの説明（情報アイコン）は、総合難易度の説明。
パネル内の総合難易度のところに移動して」。「ルート結果」見出し脇の情報アイコン
（`ROUTE_RESULT_HINT`、`FieldLabel`）は、内容が実際には総合難易度の説明
（「距離・軸重みを反映した絶対値...候補タブはこの値が小さい順に並びます」）だったが、
T545フォローアップで見出し1箇所へ集約する形になっていた。説明の対象（総合難易度の表示）
から離れた場所にあるのが分かりにくいという指摘。

## 対応内容

- `RouteAxisProfile.tsx`: 「総合難易度」の表示（`/100 総合難易度`）の隣に、既存の
  「負荷（難易度×距離）」の説明ポップオーバーと同じ形（`InfoPopover`、
  `RouteSettingsPanel.module.css`の`legendInfoButton`/`legendInfoPopover`）で
  説明文を追加した。
- `page.tsx`: `ROUTE_RESULT_HINT`定数・`renderRouteResultHeaderActions()`内の
  `FieldLabel`呼び出しを削除。ヘッダは保存・GPX出力・ルートをクリアの操作アイコンのみを
  持つ形になった。未使用になった`FieldLabel`のimportも削除。

## テスト

`RouteAxisProfile.test.tsx`へ、総合難易度に説明ポップオーバーが付くことを検証する
テストを追加。
