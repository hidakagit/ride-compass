# T508: 走行方位アイコンの左右位置をMapLibreコントロールへぴったり揃える

## 背景

T507でアイコンの配色・サイズをMapLibreの`.maplibregl-ctrl-group`と揃えたが、ユーザー
指摘（2026-08-31）:

> アイコンの見た目ok
> maplibreのアイコン位置と微妙に縦が揃っていない。

## 原因

`.trigger`の`right`にアプリの余白トークン`--space-3`（デスクトップ0.75rem=12px、
ブレークポイントにより0.55rem=8.8px）を使っていた。MapLibreの`.maplibregl-ctrl-top-right`
自身のmargin（固定10px、テーマ・ブレークポイントに関わらず変わらない）と一致せず、
2px（デスクトップ時）左右にずれていた。

## 対応

T507で配色・サイズをMapLibre自身の固定値へ揃えたのと同じ考え方で、`right`もトークン
ではなく`10px`を直書きしMapLibre自身の値へ揃えた。

## 検証結果

- 修正前: `navGroupRect.left=1241`に対し`triggerRect.left=1239`（2pxのずれ）。
- 修正後: `navGroupRect`と`triggerRect`のleft/rightとも完全一致（diff=0）を
  `localhost:3010`で座標比較して確認。スクリーンショットでもズーム+/−・回転
  コントロールの真下に縦の辺が揃って見えることを確認した。
- `npx tsc --noEmit`・`npx eslint src/components/TravelBearingControl/`: エラー無し。
- 状態: 完了。
