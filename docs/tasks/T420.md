# T420. キキクル+線状降水帯予測マップを既定ONにする 規模S

状態: 完了（2026-08-30）

- 背景: T410で実装したキキクル（危険度分布：土砂・大雨・浸水）+線状降水帯予測マップは
  既定OFF（他の動的レイヤーと同じ「設計原則12: 明示的にONにして初めて出る」規約）
  だった。実機フィードバック「キキクルのような防災級の情報は、ユーザー操作を待たず
  表示すべきでは（予兆があってからチップをONにするのでは手遅れ）」を受け、常時ON化を
  検討した。
- 検討過程（別タスクT412に分離済み）: 常時ON化の前提として、JMA動的タイル系レイヤー
  全般がフロントエンド直接fetchでバックエンド非経由だった問題を解消（T412、プロキシ+
  キャッシュ導入）。
- 「複数の危機が同時に迫っているときの表現」（防災アイコン1つへ集約する案）も検討したが、
  **キキクルには現在の警戒レベルを返すJSON APIが存在せず**（JMA公式ページの実機確認、
  配信されているのはラスタ画像のみ）、正確な警戒度判定にはピクセル解析等の新規実装が
  必要と判明。既存のJMA警報・注意報バッジ（WarningBadge、T205）が近い役割を果たすため、
  キキクル専用の集約バッジは見送り、シンプルに「既定ON」のみで対応する方針にユーザー
  確認のうえ決定した。

## 実装メモ

- `frontend/src/app/page.tsx`の`FIXED_LAYER_VISIBILITY_DEFAULTS`で、
  `landslideRisk`/`heavyRainRisk`/`inundationRisk`/`linearRainbandRisk`の4キーを
  `false`→`true`に変更（`route: true`と同じ「設計原則12の例外」パターン）。ラスタタイルは
  危険度ゼロの場所では実質透明（T410実装メモ参照）なので、既定ONでも平常時の地図の
  見た目は変わらない。チップ自体（ON/OFF切り替え・凡例表示）はそのまま残し、
  MapOverlayControls/MapLayersPanel側の変更は不要（既定値の変更のみで完結する
  最小差分の実装）。
- 実機確認（Browserペイン）: localStorageの`ridecompass:layer-visibility`をクリアした
  「初回ユーザー」状態でページを開き、チップを一切操作せずに`risk/targetTimes.json`・
  土砂/大雨/浸水のラスタタイルPNGが自動的にfetchされることを確認した。
- `npx tsc --noEmit`・`npx vitest run`（790件）とも成功。
