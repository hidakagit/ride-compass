# T918. 路面タイルの単位を、区間が読めるズームでは区間（edge）にする

状態: 着手中
規模: L

## 背景

[T917](T917.md)の計測で、gzip後の費用と区間単位の情報量が、ズームで逆向きに効くことが
分かった。詳細はT917参照。境界をz14に置く（z14以上=区間、z13以下=way）。

同じ「区間ごとの値」をルート前はway近似・確定後は区間実値で作り分けている状態を畳む。

## 段階

1. タイルの単位をズームで切り替える（`feature_key`追加・世代bump）
2. 値の配信を`feature_key`鍵へ（低ズームはそのwayの最急へ差し替え）
3. フロントの`promoteId`切り替え
4. way単位で意味を持つ材料の扱いを決める
