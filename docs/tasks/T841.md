# T841. 地図でできることを、いま見ているパネルが持つ操作だけにする

規模S〜M。
状態: 完了（2026-09-14）

## 方針（ユーザー判断、2026-09-14）

| パネル | 地図でできること |
|---|---|
| ルート設定（条件タブ） | 出発地・経由地・目的地を置く／つかんで動かす／消す |
| ルート結果 | 候補の切り替え、区間詳細（赤ピン） |
| ルート編集（区間の乗り換え） | 乗り換え先の区間を選ぶだけ（元ルートは固定） |

**これ以外の操作はできない**。地図を触った副作用で、いま見ていない面の状態が変わらないようにする。

## 照合した結果（着手時点）

| 地図の操作 | 実装 | 着手前の条件 | 方針とのずれ |
|---|---|---|---|
| ピンを置く | `handleClick`＋`armedPinRole` | ルート設定×条件タブ×目的地モードで武装中のみ（[T781](T781.md)） | なし |
| 出発地マーカーを動かす | 出発地マーカーの`dragend` | **常時** | ずれ（結果・編集を見ている間も動く） |
| 経由地マーカーを動かす／押して消す | 経由地マーカー | **目的地モードなら常時** | ずれ |
| 目的地マーカーを動かす／押して消す | 目的地マーカー | **目的地モードなら常時** | ずれ |
| 候補線を押して切り替え | `handleCandidateClick` | **常時** | ずれ（編集中に押すと元と地図が食い違う） |
| 区間詳細（赤ピン） | `handleRouteSegmentClick` | 編集中以外（[T808](T808.md)で対応済み） | ずれ（ルート設定を見ている間も選べる） |
| 乗り換えの帯を押す | `handleSpliceStretchClick` | 帯は編集中しか描かれない | なし |
| 道路・POI・面レイヤーのポップアップ | `handleClick`の汎用ディスパッチ | 常時 | **方針の対象外と判断**（後述） |

## 汎用ポップアップを対象外にした理由

道路属性・POI・災害面などのポップアップは、ルートを作る操作ではなく**地図そのものを読む**機能
（地図レンズ）。パネルに紐付けて塞ぐと、ルート結果を見ている最中に道路の素性を確かめられなく
なる。ルートの状態を変えないため、方針の「地図を触った副作用で状態が変わる」にも当たらない。

## 実装

`page.tsx`に2つの判定を置き、地図へ渡す。

- `pointEditingEnabled` = ルート設定が見えている×条件タブ×編集中でない
- `routeInspectionEnabled` = ルート結果が見えている×編集中でない

`MapView`は`pointEditingEnabled`で3種のマーカーの`draggable`とクリック（消す）を切り替える。
出発地マーカーだけは**作り直さずに`setDraggable`だけ切り替える**——作り直すeffectはカメラ移動
（`flyTo`）を伴うため、パネルを切り替えるたびに地図が飛ぶ。

デスクトップは区分の開閉が「見ているか」にあたるため、設定と結果を両方開いていれば両方できる
（モバイルはシートが排他）。
