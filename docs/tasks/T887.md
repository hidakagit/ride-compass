# T887. 土地被覆の材料を、1クラス＝1材料で足せる形にする

規模M。
状態: 完了（2026-09-16起票・同日実装。[T885](T885.md)の議論から、ユーザー要望「後から使いやすい形で
正規化して材料にできるならそうしておきたい」「今みたいなよくわからないまぜこぜな何かに
なっちゃうなら使いにくい」）

## 背景

`way_landcover`は8クラスの割合を持つが、材料として配線されているのは`trees_percent`と
`built_percent`の2つだけ。残りは[T885](T885.md)で実測したとおり、まだ使える量がある。

    クラス        平均    p99     30%以上のway
    crops       10.9%   100.0      192,766
    rangeland    1.4%    38.9       19,443
    water        0.5%    18.6        5,979
    bare         0.01%    0.0           51
    flooded_veg  0.00%    0.0           41
    snow_ice     0.00%    0.0            0

`crops`・`rangeland`・`water`を材料にする。下位3つは足さない——関東では`30%以上`が
51本・41本・0本で、材料にしても常に0が返るだけであり、軸スタジオの材料一覧を埋める害の方が
大きい。**データはDBに残っているため、対象地域が広がれば再取込なしでいつでも足せる。**

## 1クラス＝1材料。合成しない

材料はそれぞれ1クラスの割合（0〜100%）だけを答える。今の開放度が使いにくいのは、樹木と
建物を足して1つの数字にしているからで、材料の側でそれをやらない。

**8クラスは合計100%になるため、1つの軸で複数クラスを足すと同じ地面を二重に数える。**
[design-principles.md](../design-principles.md)構造仕様14として明文化した。

## 対応（2026-09-16）

### 配線するクラスを1つの宣言から導く

`attributes.py: WIRED_LANDCOVER_KEYS`が唯一の正本になり、次がすべてそこから導かれる。

- `EdgeMaterialBundle.landcover_percents`（クラス別の2フィールドを1つの辞書へ）
- 列指向テーブル（`EdgeMaterialTable`）の`landcover_percents`
  （クラスごとの`np.ndarray`を行×クラスの2次元へ）と、その生成・復元・`to_legacy_dicts`
- `get_edge_materials_batch`のSELECT列とbundleの組み立て
- 路面タイルの焼き込み列（`_LANDCOVER_TILE_COLUMNS_SQL`）
- カバレッジ台帳（`MATERIAL_COVERAGE_SPECS`）の宣言
- `axis_inspector.way_scalar_materials`の引数

### 起票時の判断を変えた: 8クラス全部を配線する

起票時は`crops`・`rangeland`・`water`の3つだけを足し、下位3クラスは「常に0を返すだけ」
として見送る方針だった。2点で改めた。

1. **「常に0」は言い過ぎだった。** 実測の最大値は`bare` 64.5%（河川敷・造成地）・
   `flooded_veg` 97.8%（湿地）・`snow_ice` 22.9%で、稀なだけで存在する。
2. **上の作り直しで、1クラス増やす費用が宣言の1行になった。** 材料一覧をテーブルと
   1対1にしておけば、「なぜこのクラスだけ無いのか」を後から何度も判断し直さずに済む。

効いていることの確認: 5クラスから8クラスへ広げたとき、**テストを1件も変更せずに**
1,984件が通った（すべて`WIRED_LANDCOVER_KEYS`から導かれているため）。

### タイル世代

焼き込み列が増えるため路面タイルの世代が変わる（`cache_identity`が焼き込みSQLから
導出するので手で上げない）。生成物`region-tile-config.json`を同一コミットで再生成した。
## 保留することで何が起きうるか

[T885](T885.md)で`openness`軸を消した後、土地被覆の材料は「軸から使われていないが残す」
状態になる。そのとき2列しか無いと、後で「木陰」「市街地」以外の軸を作ろうとするたびに
同じ5箇所を触ることになり、材料を足す判断そのものが重くなる。
