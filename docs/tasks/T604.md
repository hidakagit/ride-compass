# T604. 降水延長予報gridFillの「未着色」が取得失敗によるものか閾値未満によるものか区別できない

状態: 保留（トリガー付き、2026-09-05起票）

## 背景

ユーザー報告「画面の右端が塗られない」（本番、デフォルト地点[王子]・降水レイヤON・出発時刻
9/6 15:00で再現）を調査。実機の`api:windGridDetail`デバッグログ2件（リクエストbbox・
spacing_deg・応答`points`件数）を、`generate_wind_grid_detail_points`と同じ計算式で
検証したところ、いずれもリクエストしたbboxから理論計算した格子点数と実際の`points`件数が
完全に一致した（24=24、9=9）。つまり**取得失敗によるデータ欠落は無かった**。
