# T625. 走行条件バーをレンズピル直下（地図上部中央）へ移設 規模S

状態: 完了（2026-09-06）

## 背景

ユーザー指摘: 「出発時刻と速度はレンズと同じく画面上部に持っていける？下部パネルを
開いていると隠れて使いにくい」。走行条件バー（`RideConditionBar`、出発時刻・想定速度）は
地図下部中央（`.bottomControlRow`）に置かれていたが、モバイルの`BottomSheet`
（z-index:45）が開いている間、`.bottomControlRow`（z-index:20）より手前に重なり隠れて
しまっていた。

`LensControl`（レンズピル）は既に「モバイルのBottomSheetにも隠れない」地図上部中央の
位置（`top: var(--space-3)`）を使っており、この実績のある位置へ揃える。

走行方位（`TravelBearingControl`）は今回の変更対象に含めない（ユーザー選択、小規模に
留める）。

## 対応内容

- `LensControl.tsx`に`rootRef`（任意）propを追加し、`.wrap`要素へ渡せるようにした。
- `page.tsx`: `useElementHeightCssVar`でレンズピルの実測高さを`--lens-control-height`
  として`.mapPane`へ反映（既存の`--bottom-control-row-height`と同じパターン）。
  `RideConditionBar`を`.bottomControlRow`から独立させ、新設した`.rideConditionRow`
  （レンズピル直下、`top: calc(space-3 + var(--lens-control-height) + space-2)`）へ移設。
- `page.module.css`: `.rideConditionRow`を新設。`.bottomControlRow`は全レイヤー一括OFF
  ボタンのみを持つ形へ縮小。
- `docs/modules/frontend/page-composition.md`・`route-settings-and-results.md`の
  「地図下部の条件バー」という記述を「地図上部中央（レンズピル直下）」へ修正。

## 検証結果

- `tsc --noEmit`: エラー無し。
- `npx vitest run`: 113ファイル1022件通過。
- `npx eslint .`: エラー無し。

## フォローアップ（2026-09-06）: レンズ直下→走行方位アイコンの隣（右上）へ再配置

ユーザー指摘: 「レンズの横に収められない？スマホだと画面が小さい。地図表示する領域を
なるべく狭めたくない」。レンズピル（最大14rem≒224px）と当時の走行条件バー（テキスト
チップ2つ、約180-200px）を横に並べると合計400px超になり、幅375px前後のスマホでは
収まらない。真に幅を抑えるには走行条件バー自体をコンパクト化する必要があると判断し、
ユーザーへ3案（アイコンボタン化/テキスト短縮/走行方位への集約）を提示、「レンズと並べず、
走行方位の隣（右上）へアイコンとして集約」を選択。

**対応内容**:
- `RideConditionBar.tsx`: 2つのトリガーを、テキストチップ（「出発 5:31 ▾」「20 km/h ▾」）
  から`TravelBearingControl`と同じ29px四方のアイコンボタンへ変更（出発時刻=`ClockIcon`、
  想定速度=新設`SpeedGaugeIcon`[`Map/icons.tsx`]）。値はポップオーバーを開くまで表示しない。
  ポップオーバーの開く向きも`side="left"`へ変更（右上配置のため画面外へはみ出さないよう）。
- `RideConditionBar.module.css`: `.bar`を横並びから縦積み（`flex-direction: column`）へ、
  `.chip`系クラスを`.trigger`（`TravelBearingControl.module.css: .trigger`と同じ見た目）へ
  置き換え。
- `page.tsx`/`page.module.css`: T625本編で追加した`lensControlRef`・
  `useElementHeightCssVar(..., "--lens-control-height")`・`LensControl`の`rootRef`prop・
  `.rideConditionRow`は不要になったため削除。代わりに`.rideConditionColumn`
  （`TravelBearingControl`の`top: 6.5rem`・29px四方と結合したtop位置、右上）を新設し、
  `RideConditionBar`を`TravelBearingControl`の直下へ積んだ。
- Playwright（Chromium、`/opt/pw-browsers/chromium`）でdev server起動→スクリーンショットを
  取り、ズームコントロール・走行方位・出発時刻・想定速度の4段が均等な間隔で並ぶこと、
  両方のポップオーバーが画面内に収まって開くことを実機相当の見た目で確認した。
- 関連docs（`page-composition.md`・`route-settings-and-results.md`）の「レンズピル直下、
  地図上部中央」という記述を「走行方位アイコン直下、地図右上」へ修正。

**検証結果**: `tsc --noEmit`・`npx vitest run`（113ファイル1022件）・`npx eslint .`いずれも
クリーン。
