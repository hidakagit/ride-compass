# T742. 残骸の撤去 規模S

状態: 完了（2026-09-12。起票は2026-09-11、統合レビュー第7回 P3束ね）

## 背景

対象5件。`route_preference.py`末尾の孤立コメント、`.settingsGroup`の到達不能セレクタ、`export_openapi.py`の「廃止したものの記録」だけのコメント塊ほか。

詳細な指摘（Evidence・Impact・Root Cause・Recommendation）は[history/2026-09-11_all.md](../../.claude/commands/review/history/2026-09-11_all.md)を参照。

## 対象の確定

第7回のP3個票は残っていない（[T752](T752.md)）。名前が挙がった3件を直すだけでは届かないため、
残骸の型ごとに母集団を機械的に数えた（[design-principles.md](../design-principles.md)構造仕様12）。

| 型 | 候補 | 本物 | 偽物の中身 |
|---|---|---|---|
| 兄弟セレクタが要求する数だけ同じクラスが出てこないCSS | 3件 | 1件 | 2件は`key=`付きで`.map()`から並ぶ要素（実行時には複数並ぶ） |
| どこからもimportされていないexport | 7件 | 2件 | 5件は自ファイル内で使っており、余分なのは`export`だけ |
| 自ファイル内でしか使わないのにexportしている | 5件 | 5件 | — |

どの型も検知器にはしなかった。CSSの側は偽物が2/3を占め、`key=`の有無や`.map()`の中かを
見分ける必要がある。exportの側は**テストのためにexportする**のがこのリポジトリの既定の
やり方（`MapView.tsx`の大半のexportがそれ）で、「テストからしか参照されない」を違反に
すると母集団の9割が偽物になる。測った結果を根拠に見送り、見つかった分は人が直した。

## 撤去したもの

| 箇所 | 残骸の種類 |
|---|---|
| `route_preference.py`末尾の孤立コメント | 語っている対象（区間インスペクタ）は`axis_inspector.py`へ移っており、このファイルには無い。残す価値のある制約1文（クリックごとに1回計算する参照用途で共有キャッシュに乗らないため、タイル焼き込みの制約が当てはまらない）だけを`axis_inspector.py`のdocstringへ移した |
| `page.module.css`の`.settingsGroup + .settingsGroup` | このクラスが付く要素は1つしか無く、セレクタが一致しない。クラスを付けるためだけにあったラッパー`<div>`も一緒に撤去 |
| `export_openapi.py`の「廃止した生成物の記録」5行 | 生成していないものの一覧。今ある挙動を何も説明していない |
| `recipeControls.tsx`の`RecipePanelSection` | どこからも使われていないコンポーネント（参照はコメントの中だけ）。専用CSS（`.panelSection`等6クラス）と、これだけが使っていたimport 2本も撤去 |
| `useMaterialDistribution.ts`の`clearMaterialDistributionCache` | 「テスト用」と書いてあるが、テストからも呼ばれていない |
| 5件の余分な`export`（`JMA_TILE_BASE_URL`・`jmaTargetTimesUrl`・`JMA_TILE_PROTOCOL`・`rangeStepLabel`・`EMPTY_DEDICATED_WAY_VALUES_RESULT`） | 自ファイル内でしか使わない |

`RecipePanelSection`を撤去したので、それを名指ししていた`LayerChip.tsx`のコメントと
`route-settings-and-results.md`の対象ファイル表も同時に直した（撤去した名前が残ると、
次に読む人が実在しないものを探す）。
