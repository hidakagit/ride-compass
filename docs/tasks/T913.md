# T913. 面レイヤーの差し込み位置が、本番の基礎地図でどこになるか未確認

状態: 未着手
規模: S

## 背景

[T912](T912.md)が入れた`areaLayerAnchorId`（`mapStyleOps.ts`）は「基礎地図が最後に面を
描いたレイヤーの次」を差し込み位置にする。基礎地図（OpenFreeMap liberty）の実レイヤー
構成では道路・地名がこの位置より後ろに並ぶ想定だが、**実物で確認できていない**——起票時の
実行環境から`tiles.openfreemap.org`へもCDNへも出られず、スタイルJSONを取得できなかった。

想定が外れるのは、面（建物のfill-extrusion等）が道路の線より後ろに並ぶスタイルの場合。
そのとき差し込み位置は地名ラベルの手前まで下がり、面が道路を覆う状態がT912の修正後も
残る（地名は覆われないぶん現状よりは改善しているが、目的は達していない）。

## 対応方針

デバッグモードのログ（`map:lifecycle`「面レイヤーの差し込み位置」、`anchorId`）を本番/dev
の実機で読み、道路・地名のレイヤーがそれより後ろにあることを確認する。外れていた場合は
導出を「最後の面の次」と「最初の記号」のより背景寄りの方を採る形へ広げるかを、実際の
並びを見て判断する（並びを見ずに広げると、記号が早い位置にあるスタイルで面が水域の下へ
潜る）。
