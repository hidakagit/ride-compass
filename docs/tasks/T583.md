# T583: 管理画面「材料」タブの表示を簡素化し他タブと統一する

状態: 完了（2026-09-05起票・同日実装、ユーザー指摘）

## 背景

[T577](T577.md)で追加した「材料」タブについて、ユーザーから「画面が説明文で非常に乱雑」
「多くの項目が95%以上欠損に見えるが本当か（見方が分からない）」という指摘があった。

- 見出し直下に3行の説明段落が常時表示され、表は7列（材料・母集団・総数・欠損数・欠損割合・
  欠損時の扱い・判定根拠）で横スクロールが必須だった。
- 「欠損時の扱い」が「不明」（軸が評価対象外になる、実害あり）の材料と「確定」（タグ不在＝
  該当なし、評価に穴は開かない）の材料が同じ表に欠損割合順で混在し、後者の90%超の数字が
  前者と同じ重みで目に入るため「軒並み欠損」に見えていた。

## 対応方針

- 「欠損時の扱い」で表を2グループに分ける（「評価に影響する欠損」／「タグ不在を確定値として
  評価する材料（参考）」）。各グループの説明は1行だけ。
- 表は4列（材料・母集団・欠損割合・欠損 / 総数）に減らし、判定根拠は材料セルの`title`へ。
- 母集団や件数ベースの注記など補足は見出し脇の(i)ポップオーバー（`AxisComposer`の材料説明と
  同じ部品・見た目）へ畳む。
- backend・APIは変更しない（表示の再構成のみ）。

## 実施内容（2026-09-05）

`components/AxisStudio/MaterialCoveragePanel.tsx`・`.module.css`・`.test.tsx`を再構成、
`docs/modules/frontend/axis-studio.md`の「材料」タブ節を更新。
