# T601: T595〜T597の完了条件乖離是正（出発時刻ドラッグタイムライン化・デッドコード/ドキュメント整合）

状態: 完了（2026-09-05起票・同日完了）

## 背景

ユーザー報告「時刻スライダーが出なくなった」を受けT596を調査したところ、`DynamicLayerTimeSlider`
撤去の宣言と実態（未削除）の乖離、および出発時刻UIがドラッグ式タイムラインという期待と
異なる（クイックボタン+datetime-local）ことが判明。これを機にT595・T597・T593も含め
直近UI改修シリーズを監査エージェント2件（general-purpose、T595担当・T597担当）で点検した
結果、同種の「完了条件・ドキュメントの宣言と実装の乖離」が複数見つかった。

## 監査結果（対応前）

- **T596（重大）**: `DynamicLayerTimeSlider`を「削除した」とT596.mdに記載しているが実ファイルは
  未削除（デッドコード化）。出発時刻UIがクイックボタン+datetime-localで、ユーザーが期待した
  「ドラッグ式タイムライン」になっていない。
- **T597（重大）**: モバイルは候補0件時の案内文（emptyHint）が出ず空白のシートになる
  （デスクトップとの「中身の一致」という完了条件に違反）。この不一致を検知できるはずの
  Playwright smokeにモバイルviewport自体が存在せず、vitest側も`useIsMobile`を常にfalseへ
  固定モックしていてモバイル分岐が一度もレンダリングされていなかった。
- **T595（重大〜軽微）**: `route-settings-and-results.md:136`が「重み>0のみ絞り込んで渡す」と
  明記するが実装は絞り込みなし。`map-axis-coloring.md`が同一ファイル内で自己矛盾（末尾だけ
  旧仕様のRouteSettingsPanel起動導線を記述）。`route-settings-and-results.md`の対象ファイル表
  2箇所が撤去済み機能（色分けトグル・チップ列）を責務として記載したまま。`page.tsx`の
  コメント2箇所・`routeStyleModes.ts`のコメント1箇所が削除済み関数
  （`renderMapColorToggle`/`filterRouteStyleModesByPreference`）を参照。
  `RouteSettingsPanel.module.css`に撤去済みボタンのCSSクラスが残存。
- **T593（軽微）**: backendのdocstring（OpenAPI経由でapi.d.tsにも転写）が削除済み
  フロントファイル名（`windAxisLayer.ts`・`gradientAxisLayer.ts`）を参照。

## 対応内容

- **出発時刻のドラッグタイムライン化**: `RideConditionBar`の出発時刻ポップオーバーを
  「クイックボタン+datetime-local」から「クイックボタン+ドラッグ式タイムライン」へ作り直した。
  `DynamicLayerTimeSlider`（未使用化していたコンポーネント）を再利用し、新規
  `RideConditionBar/departureTimeline.ts`（`buildDepartureTimeline`/`buildDepartureFrames`、
  気象レイヤーの実フレームに依存しない自己完結した合成タイムライン。直近60分以上は5分刻み・
  以降48時間先までは正時刻みで、切り替わり目の重複/欠落が出ないようtransitionMsを正時へ
  揃える設計）でタイムラインを生成する。これにより`DynamicLayerTimeSlider`は
  デッドコードでなくなった（削除ではなく再利用で解消）。関連コメント（同コンポーネント
  内の3箇所、旧・気象レイヤー専用の記述）を現在の汎用UIとしての役割に合わせて書き換えた。
- **T597モバイル空状態の是正**: `page.tsx`のモバイル`BottomSheet`（ルート結果）に、
  デスクトップと同じ`emptyHint`分岐を追加。`page.test.tsx`に`renderFreshHome({mobile:true})`
  オプション（`useIsMobile`モックの上書き）を追加し、モバイル分岐でも案内文が出ることを
  検証するテストを新設（初のモバイル分岐テスト）。
- **T595ドキュメント/コメント/CSS是正**: 上記監査結果の記載乖離をすべて修正
  （route-settings-and-results.md 3箇所、map-axis-coloring.md 1箇所、page-composition.md
  1箇所[RideConditionBar未記載を追加、新規ファイル2件を対象ファイル表へ追加]、page.tsx
  コメント2箇所、routeStyleModes.tsコメント1箇所、RouteSettingsPanel.module.css未使用
  クラス2件削除）。
- **T593是正**: `backend/app/api/routers/region.py`のdocstringを
  `dedicatedWayValueLayer.ts`参照へ更新し、`frontend/src/types/generated/openapi.json`・
  `api.d.ts`を同じ文言へ同期（backend実行環境が本セッションに無く`export_openapi.py`は
  実行できなかったため、生成物へ同一のテキスト置換を直接適用。スキーマ形状の変更は無いため
  内容は生成結果と等価）。
