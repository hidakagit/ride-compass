# T866. 再描画のたびにramp軸のレイヤーが「ソースが無い」で落ちる

状態: 未着手（2026-09-15起票）
規模: S

## 背景

ユーザー報告（2026-09-15、周回モードの生成中）:

```
[map:error] layers.region-axis-surface_q-line: source "region-road-surface-tiles" not found
[map:error] layers.region-axis-car_stress-line: source ... not found
[map:error] layers.region-axis-accident-line: source ... not found
[map:error] layers.region-axis-night-line: source ... not found
```

`map.setStyle()`はソースもレイヤーも全て捨てるため、`redrawAllLayers`が作り直す。その中で
`setStaticOverlayVisibility`が各レイヤーの`ensure`を順に呼ぶが、**ramp軸のensureは路面
ソースを作らない**（`makeEnsureAxisRampLayer`）。ソースを作るのは後から呼ばれる
`applyRoadLayerState`のため、ramp軸だけがソース未作成のまま追加されて落ちる。専用way値軸
（風・勾配）が落ちないのは、そのensureが先に`ensureRoadSurfaceTileLayer`を呼ぶため。

落ちたレイヤーは追加されないので、再描画のあと**その軸の色分けは戻らない**（次に何かが
そのレイヤーを作り直すまで）。
