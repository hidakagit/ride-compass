# T873. 「今」ボタンを張り付き復帰へ配線し、dirty印の誤点灯を止める

規模S。
状態: 未着手（2026-09-15起票。統合レビュー第9回のP1。2件は同じ`dynamicLayerTargetTime`
に起因するため1タスクにまとめる——片方だけ直すともう片方の発生頻度が上がる）

## 背景1: 「今」ボタンが未配線で、T859が直した欠陥が復活する

「今」へ張り付きを戻す唯一のAPI `handleDynamicLayerNow`
（`useDynamicWeatherLayers.ts:302-305`、`setNow(steppedNow()); setPinnedTargetTime(null);`）が
**productionからは一度も呼ばれていない**。`grep -rn "handleDynamicLayerNow" src`の結果は
宣言・型・returnとテスト1件のみ。

実際の「今」ボタンは`RideConditionBar.tsx:117`の
`onNow={() => onDepartureTimeChange(new Date())}`で`setPinnedTargetTime`へ入るため、
**押すと逆に現在時刻でピン留めされる**。以後`pinnedTargetTime`は二度とnullに戻らない。

フックのコメント（`:145-146`）は「「今」ボタンで張り付きへ戻る」と書いており、
実装だけが違う。テスト（`useDynamicWeatherLayers.test.ts:404`）は
「「今」ボタンで追従へ戻る」という名前で**実UIが呼ばない関数を直接叩いている**ため、
この乖離をgreenのまま隠している。

結果として、出発時刻を一度でも触った後（「今」を押した後を含む）に10分以上地図を開いた
ままにすると、`frameIndexForTime`が範囲外を返して降水・雷・竜巻・雷放電が無言で描画を
止める——[T859](T859.md)の起票理由そのものが、T859の後に別経路で復活している。

加えて`new Date()`は`NOW_STEP_MS`へ丸められておらず、`:68-72`のコメントが警告する
「5分より細かく進めても、どのレイヤーが選ぶフレームも変わらないまま
`useDedicatedWayValues`の取得だけが無効化される」状態を作る。

## 背景2: 生成の約5分後に「条件が変更されています」が誤って点く

[T859](T859.md)で共有時刻が5分刻みで自動前進するようになった結果、利用者が何も操作
しなくても生成の約5分後にdirty印が3箇所（設定見出し横のドット・結果欄先頭の文言・
モバイルタブのドット）へ点灯する。

`dynamicLayerTargetTime = pinnedTargetTime ?? now`（`useDynamicWeatherLayers.ts:147`）で
`now`は30秒ごとに`steppedNow()`へ更新される。`buildCurrentGenerationInput`は
`startTime: dynamicLayerTargetTime`（`page.tsx:1453`）を入れ、
`generationConditionsKey`は`IGNORED_WHEN_COMPARING`（現在は`lens_axis_id`のみ）を除く
**すべて**を比較対象にする（`generationRequest.ts:96-105`）。`start_time`は除外されていない。

[T815](T815.md)が直した「dirty印が常時点灯すると本当の変更の合図が意味を失う」と同じ性質が、
別の入力から再発している。既存テスト（`page.test.tsx:935/957`）はタイマーを進めないため
検出できない。

## 対応方針

- `RideConditionBar`に`onNow`用の口を分けて`handleDynamicLayerNow`を配線する
  （配線しない判断なら関数とテストを撤去してコメントを実態へ直す。「テストだけが参照する
  コード」の状態は残さない）
- `setDynamicLayerTargetTime`側も`steppedNow`と同じ刻みへ丸めるか、丸めない理由を書く
- 「今」に張り付いている間の`start_time`はdirty判定から外す。
  **`IGNORED_WHEN_COMPARING`へ理由付きで加える形にして、「送るものは全部比較する」規約に
  穴を開けない**（`lens_axis_id`が既にこの形）
- テストは`RideConditionBar`の`onNow`を経由する経路で検証し直す。dirty側はタイマーを
  進めるテストを1件置く

## 完了条件

「今」を押した後に時間を進めても降水レイヤーが描かれ続けること、および何も操作せずに
5分以上経ってもdirty印が点かないことを、それぞれ**壊すと落ちるテスト**で固定する。
