# T517: 「開発者」タブからバックエンドの直近ログを見られるようにする

状態: 着手中（2026-09-01）

## 背景

`GET /api/admin/debug/logs`（T379）はHTTP Basic認証必須のAPIとして既に存在するが、
フロントエンドに一切配線されておらず、確認するたびに毎回curl等で認証情報を渡して
手動で叩く必要があった（ユーザー指摘「バックエンドのログを見るのに、サーバに毎回
入らないとだめなのはキツい」）。

`/admin`（軸スタジオ・研究/開発者ツール）はブラウザの標準Basic認証で既に保護されており、
軸CRUD管理API（`axis-definitions`）は`adminApiProxy.ts`経由でこのブラウザセッションを
再利用し、二重ログイン無しでbackendのadmin APIを叩けている。同じ仕組みをログ取得にも
使う。

## 対応方針

- `lib/adminApiProxy.ts`: `proxyToAxisAdmin`を軸CRUD専用ではない汎用名
  （`proxyToBackendAdmin`）へ改名し、クエリ文字列（`limit`/`contains`）も転送するよう
  拡張する。
- `app/admin/api/debug/logs/route.ts`（新設）: `proxyToBackendAdmin`経由で
  `GET /api/admin/debug/logs`を中継する。
- `services/debugAdminApi.ts`（新設）: `/admin/api/debug/logs`を叩くクライアント。
- 「開発者」タブ（`app/admin/page.tsx`）へ新規パネル（ログ本文の表示、`contains`
  絞り込み・件数指定・取得ボタン）を追加する。
