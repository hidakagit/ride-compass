# T615. 地図上チップの排他ドメインを廃止し、すべて複数選択可にする 規模M

状態: 着手中（2026-09-06起票）

## 背景

[T610](T610.md)で災害チップを排他ドメインの対象外にしたところ、本番実機確認でユーザーから
「災害と降水は重複ONできるけどこれは不整合にならない？」との指摘。降水も災害も面（ラスタ）
であり、「面を重ねると読めなくなるから1つに絞る」という排他ドメイン（T400/T406）の目的から
すれば、災害だけを例外にする理由は無い——防災情報を消したくないという別の価値判断で例外を
作っただけで、仕組みとしては一貫していない。

[T612](T612.md)で▶パネルの内訳トグルが入り、「重なって読めないときにユーザーが自分で絞る
手段」が用意できたため、排他という強い制約自体を廃止して例外を無くす方針をユーザー判断で
決定した。

あわせてユーザー要望「各▶パネル内で一括ON/OFFチェックを省スペースで追加して」に対応する。
サイドバー（`MapLayersPanel`）が持つ「すべて表示/すべて隠す」の一括操作を、地図上チップの
▶パネルにも省スペースな形で置く。
