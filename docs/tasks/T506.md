# T506: 走行方位アイコン（TravelBearingControl）を現在値を映すミニダイヤルへ再設計

状態: 完了（2026-08-31）

## 背景

T504で地図右上へ新設した`TravelBearingControl`のトリガーアイコンについて、ユーザー指摘
（2026-08-31、本番`ride-compass-frontend.onrender.com`で確認後）:

> アイコンが非常に見にくい。丸形の中にすごく小さく矢印。
> これを、コンパス設定画面をそのまま縮小したみたいにはできない？

T504時点の実装は、`WindDirectionArrowIcon`を固定サイズ18pxで常に北向きのまま（現在値に
連動して回転しない）表示するだけの汎用アイコンボタンだった。(1)アイコン自体が小さく
視認しづらい、(2)開く前から現在の走行方位が分かるはずなのに機能していない、という
2つの問題があった。

## 対応方針

トリガーのアイコンを、ポップオーバーで開く`WindBearingSlider`本体のダイヤル
（`.dial`/`.arrow`、`docs/tasks/T503.md`で新設）と同じ配色・比率の「ミニチュア」として
再設計した:

- 背景を`var(--color-surface-2)`・枠線を`var(--color-border-muted)`へ変更（`.dial`と同じ
  トークン、以前は`.locateButton`と同じ汎用ボタンの配色だった）。
- ボタン直径を36px→40pxへ、矢印アイコンを18px→26pxへ拡大（矢印/直径比0.65、
  `WindBearingSlider`本体のダイヤル[矢印44px/直径68px≒0.647]とほぼ同じ比率に揃えた）。
- 矢印の色を`var(--color-accent-strong)`へ（`.arrow`と同じ）。
- 矢印自体を`travelBearingDeg`（`value`prop）に応じて`transform: rotate(${value}deg)`で
  回転させるようにした（以前は回転していなかった）——開く前のアイコン単体で現在の
  走行方位が一目でわかる。

`WindBearingSlider.tsx`自体（ポップオーバーの中身）は変更していない。

## 検証結果

- `npx tsc --noEmit`・`npx eslint src/components/TravelBearingControl/`: エラー無し。
- `npx vitest run src/components/TravelBearingControl src/components/WindBearingSlider`:
  16件成功。
- Browserペイン実機確認（`localhost:3010`）: 走行方位を135°（南東）へ設定した状態で
  ポップオーバーを閉じ、トリガーアイコンの矢印が南東（右下）を指した状態で表示される
  ことをデスクトップ（1280×720）・モバイル（375×812）両方でスクリーンショット確認した。
  MapLibreのズーム+/−・回転コントロールとの重なりも無いことを確認済み。
- 状態: 完了。
