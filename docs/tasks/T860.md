# T860. 面レイヤーの不透明度を1つの値へ揃え、地図が読める濃さまで下げる

状態: 完了（2026-09-15）
規模: S

## 背景

降水・災害（キキクル等）の面が出ると下の地図がほとんど見えなくなる（ユーザー指摘
「降雨や災害レイヤで色がつくと、色が濃すぎて地図がほぼ見えなくなる」「色と言うより
透明度の調整かな」）。実測でも、注意報級のキキクルが出ている日は画面全体が単色で覆われ、
道路レイヤーの色分けが読めない。

現状の不透明度は描画スペックの各所へ個別に書かれている（気象庁ナウキャスト系ラスタ0.65、
降水延長予報の格子塗り0.55、標高図0.55）。

## 対応

`AREA_LAYER_OPACITY`（0.4）を1つ置き、面で塗るレイヤー（気象庁ナウキャスト系のラスタ・
降水延長予報の格子塗り・標高図）すべてがこれを共有する。**濃さをレイヤーごとに決めない**
——面が重なったときの濃さは重なりの数で決まるべきで、レイヤーごとの主張の強さで決まると、
何が上に乗っているのかが読めなくなる。

## 検証

実機（開発サーバー、渋谷付近z16、当日はキキクルが注意レベルで広域に出ていた）で、調整前は
画面全体が単色の黄色で覆われ道路の形しか分からなかったのに対し、0.4では道路・地名・
公園の緑・道路レイヤーの線がすべて透けて読める。
