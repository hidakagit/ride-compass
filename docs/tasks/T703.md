# T703. maplibre-glを6系へ更新する（XSS Sanitizer Bypass） 規模M

状態: 未着手（2026-09-10起票、統合レビュー第6回 I-9の分割）
— トリガー: 一般公開の意思決定、または[T702](T702.md)完了後に独立タスクとして着手できる余力ができた時点

## 背景

`maplibre-gl`（`^5.24.0`、直接依存）に
**XSS Sanitizer Bypass in `DOM.sanitize()` via Live NamedNodeMap Removal Skip**（CVSS 10）。
修正版は6.9.0で**semver major**。

## 到達可能性（実在する）

地図ポップアップ（`buildRoadSurfacePopupHtml`ほか）が表示する値はOSMタグ由来＝
**第三者が編集できるデータ**。`DOM.sanitize()`のバイパスはそのまま任意スクリプト実行につながる。
`next`側の2つのRCEが本プロジェクトの構成では届きにくいのに対し、**これは実際に効きうる**。

## 分離した理由（トレードオフの判断）

5→6はmajorで地図UI全体の再確認が要る。現フェーズは**一般公開前・低利用規模**で、
攻撃者が特定利用者を狙う動機が薄い。`next`（minor、低リスク）と一括にすると
両方が止まるため、確実に進められる方を先に出す。

## 対応方針

MapLibre GL JS 6のbreaking changesを確認し、`components/Map/`配下
（`MapView.tsx`・`axisLayers.ts`・`mapLayers.ts`・`staticAttributeLayers.ts`・
`dynamicWeather.ts`・`jmaTileProtocol.ts`ほか）への影響を洗う。
**地図UIの変更確認は必ずPlaywrightで実機確認する**（context.md「テスト構成」）。
