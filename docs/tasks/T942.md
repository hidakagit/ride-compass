# T942. architecture.mdにT805（較正値）・edge_landcover・tile_version_serviceが存在しない 規模S

状態: 未着手（2026-09-19起票、統合レビュー第11回）

## 背景

規模M〜Lで新テーブル・新API・新しい管理画面タブを伴ったT805が、現状文書に1文字も反映されていない。
T919の`edge_landcover`・T848の`tile_version_service.py`も同様。
「更新されているが古い」ではなく「対応するセクション自体が存在しない」型である。

詳細は[history/2026-09-19_all.md](../../.claude/commands/review/history/2026-09-19_all.md)。

## 対応方針

1. `docs/architecture.md`へ較正値の節を足す（テーブル・管理API・`/admin`の較正値タブ・
   `TuningEffect`の意味）。APIの一覧とデータモデルの両方に対応する記述が要る。
2. 「派生データの系譜追跡」節へ`edge_landcover`を足す（系譜の2列を持つのに、way単位のほうだけが
   列挙されている）。
3. `tile_version_service.py`（世代を実行時に組み立てて配る）を足す。あわせて撤去済み定数を
   名指ししている箇所を現在の形へ直す。
4. APIの一覧に起伏タイルのエンドポイントを足す（別の節には記載がある）。

## 再発防止

**文章のルールを足さない。** 「`backend/migrations/`に新しい`CREATE TABLE`があるのに
architecture.mdにその表名が無い」は機械的に判定できる形をしているため、まず検知器にできないかを
検討する。届かない場合だけ手順として残す。

## 完了条件

- 上記4点がarchitecture.mdに反映されている
- 検知器の可否を実測し、結論（作る／作らない理由）を本文へ書く
