# T614: 「ルート設定」パネルをタブ分割・入力欄圧縮・説明文のinfoアイコン化で高さを圧縮する

状態: 起票（2026-09-06、ユーザー指摘を受け着手中）

## 背景

モバイル実機のスクリーンショットで、「ルート設定」BottomSheetが縦に長く、スクロールしないと
「除外する道路」「既定値に戻す」まで見えないことが判明した。ユーザー指摘: 「ルート設定パネル内
にタブ作ってもいいから、もう少し高さ低くて収まるようにしたい。あと距離や候補数が入力エリア
だけ変に大きい。説明内容を情報アイコンに収めたりとか工夫余地もありそう」。

## 対応方針（ユーザー確認済み）

- パネル内を2タブに分割する:
  - 「生成条件」: 周回/目的地トグル・距離・候補数（コンパクトな1〜2行）
  - 「重みづけ」: 重み配分バー・8軸チップ・除外する道路・既定値に戻す
  - 「ルート生成」ボタンはタブの外・パネル下部に常時表示にする（重みづけタブを見ている間も
    タブを行き来せず押せるようにするため）。
- 距離・候補数の入力欄を圧縮する（幅を数字2〜3桁分まで縮小・中央寄せ・横1行に並べる）。
- 「重み配分[帯の境界をドラッグして配分を調整できます]」の操作説明文を、見出し脇の
  既存(i)アイコン（凡例ポップオーバー）内へ移し、見出しは「重み配分」だけにする。
