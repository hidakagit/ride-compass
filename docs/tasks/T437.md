# T437. 目的地モードの空状態案内文をルート生成モードに応じて出し分ける 規模S

状態: 完了（2026-08-30）

- 背景: review:ui（2026-08-30、[history/2026-08-30_ui.md](../../.claude/commands/review/history/2026-08-30_ui.md) F-3）。
  「目的地」モードでは距離入力欄が無いにもかかわらず、空状態の案内文が
  「距離を入れて『ルート生成』を押すと...」という周回モード専用の文言のまま無条件に表示される。
- 対応: `frontend/src/app/page.tsx`の`renderRouteOutcomeSectionBody`内、空状態ガイドの`<p>`を
  `routeMode === "destination"`で分岐させ、目的地モード専用の文言
  「地図をタップして経由地・目的地を指定し『ルート生成』を押すと、ルート候補が地図に
  表示されます」を追加。周回モードの既存文言は無変更。
- 検証: `tsc --noEmit`・`eslint`とも問題なし。既存の`page.test.tsx`はRouteFormをまるごと
  `() => null`へモックしておりUI操作でrouteModeを切り替えられないため、本変更に対する
  ユニットテストは追加せず、Playwright実機確認で検証した（周回モードでは従来通り
  「距離を入れて」表示、「目的地」ボタン押下後は新文言のみ表示され旧文言は表示されない
  ことをテキスト検索で確認済み）。
