# T518: ルート結果パネルの再構成（「ルート選択」への統合＋重み反映＋表示トグル修正）

状態: 着手中（2026-09-01）

- 背景: ユーザーから連続する指摘。「生成したルートの色分け」「凡例の表示設定」が
  ルート結果パネルの全タブ（ルート選択/全体プロファイル/比較）に重複表示され続ける、
  色分け対象の選択肢がルート設定パネルと連動せずパネルを跨ぐ操作になる、UIが
  RouteSettingsPanelの凡例チップパターンと揃っていない、全体プロファイルの軸別内訳が
  重み（route_preference）を無視した絶対値のため総合スコアとの見た目の整合が取れない、
  等。Plan Modeでのモックアップのやり取りを経て、「全体プロファイル」タブ自体を廃止し
  「ルート選択」タブへ統合する方向へ発展した（詳細はPlan承認済みの設計を参照）。
- 対応方針の要点: (1) タブを「ルート選択」「比較」の2つへ統合、(2) 総合難易度を内訳の
  合計として分離し「おすすめ度」と並記、(3) 軸別内訳バーを距離×重みの寄与度で表示、
  (4) RouteSettingsPanelの凡例チップパターンを流用、(5) 比較タブもOFF軸を除外、
  (6) 地図上「ルート」チップの重複解消・完全非表示への修正。
- 詳細な設計判断・検証結果は実装完了後にこのファイルへ追記する。
