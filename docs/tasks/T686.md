# T686. 軸スタジオで折れ点の効き方を実データの分布として見せる 規模M

状態: 未着手

## 背景

停止密度の軸（[T655](T655.md)）を較正する際、折れ点`[[0,0],[2,25],[4,50],[7,75],[12,100]]`が
妥当かどうかを軸スタジオの画面からは全く判断できず、本番タイルを1,060km分デコードして
「この折れ点だと延長の何%がどの得点帯に入るか」を手で測る必要があった。結果として
最初の較正は外れており（本番の92.3%が満点に張り付く／逆に伸ばしすぎてルート値が10に
潰れる）、実データを測って初めて分かった。

**軸スタジオは数値の入力欄をDBの構造どおり並べているだけで、判断を助けていない。**
利用者は勘で入れるしかなく、公開して地図とルートを見るまで結果が分からない。
「DBへ直接INSERTした方が楽」という感想はここから来ている（ユーザー指摘、2026-09-08）。

## 対応方針

折れ点を編集している最中に、**その折れ点で実データがどう分布するか**を画面に出す。
