# T520: nowcグループ（targetTimes_N3.json）の未使用element調査（liden・slmcs系）

状態: 調査継続中（2026-09-01、要素ごとの確証度を追記）

## 背景

T514/T510フォローアップの雷・竜巻ナウキャストのbasetime選択バグ調査中、
`bosai/jmatile/data/nowc/targetTimes_N3.json`の各エントリの`elements`配列に、
RideCompassが現在使っていない要素が含まれることが分かった。

- `liden`: 雷放電位置データ（実際の落雷地点そのものを点として示すデータ。現在の
  `thns`は活動度をエリア単位のラスタタイルで示すのみで、個々の地点は扱っていない）
- `amds_rain10m`: アメダス10分雨量（`jma_amedas_service.py`経由の既存アメダス実況と
  重複する可能性が高い、要確認）
- `slmcs`/`slmcs_fcst`/`slmcs_unify`/`slmcs_unifyfcst`: Web検索で「線状降水帯直前予測の
  運用開始について」（気象庁、2026年3月の報道発表）がヒットした。既存の「線状降水帯
  予測マップ」（`sjfcstmap`、rasrfグループ、T410）とは別物で、より切迫したタイミングの
  予測を扱う可能性がある。

**確証度が低い（起票時点）**: 上記はWeb検索結果からの推測であり、`jma.go.jp`公式ページへ
直接アクセスして確認できていない（調査時点でサンドボックスから同ドメインへの
アクセスがブロックされていた）。着手前に気象庁公式のドキュメント・報道発表で
正確な仕様（更新頻度・提供形式・利用条件）を確認すること。

## 追加調査結果（2026-09-01、WebSearch経由。`jma.go.jp`本体への直接WebFetchは
依然EGRESS_BLOCKEDで不可、検索結果スニペット・第三者記事からの間接確認に留まる）

- **`liden`（確証度: 中）**: 気象庁公式ページ「雷監視システムによる観測」がヒットし、
  LIDEN（LIghtning DEtection Network system、全国30箇所の検知局＋中央処理局）による
  雷放電の緯度経度・発生時刻の標定システムと確認できた
  （[雷監視システムによる観測 | 気象庁](https://www.jma.go.jp/jma/kishou/know/kouku/2_kannsoku/25_liden/25_liden.html)、
  本文への直接WebFetchはブロックされたためタイトル・要約のみ）。検索結果には配信URLの
  形も見つかった: 時刻一覧は既存で使っている`targetTimes_N3.json`と共通、個々の観測は
  `https://www.jma.go.jp/bosai/jmatile/data/nowc/{basetime}/none/{validtime}/surf/liden/data.geojson?id=liden`
  という**GeoJSON**（`thns`/`trns`のようなラスタタイルではなく点データ）で提供される
  との記述があった（出典: 検索結果スニペット、一次ページ本文は未直接確認）。事実なら
  現行の`JmaTileClient`（z/x/yのラスタタイルパスを前提にした設計）をそのまま流用できず、
  別経路のfetch・別のレンダリング方式（MapLibreの点マーカー等、既存の面塗り/ラスタタイル
  系レイヤーとは異質）が必要になる。
- **`amds_rain10m`（確証度: 中、既存機能との重複を裏付け）**: 気象庁「統合地図ページ」の
  URL（`elem=precipitation10m&contents=amedas&interval=10`）がヒットし、アメダス
  10分雨量は同ページの「アメダス」レイヤー（点データ）の一部と確認できた
  （[気象庁｜統合地図ページ](https://www.jma.go.jp/bosai/map.html#9/42.946/142.828/&elem=precipitation10m&contents=amedas&interval=10)）。
  RideCompassは既に`jma_amedas_service.py`経由でアメダス実況（降水量含む）を独自に
  取得済みであり、起票時点の「重複する可能性が高い」という推測を裏付ける方向の結果。
  新規導入の動機が薄い。
- **`slmcs`系（確証度: 中、機能の実在は確認。配信形式は未確認）**: 気象庁の報道発表
  （[20260310 SLMCS](https://www.jma.go.jp/jma/press/2603/10b/20260310_SLMCS.html)、
  本文は直接WebFetch不可のためタイトルのみ確認、第三者記事
  [気象庁「線状降水帯直前予測」の使い方完全ガイド](https://vegcale.com/2026/05/19/jma-senjo-kousuitai-chokuzen-yosoku-guide/)
  経由で要約を取得）により、「線状降水帯直前予測」が2026年5月に正式運用開始したことを
  確認。発生2〜3時間前を目標に、都道府県内の主要な地域区分（例:「◯◯県北部」）単位で
  通知、適中率は目安50%程度、既存の警報・注意報を補完する「防災気象情報（線状降水帯
  直前予測）」という位置づけ。**この粒度感（県内地域区分単位のテキスト警報）は、
  ラスタタイル(thns/trns型)よりも既存の気象警報・注意報バッジ（T205実装済み、
  `WarningBadge.tsx`）の配信形態に近い可能性が高いが、タイル/GeoJSON/テキストAPIの
  いずれで配信されるかという技術仕様までは確認できていない**（jmamap等の非公式ライブラリ
  ソースを検索したが、slmcs/lidenへの言及は見つからなかった——T521調査時のように既存の
  非公式実装で裏取りする手段は今回使えない）。

URL）を直接取得してもらう、またはPlaywright等でのアクセス可否を再確認することから
