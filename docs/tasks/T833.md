# T833. 停止密度の折れ線が早く飽和し、上位の段階が区別できない

規模S（較正の判断はユーザー）。
状態: 完了（2026-09-14、[T831](T831.md)完了時に分離）

## 背景

停止密度（`axis_abdaded0be20`）の折れ線は**5回/kmで難易度100に達する**
（`[[0,0],[0.5,20],[1.5,50],[3,75],[5,100]]`）。一方その軸の段階の境界は
`[2, 4, 7, 12]`（回/km）に置かれており、**上2つ（7・12回/km）はどちらも難易度100へ写る**。

結果、地図が塗る値のスケールでは段階が5つから4つへ減る
（[T809](T809.md)の実測: `[58.3, 87.5, 100.0]`）。減った分だけ体感ラベルの件数（5件）が
段階数と合わなくなり、**ルート後の凡例ではこの軸だけラベルが出ない**
（[T831](T831.md)。ずらして添えると「83m以下で1回停止」が実際には143m以下すべてを指す嘘に
なるため、数値だけにしている）。

利用者から見ると、**7回/kmの道と12回/kmの道がルート線で同じ色になる**。停止が多い側は
実走の負担が大きく変わる範囲のはずで、そこが1色に潰れている。

## 実データ（本番DB、TABLESAMPLE 2%・way 20,000本・3,655km）

生値（重み付き和、回/km相当）の分布:

| 分位 | 値 | | しきい値を超える延長 |
|---|---|---|---|
| p50 / p75 | 0.00 | | > 2回/km: 10.2% |
| p90 | 2.10 | | > 4回/km: 5.1% |
| p95 | 4.05 | | > 5回/km: **3.7%**（現在の飽和点より上） |
| p99 | 9.17 | | > 7回/km: 1.8% |
| p99.9 | 25.39 | | > 12回/km: 0.55% |

道の8割超は停止ゼロで、飽和点（5回/km）より上に延長の3.7%がある。上2段階が分ける対象は
1.8%で、サンプル3,655kmのうち66km相当。

## 対応と結果

**ユーザー判断: 案A（折れ線の飽和点を12回/kmまで伸ばす）**（2026-09-14）。段階の境界
`[2,4,7,12]`は500m/250m/143m/83m間隔という**人が読める尺度**で、こちらを曲線に合わせて
歪めるべきではない、という判断。体感ラベルもそのまま使える。

折れ線を `[[0,0],[0.5,20],[1.5,50],[3,75],[5,100]]` から
`[[0,0],[0.5,15],[1.5,40],[3,60],[7,82],[12,100]]` へ変更した。

| 段階の境界 | 変更前 | 変更後 |
|---|---|---|
| 2回/km | 58.3 | 46.7 |
| 4回/km | 87.5 | 65.5 |
| 7回/km | **100.0** | **82.0** |
| 12回/km | **100.0** | 100.0 |

軸スタジオAPI経由（unpublish→PUT→republish）で**本番DBへ適用済み**。
`dump_axis_definitions_snapshot.py`でスナップショットを更新し、開発DBは
`bootstrap_fresh_db.py`でそのスナップショットから入れ替えた。生成物
（`axis-catalog.json`の`map_value_thresholds`）も本番DBから作り直している。

**低い側は今より平たくなる**（2回/kmが58→47）。延長の96%が0〜3回/kmに入るため、
そこの分解能は落ちる——それでも上端が1色に潰れている状態よりは良い、という選択である。

## 検証結果

- **段階が5つに戻ったこと**: `GET /api/axis-catalog`の`map_value_thresholds`が
  `[58.3, 87.5, 100.0]`（3つ＝上2段階が重複して畳まれていた）から
  `[46.7, 65.5, 82.0, 100.0]`（4つ）へ。体感ラベル5件と段階数が一致する。
- **上端の張り付きが減ったこと**（本番DB・同じ標本の取り方で前後を測定）:

  | | 変更前 | 変更後 |
  |---|---|---|
  | 難易度95以上が占める延長 | 4.0% | **0.7%** |
  | p90 | 57.8 | 47.6 |
  | p99 | **100.0** | 89.0 |

- `cd backend && pytest tests -q`（postgis込み）→ 2248 passed。
  `npx vitest run` → 142ファイル 1349 passed。
- [T831](T831.md)のテストは変更不要でそのまま通る（「ラベルが出ないのは畳まれた軸だけ」と
  いう性質で書いてあり、飽和が解けたこの軸はラベルが出る側へ移る）。
