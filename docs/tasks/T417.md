# T417. 評価軸チップの展開方向を横並びから縦並びへ統一（道路/環境/スポットと揃える）

状態: 未着手（起票のみ、実装はこの後すぐ着手）

- 背景: T406で地図チップは「道路/評価軸/環境/スポット」の4グループへ再編したが、
  「評価軸」グループだけ横並び展開（`flatRight`、SECONDARY_AXES駆動のページ送り付き
  チップ行）を維持し、他3グループ（`道路`/`環境`/`スポット`）は縦並び展開
  （`renderObservedMemberRows`系）だった。実機フィードバック「評価軸チップだけ横に開くのは
  UI設計として不ぞろい」を受け、4グループの展開方向を統一する（2026-08-30起票）。
- 対応方針（ユーザー承認済み）:
  1. 評価軸グループの展開方向を横（`flatRight`）から縦（他3グループと同じ）へ変更し、
     ページ送り（◀/▶）ボタンを撤去する。
  2. グループの並び順・「道路」との隣接は変更しない（道路と評価軸は同じ排他ドメイン
     「line」を共有しており、隣接配置がその関係を視覚的に伝えるため）。
  3. ルート設定側（重み配分）との統合はしない。地図上の評価軸チップ＝探索的に1軸だけ
     見るもの、ルート設定の重み＝候補ルート順位付けに複数軸をどう効かせるかを決めるもの、
     という役割の違いをそのまま維持し独立させる。軸の名称・並び順（SECONDARY_AXES）のみ
     単一ソースを継続する。
