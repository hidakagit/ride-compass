# T472. jma_amedas_service.pyのRedis呼び出しをfail-open契約へ統一

状態: 完了（2026-08-31）

- 背景: T464が`get_redis_client()`直接呼び出しを`get_redis_client_or_none()`へ置換し、
  Redis接続確立自体が同期的に例外送出する場合でもfail-open（Redis無し扱いで処理続行）と
  なるよう4モジュール（`road_edge_geometry_cache.py`・`road_graph_tile_cache.py`・
  `wind_forecast_cache.py`・`dynamic_way_value_cache.py`、計12箇所）を修正したが、
  `backend/app/services/jma_amedas_service.py`の2箇所（`_get_from_redis`115行目・
  `_save_all_to_redis`208行目）が対象範囲（`app/infrastructure/`のみ）から漏れ、
  同一パターンの`client = get_redis_client()`がtry/exceptの外に残っている
  （統合レビュー第3回 `history/2026-08-31_all.md` P1、Shard C2発見・Shard C1が独立に
  再現確認・Shard Bが横断確認しinfrastructure層自体には他の取りこぼしが無いことを確認済み）。
- 影響: `settings.redis_url`の設定ミス等でRedis接続確立自体が例外を送出する環境では、
  天候（アメダス実測値）取得経路が未捕捉の例外で丸ごと落ちる。`redis_client.py`の
  モジュールdocstringが謳う「Redis障害はfail-fastさせない」契約がこの2箇所だけ破られている。
- 対応方針: `jma_amedas_service.py`の該当2箇所を`get_redis_client_or_none()`へ置換し、
  Noneの場合は既存のfail-open経路（現状の`except Exception`と同じ「観測値なし」扱い）へ
  合流させる。回帰テスト（`redis.from_url()`相当の同期例外を模したフェイク）を
  `test_jma_amedas_service.py`へ追加する。
- 規模: S

## 実施記録（2026-08-31完了）

- `backend/app/services/jma_amedas_service.py`: `get_redis_client`のimportを
  `get_redis_client_or_none`へ置換し、`_get_from_redis`（旧115行目）・
  `_save_all_to_redis`（旧208行目）の両方で`client = get_redis_client_or_none()`→
  `if client is None: return`（前者は`return None`）という、他4モジュール
  （`road_edge_geometry_cache.py`等）と同一のfail-openパターンへ統一した。
- `backend/tests/test_jma_amedas_service.py`: 既存の`_patch_client`ヘルパーが
  monkeypatchする対象を`get_redis_client`→`get_redis_client_or_none`へ更新（旧名の
  参照が残っていた）。新規に2件の回帰テストを追加:
  - `test_get_nearest_observation_fails_open_when_redis_client_unavailable`:
    `get_redis_client_or_none`がNoneを返す状況（＝`redis.from_url()`が同期的に例外を
    送出する状況）を再現し、`get_nearest_observation`が例外を送出せずNoneを返すことを確認。
  - `test_refresh_all_stations_fails_open_when_redis_client_unavailable`: 同じ状況で
    `refresh_all_stations`（バッチ）がRedis書き込みだけをスキップし、例外を送出せず
    完了することを確認。
- 検証: `pytest backend/tests/test_jma_amedas_service.py backend/tests/test_redis_client.py -q`
  → 10件全件green。
