# T795. 重み配分のプロファイル（名前を付けた配分の切り替え）

規模M。
状態: 未着手（2026-09-13起票、[T794](T794.md)で既定値ボタンを落とした際の代替として。
採番はT793で確保しようとしたが並行セッションが先に使ったため振り直した）

## 背景

軸ごとの重みを毎回組み直すのは、走行中はもちろん出発前でも手間が大きい。実際に使うのは
いくつかの決まった配分で、利用者は「今日は裏道優先」といった粒度で選びたい。

例: 「裏道優先」プロファイル＝停止密度60%＋蛇行40%。

## 対応方針（未確定、着手時に詰める）

- 名前の付いた重み配分をいくつか用意し、1タップで切り替えられるようにする。
- 「既定値」もプロファイルの1つとして扱う（[T794](T794.md)で撤去した「重みを既定値に戻す」の
  行き先）。
- 利用者が自分の配分に名前を付けて保存できるかどうか、保存先（localStorageか軸カタログと
  同じくbackendか）は着手時に決める。
- 軸は軸スタジオで増減するため、プロファイルは軸idの集合を固定で持たない形にする
  （知らない軸が現れたとき・消えたときに壊れない、`syncRoutePreferenceKeys`と同じ問題）。
