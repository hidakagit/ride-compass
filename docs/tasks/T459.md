# T459. car_stress_display_level()がAXIS_DEFINITIONS["car_stress"]を直接ハードコードしている

状態: 起票

- 背景: モジュール設計書作成のため`backend/app/domain/axis_definitions.py`を実コードで
  確認したところ、`car_stress_display_level(difficulty)`関数が`AXIS_DEFINITIONS
  ["car_stress"]`という軸idの直接ハードコードで、difficulty(0-100)を旧来の1-5段階表示
  （`RouteSegmentDetail.car_stress`向け）へ逆変換している。
- Impact: `docs/design-principles.md`構造仕様2・3への違反（動的材料
  [T458・DYNAMIC_WAY_VALUE_MATERIALS]と同一カテゴリの違反——軸idの直接ハードコードは、
  対象が動的材料か静的な表示変換かに関わらず一律で違反として扱う、というユーザー方針に
  基づく）。`difficulty`（軸ではなく合成スコア自体という唯一の明文化された例外、
  design-principles.md構造仕様3）とは異なり、car_stressは軸スタジオが管理する軸そのもの
  であり、除外理由に該当しない。
- 対応方針（未検討）: `RouteSegmentDetail.car_stress`という1-5段階の専用フィールド自体を
  廃止し汎用の`axis_difficulties["car_stress"]`（0-100）へ一本化するか、もしくは
  1-5段階への逆変換ロジック自体を軸スタジオのデータ（`display_thresholds_override`等）
  から汎用に導出できる形にするか、着手時に検討する。フロント側でこのレガシーフィールドを
  参照している箇所の洗い出しが前提。
- Confidence: High（`axis_definitions.py`の実コードで直接確認済み）。
- 規模S〜M（フロント参照箇所の調査次第）。
