# T502: 地図色分け凡例がモバイルのBottomSheetに隠れる問題を修正

状態: 完了（2026-08-31）
## 背景

T499で追加した地図左下の色分け凡例（MapColorLegend）が、モバイルでルート設定パネルの
BottomSheetを開くと隠れて見えなくなるとユーザーから報告があった。BottomSheetは
20〜80vhの範囲で画面下側の大部分を覆うことがあり、タブバーの高さぶんだけ底上げする
従来の対策（`.bottomControlRow`等と同じ手法、地図下部中央の要素向け）では足りなかった。

## 対応方針

BottomSheetは画面下側からしかせり上がらないため、凡例を地図上部（MapOverlayControls
[左上]・MapLibreズームコントロール[右上]のどちらとも重ならない上部中央）へ移設した。
シートの高さに関わらず隠れない。

## 実装

- `frontend/src/components/MapColorLegend/MapColorLegend.module.css`: `.wrap`の位置を
  `left: var(--space-3); bottom: 2.5rem`（左下、モバイルは`bottom: calc(5rem +
  var(--mobile-tabbar-height))`）から`top: var(--space-3); left: 50%; transform:
  translateX(-50%)`（上部中央）へ変更。モバイル専用のメディアクエリは不要になった
  （BottomSheetは常に画面下側のみを覆うため、上部中央なら追加の底上げが要らない）。

## 検証結果

- `npx vitest run`・`npx tsc --noEmit`・`npx eslint src/`: 既存のとおり全て成功
  （CSSのみの変更で、テスト対象の分岐ロジックへの影響は無い）。
- Browserペインで実機確認: デスクトップ・モバイル(375x812)いずれも、凡例が地図上部
  中央に表示され、MapOverlayControls（左上）・MapLibreズームコントロール（右上）と
  重ならないことを確認。モバイルでBottomSheet（ルート設定パネル）を展開した状態でも
  凡例が隠れずに見え続けることを確認した。

## 残課題

なし。
