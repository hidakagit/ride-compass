# T430. MapView.tsxのKeep List閾値更新（カウント方式再定義＋行数閾値引き上げ）

状態: 未着手（起票のみ、2026-08-30・統合レビュー`/review:all`第9回complexity F-1で発見）

- 背景: `frontend/src/components/Map/MapView.tsx`が個別閾値（2,800行）・種類数条件
  （`DYNAMIC_WEATHER_RENDERERS`5件目）の両方を初めて実際に超過（2,496→2,992行、
  レンダラー2→8件）。増分の大半（8件中6件）はraster専用の単純な宣言的成長で、
  `ensureWindPenaltyFillLayer`のようなbespoke ensure/apply関数の増加とは性質が異なるが、
  現在のカウント方式では両者が閾値上で混在している。
- 対応方針:
  1. raster専用の宣言的エントリ（現在6件）は`STATIC_OVERLAY_LAYERS`のramp軸と同じ
     「宣言だけが増える種類はノーカウント」（T157）扱いへ改める。
  2. 種類数条件を「gridFill/gridMark等の描画ロジックを持つレンダラー、またはbespoke
     ensure/apply関数が新規に増えた件数」（現在の実質該当数は3件相当）へ再定義する。
  3. 行数閾値を2,800→3,200行へ引き上げる。
- 対応範囲: Keep List（`.claude/commands/review/context.md`等）の更新のみ、コード変更は
  不要。
