# T924: 軸の更新を1画面にする（ウィザードを撤去し、依存は表示の切り替えで表す）

状態: 着手（2026-09-17起票）

## 背景

軸スタジオの編集は4ステップのウィザード（`AxisComposer.tsx`、1,444行に4ステップ分の描画・
ナビゲーション・例外が同居）で、「値を直す」だけの操作でも順送りになる。ステップの必要性を
実在する依存と突き合わせると、依存に由来するのは「後段が前段の選択で具体化する」という性質
だけで、これは1画面でも表示の切り替えで表せる。

| 実在する依存 | 内容 |
|---|---|
| 形の種類 → パラメータ欄 | 折れ線か分類かで入力欄の種類が変わる |
| 材料 → 折れ点の横軸 | 材料が決まらないと単位・値域・参考点・分布が出せない |
| 形 → 地図の色分けスケール | `abs`＋単一材料なら符号付き生値、それ以外は難易度 |

`基本情報`ステップに至っては何にも依存していない。ウィザードが編集に合っていないことは
実装自身が認めており、公開済み軸だけステップを飛ばして最終画面から開く例外
（`restrictedDisplayOnly`）が入っている。
