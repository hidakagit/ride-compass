# T850. 標高が、何度作り直しても48件だけ埋まらない

規模M。
状態: 未着手（2026-09-14起票。ユーザー報告「鮮度台帳をつくり直しても未計算が残っている」から）

## 背景

本番で`elevation_attributes`の未生成が5,047,354件中48件残る。`precompute_elevation_
attributes`は行が無いEdgeを毎回すべて対象にする（anti-join）ため、回し直しても残るという
ことは、そのEdgeについて計算しても値が出ていないことを意味する。DEMタイルが無い範囲
（離島・海上にかかる線）か取得失敗が疑わしいが、**原因は未特定**。

「試したが値が出なかった」を記録しないと「まだ試していない」と区別できないため、
[T849](T849.md)のように判定をバッチの対象集合と揃えるだけでは消せない。まず48件が何かを
本番DBで特定するところから。
