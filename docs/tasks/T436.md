# T436. RouteAxisProfileの難易度バーが未描画になる不具合を修正 規模S

状態: 完了（2026-08-30）

- 背景: review:ui（2026-08-30、[history/2026-08-30_ui.md](../../.claude/commands/review/history/2026-08-30_ui.md) F-2）。
  「ルート全体プロファイル」の軸別難易度バーが、track/barとも`<span>`でbar側に`display`指定が無く
  インライン既定のままのため、`width`スタイルが効かず常に幅0で描画されない。
- 対応: `RouteAxisProfile.module.css`の`.track`・`.bar`両方に`display: block;`を追加（1行ずつ）。
  `.track`側は本レビュー時点の実測で別要因により偶然`display:block`相当になっていたが、
  今後の再発防止のため明示した。
- 検証: `RouteAxisProfile.test.tsx`に、`.bar`要素の`getComputedStyle().display`が`"block"`で
  あることを確認する回帰テストを追加（vitestの`css: true`設定によりCSS Modulesの実スタイルが
  jsdomへ適用される。jsdomはレイアウトエンジンを持たないため`getBoundingClientRect()`による
  幅の直接検証はできないが、`display`の解決値は検証できる）。修正前のCSSに戻すと
  このテストが実際に失敗する（`''` != `'block'`）ことを確認済み——真の回帰防止テストとして
  機能する。`frontend/src/components/RouteAxisProfile/RouteAxisProfile.test.tsx`3件成功。
