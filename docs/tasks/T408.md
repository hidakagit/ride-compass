# T408. 線状降水帯予測マップ（気象庁sjfcstmap）の導入可否調査 規模S（調査のみ）

状態: 未完了

- 背景: T387「無償範囲で追加できるJMAデータの調査」（2026-08-29）で発見した2候補
  （降水短時間予報[rasrf]・線状降水帯予測マップ[sjfcstmap]）のうち、rasrfは[T407](T407.md)
  （2026-08-30）で実装済み。sjfcstmapは局地的豪雨・突発的な河川氾濫の主因である線状降水帯の
  発生予測プロダクトで、サイクリング中の安全という観点では降水短時間予報より実用価値が
  高い可能性がある。
- T407実装時に判明した追加情報: sjfcstmapはrasrfと同じ`targetTimes.json`
  （`https://www.jma.go.jp/bosai/jmatile/data/rasrf/targetTimes.json`）にmember="none"の
  行として混在しており（`elements: ["sjfcstmap"]`のみ、rasrfを含まない）、時刻一覧の
  取得元は既に判明している。ただし**実際のタイル画像URL・配色パターンは未検証**
  （T387時点の推測「rasrfと同系統と推測されるが未検証」のまま）。
- トリガー: ユーザーの着手指示。
