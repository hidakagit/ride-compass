# T855. 難易度の帯へ距離の次元を与え、面積で負荷を表す

状態: 未着手（2026-09-14起票）
規模: M

当初T854で採番したが、並行セッションが同番号を先にmasterへ載せたためT855へ振り直した。

## 背景

総合難易度（距離加重平均）と負荷（平均×距離）が、候補パネルに別々の数字として
並んでいる。後者は前者から距離を掛けただけの派生量のため、2つ並ぶと「どちらが
このルートの評価なのか」が読み取れない（ユーザー指摘「総合難易度の位置づけが
分からなくなってきた。負荷で代替してよくない？」）。

負荷で代替はできない——区間の色分け・軸別内訳の合計一致・実験間の比較は、いずれも
距離で正規化された0-100の絶対基準を必要とする。

## 対応方針

`AxisContributionBar`の帯は、すでに長さが総合難易度を表している（幅100%＝難易度100の
目盛りで、余りが下地として見えている）。ここへ高さ＝距離を与えると、塗られた矩形の
面積がそのまま負荷になり、色ごとの面積が軸別の負荷になる。数字を1つ減らすのではなく、
1つの図が両方を持つ形にする。
