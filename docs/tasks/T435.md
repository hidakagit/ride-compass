# T435. RouteSettingsPanelの重みスライダーがデスクトップサイドバーで幅0pxに潰れる不具合を修正 規模S〜M

状態: 完了（2026-08-30）

- 背景: review:ui（2026-08-30、[history/2026-08-30_ui.md](../../.claude/commands/review/history/2026-08-30_ui.md) F-1）。
  デスクトップの固定幅サイドバー(280px)で、軸の重み調整スライダーが幅0pxに潰れて見えず操作もできない。
  原因は`.row`が1行flexで、チェックボックス・ラベル(6.5rem固定)・重み値(2.6rem固定)・
  色分けトグル(flex-shrink:0)の固定幅合計がサイドバー内幅を超え、可変幅の`.slider`
  (flex:1;min-width:0)が真っ先に0まで潰れる設計だったこと。
- 対応: `RouteSettingsPanel.module.css`の`.row`を1行flexから2段のCSS Grid
  （`grid-template-areas: "checkbox label value" "checkbox slider toggle"`、
  スライダー列は`1fr`）へ変更。上段=チェックボックス+ラベル+重み値、下段=
  チェックボックス(2段分)+スライダー+色分けトグル。固定幅要素の合計をピクセル単位で
  見積もり続ける脆い方式ではなく、スライダー列を「残り全部」にすることで、
  サイドバー幅に関わらずスライダーの実幅が0にならないことを構造的に保証する。
  `RouteSettingsPanel.tsx`は`<Checkbox>`をgrid-area指定用の`<span className={styles.checkboxCell}>`
  で包んだのみ（他のJSX構造・ロジックは無変更）。
- 検証: `RouteSettingsPanel.test.tsx`9件成功（既存、ロジック側の回帰なし）。
  実機確認（Playwright、1280x800、backend未接続の静的フォールバック軸カタログ）:
  修正前は全軸で`input[type=range]`の`getBoundingClientRect().width`が0だったのに対し、
  修正後は全軸で115.5pxとなり、値ごとに異なるつまみ位置で正しく描画されることを確認
  （スクリーンショット確認済み）。「色分け」チップの右端もサイドバー右端(280px)内の
  250pxに収まり、クリップも解消。`tsc --noEmit`・`eslint`とも問題なし。
  モバイル幅(390px、BottomSheet全幅)は元々スライダーが機能していたため非対象・
  未回帰であることをコード上確認済み（`.row`のCSS変更にメディアクエリ分岐は無く、
  グリッドの列幅計算は狭幅でも同様に機能する）。
