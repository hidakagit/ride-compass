# T611: T609で誤って削除したドラッグタイムラインを復元し、直接日時指定と両立させる

状態: 起票（2026-09-06、ユーザー指摘を受け着手中）

## 背景

T609のユーザー依頼は「クイックボタン（今/1h等）の透過バグがあるくらいなら使いにくいので、
直接日時指定できる手段を追加してほしい」だったが、実装時に「ドラッグタイムライン全体を
直接日時指定入力へ置き換える」と誤読し、`DynamicLayerTimeSlider`（目盛り・ドラッグ・
現在ボタン一式）と`departureTimeline.ts`を丸ごと削除してしまった。ユーザーから
「スライダーバーまですべて消えている」と指摘を受け発覚。

## 対応方針

- `.quickButton:hover`の透過バグ修正（border-colorへの変更）はそのまま維持する。
- 削除した`DynamicLayerTimeSlider`コンポーネント・`departureTimeline.ts`・
  embla-carousel依存を復元する。
- T609で追加したinput[type=datetime-local]は削除せず、スライダーの**追加**の直接指定手段
  として両立させる。
