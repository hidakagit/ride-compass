# T689. 合成軸も軸単体で判断できるようにする 規模M

状態: 未着手（2026-09-09起票、[T687](T687.md)より分離）

## 背景

[T687](T687.md)で、得点の隣に生値（折れ点を通す前の物理量）を出せるようにした。ただし
出せるのは`terms`の材料の単位が揃い、かつ重みがすべて正の軸に限られる。

| 軸 | 生値 | 出せない理由 |
|---|---|---|
| 停止密度・事故密度・勾配 | 出る | — |
| 車の圧迫感 | 出ない | 内部軸5本の合成で、単位そのものが無い |
| 夜間・自転車インフラ・路面 | 出ない | 真偽値/カテゴリ材料で単位が無い |
| 開放度 | 出ない | 単位は%で揃うが重みが負で、生値が常に負になる（「開放度-45%」としか読めない） |

[設計原則](../design-principles.md)11「軸は単体で評価できる」を、これらの軸はまだ
満たしていない。得点だけを見せている状態のため、T687の元になった「10点と出るが実際は
ストレスの多い経路」と同じ誤読が起きうる。

## 保留することでブロックされること

これらの軸については、利用者は引き続き得点0〜100だけで判断することになる。得点は
目盛りの引き方に依存する相対評価であり、較正を変えるたびに同じ経路の数字が動く。
軸の較正を見直すたびに「利用者から見て何がどう変わったか」を説明できない状態が続く。

## 対応方針（未確定）

候補は3つ。どれも表示の形が決まっていないため、着手時に選ぶ。

1. 内部軸それぞれの生値を出す（車の圧迫感 → 制限速度◯km/h・◯車線…）。情報量が増え、
   走行中に見る画面としては重い（[設計原則](../design-principles.md)「走行中に見るかを
   基準に情報量を絞る」）
2. 真偽値・カテゴリ材料の軸は「該当する区間が延長の◯%」を出す（夜間 → 街灯なしが32%）。
   単位ではなく割合であり、生値とは別の機構が要る
3. 開放度のように単位が揃う軸に限り、符号を戻した値を出す（被覆率の合計45%）。重みの
   符号を表示側で解釈することになり、軸定義の意味づけを表示層へ持ち込む
