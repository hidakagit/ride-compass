# T623. 風の評価軸を既存の細かい風グリッドへ乗せ替える 規模S

状態: 起票（2026-09-06）

## 背景

ユーザー報告（T619の副産物）: 風レンズが道路タイルの色分けに使う風グリッド
（`WIND_GRID_SPACING_DEG=0.1°`≒11km、`wind_way_service.py`）が粗く、市街地を
パンする程度の範囲が丸ごと同じ格子点に収まり、道路の向きに関わらず全部同じ色になる。
同じOpen-Meteoデータを使う「環境」グループの風矢印表示は既により細かい格子
（`WIND_GRID_DETAIL_SPACING_DEG`系）を持っており、これを流用する。

決定事項（spacing_deg=0.01固定）: Open-Meteoのキャッシュキー
（`weather_client.py: WeatherClient.cache_key`、`CACHE_PRECISION=2`）が緯度経度を
小数2桁（≒0.01°）に丸めるため、これより細かい間隔を選んでも同じキャッシュ値を返すだけで
解像度は上がらない。0.005°・0.0025°は実利が無いため選ばない。
