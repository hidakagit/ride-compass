# T507: 走行方位アイコンをMapLibreのズーム+/−コントロールと同じ見た目へ統一

## 背景

T506で走行方位アイコン（`TravelBearingControl`）をアプリ独自の配色トークン（円形・
`--color-surface-2`背景・`--color-accent-strong`矢印）で作り直したが、ユーザーから
続けて2件の指摘があった（2026-08-31、いずれも同日のBrowserペイン実機確認直後）:

1. 「アイコンの矢印が北向き（上）固定に見えてるけど、これスマホの向いている方角と
   連動させたってこと？」——矢印が実機センサーと連動しない手動設定値の表示専用である
   ことが伝わっていなかった。誤解防止のため一度ポップオーバーに説明文を追加したが、
   直後に「説明文言は邪魔なので、消して」と撤回を指示された。
2. 「アイコンのデザインを補正。他ボタン、＋、−等と同じ感じにできない？」——T506の
   独自配色（丸形・アクセントカラー）が、隣接するMapLibreのズーム+/−・回転コントロール
   （白背景・角丸・ダークグレーアイコン）と見た目が揃っていない。

## 対応方針

1. 説明文（`.caption`、一度追加したが撤回）を完全に削除した。誤解防止よりも操作の
   邪魔にならないことを優先する、という判断をコードコメントに残した。
2. `TravelBearingControl.module.css`の`.trigger`/`.triggerArrow`を、アプリ独自トークン
   ではなくMapLibre`.maplibregl-ctrl-group`自身の固定色（白背景`#fff`・角丸4px・
   `box-shadow: 0 0 0 2px rgba(0,0,0,.1)`のリング・29px四方・アイコン色`#333`・
   フォーカス時`box-shadow: 0 0 2px 2px #0096ff`）へ意図的に寸分たがわず揃えた。
   このコントロール自体がズーム+/−・回転コントロールの直下に連続して見える「4個目の
   ボタン」という位置付けのため、テーマに追従するトークンではなくMapLibre自身の
   （テーマ非追従の）固定色をそのまま踏襲する。
3. 矢印サイズ（`TRIGGER_ARROW_SIZE_PX`）を26px→18pxへ縮小し、29px四方のボタンに収まる
   比率へ調整した。回転による現在値の表示（T506）自体は変更していない。

## 検証結果

- `npx tsc --noEmit`・`npx eslint src/components/TravelBearingControl/`: エラー無し。
- `npx vitest run src/components/TravelBearingControl src/components/WindBearingSlider`:
  16件成功。
- Browserペイン実機確認（`localhost:3010`）: ボタンサイズがMapLibreのズーム+/−ボタンと
  同じ29×29pxであること、ナビゲーションコントロール下端との間隔が7pxで重なりが無い
  ことを座標で確認。説明文が削除されポップオーバーにダイヤルのみが表示されることを
  確認。デスクトップ（1280×720）・モバイル（375×812）どちらも視覚的にズーム+/−・
  回転コントロールの真下に続く1個のボタンとして自然に見えることをスクリーンショットで
  確認した。
- 状態: 完了。
