# T612. 地図上チップの▶パネルを表示専用から操作可能へ（全チップ共通の内訳トグル） 規模L

状態: 着手中（2026-09-06起票）

## 背景

[T610](T610.md)（災害系7種の1チップ統合）の検討中に、7要素が同時表示されると面レイヤー
同士が混色して危険度5段階を読み取れないという問題が判明した。ユーザーから「▶パネルに
個別トグルを置くのを、全地図ボタン（災害や環境に限らず）に共通適用できる？　その整理が
一番きれい」との方針提示があり、災害チップ専用のUIを作らず共通機構を先に用意することに
決定した。

現状、地図上チップ（`MapOverlayControls`）の▶パネルは**表示専用**で、`page.tsx`の
`UNUSED_LEGEND_FILTER`（一致することのないダミー値）により凡例は描画するが絞り込みは
効かない。一方サイドバー（`MapLayersPanel`）は同じ凡例に対する実際の絞り込みを持ち、
`legendFilter.ts`の汎用機構がその実体になっている。この非対称を解消し、▶パネルの各行が
トグルとして機能する形へ揃える。
