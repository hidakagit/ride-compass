# T694. masterのCIを緑に戻す（蛇行の一次属性がフロントの対応表に無い） 規模S

状態: 未着手（2026-09-10起票、統合レビュー第6回 I-1(b)。**最優先**）

## 背景

masterのCIが**5回連続でfailure**（run 855〜859、直近の成功はrun 854 = `9e01a68d`）。
失敗しているのは`frontend`ジョブの`npm test`のみで、`backend`・`e2e`はsuccess。

[T691](T691.md)（`45ffd36b`）が一次属性`curvature`をカタログへ追加した際、
`frontend/src/components/Map/primaryAttributes.ts`の手書き対応表への登録が漏れた。
`primaryAttributes.test.ts`の2件が落ちる:

- `:17-23` 全一次属性が`PRIMARY_ATTRIBUTE_CHIP_LABELS`（`:44`）に略名を持つ → `curvature`が`undefined`
- `:32-40` 全一次属性が`PRIMARY_ATTRIBUTE_LAYER_IDS`（`:70`）か
  `PRIMARY_ATTRIBUTES_WITHOUT_LAYER`（`:93`）のどちらかにある → `curvature`がどちらにも無い

`landcover`（[T624](T624.md)）は両方に追加済みなので、漏れているのは`curvature`だけ。
**ドリフト検知テストは設計どおり機能しており、赤を出し続けている側が正しい。**

## 対応方針

まず**緑に戻すことだけ**を行う。`curvature`を`PRIMARY_ATTRIBUTES_WITHOUT_LAYER`へ追加する
（蛇行は材料の`tile_property`設定でramp軸の地図レンズを自動で得ており、一次属性としての
専用レイヤーは持たない）。略名表の側は[T695](T695.md)で構造ごと片付けるため、
ここでは暫定的に略名を1件足すに留める。

## なぜ分けるか

赤いmasterの上に5コミットが積まれた状態が2日続いており、この間に入った別の回帰を
検知できない。構造の整理（T695）を待たずに**まず検知能力を回復させる**。
