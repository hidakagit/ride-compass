# T574: refresh_derived.py実行後にタイル永続キャッシュ版数が上がらず本番へ反映されない

## 背景

2026-09-04、T552（重み付き軸の欠損比率計測）の一環で本番へ`refresh_derived.py`
（[T281](T281.md)段階2）を実行したところ、DB側（`edge_attribute_counts`等）は
更新されたにもかかわらず、実際のルート生成が改善を反映しないという不具合を発見した。

原因は`refresh_derived.py`が`graph_material_cache.py`・`tile_score_matrix_cache.py`の
コメントに既存記載されている運用ルール（precompute系バッチ実行後は
`TILE_MATERIALS_CACHE_VERSION`・`TILE_SCORE_MATRIX_CACHE_VERSION`を手動で上げる）に
従っていなかったこと。`refresh_derived.py`はこれらのバッチ（
precompute_edge_attribute_counts・precompute_elevation_attributes・
precompute_road_node_degrees・precompute_way_attribute_counts）をまさに実行する
オーケストレーションスクリプトだが、実行後にバージョン文字列を上げる処理も、
上げ忘れを検知する仕組みも持たない。

## 状態

対応中（2026-09-04）
