# T896. T886で足した土地被覆レイヤーが、3つの別々の形で整合を欠いている

規模S。
状態: 未着手（2026-09-16起票、統合レビュー第10回）

## 背景

新しい面レイヤーの追加が1本道でない（[T888](T888.md)）ため、手で追従すべき箇所が3つ別々に
取りこぼされた。3つとも本番に出ている。

1. **ズーム不足の案内が一度も表示されない**。`page.tsx`が`summaryByLayerId.landcover`へ
   「ズームインすると表示されます」を入れるが、同じ`useMemo`が`legendDetailsByLayerId.landcover`へ
   常に非空の凡例を入れ、`MapOverlayControls.tsx`は`hasLegend ? 凡例 : summary`で描く。
   道路側は`regionZoomTooWide`のとき`legendDetails = []`と空にしており、landcoverにはこの
   片割れが無い。
2. **初回描画だけラスタが路面線の上に乗る**。`MapView.tsx`が`"elevation"`というハードコードのkeyで
   標高だけを路面ソースより前へホイストしている。土地被覆と路面の種類を同時にONにすると、
   再描画を押すまで路面の色分けが濁る。
3. **一次属性カタログが矛盾している**。`primaryAttributes.ts`の`PRIMARY_ATTRIBUTES_WITHOUT_LAYER`に
   `"landcover"`が残り、その根拠コメントが撤去済みの開放度軸を挙げている。ドリフト検知テストは
   「対応表に無い」「両方にある」しか見ないため通る。

統合レビュー第10回のP1 F-5（[2026-09-16_all.md](../../.claude/commands/review/history/2026-09-16_all.md)）。

## 完了条件

- ズームを引くと案内が出る／初回描画でもラスタが路面線の下／
  `primaryAttributeIdsToLayerIds(["landcover"])`がレイヤーを返す。
- [T888](T888.md)の本文へ、この3つを動機として書き足し、**射程へ「描画順の決め方」と
  「最小ズームの宣言」を含める**（どちらも`MapLayerDescriptor`へ持たせれば配列から導ける）。
