# T967: 経緯コメントの残りを引き取る（T567完了後に残った分）

状態: 未着手（2026-09-20起票）

## 背景

`scripts/review_checks.py docs`の検知器`経緯コメント`が全件実行で103件を出し続けている。
[T567](T567.md)（既存の経緯コメント一掃）は2026-09-06に完了扱いになっており、
[T826](T826.md)がDEFERで2ファイル42件を抱えているだけで、**残り61件には引き取り手が

## 対応方針

母集団は検知器の出力そのものから導く（手で一覧を持たない）:

```
python scripts/review_checks.py docs | sed -n '/ソースコードの経緯コメント（参考、全件/,/^## /p' | grep '^  - '
```

T826が抱える`frontend/src/components/Map/axisLayers.ts`・`secondaryAxes.ts`は対象外
（あちらのトリガーで消える）。それ以外を対象にする。

1件ごとの判断はdocs/comments.mdに従う——**今も成り立つ非自明な制約・理由**なら現在形の
一文へ書き直し、経緯そのものは該当する`docs/tasks/Txxx.md`へ任せて削除する。
同じ内容が対応する`docs/modules/*.md`に既にあるならコード側は消す。

## 完了条件
