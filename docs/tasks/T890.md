# T890. 検知器が「取りこぼしていない」ことを測れるようにする

規模M。
状態: 完了（2026-09-16）

## 背景

`review_checks.py`のmutateは、各検知器へわざと違反を入れて鳴るかを確かめる仕組みだが、
**プローブの素材を検知器自身の母集団から作っている**ため、母集団の穴を原理的に検出できない。

- `removed_axis_probe_id`は違反に使うidを`removed_axis_ids()`から取る。母集団から落ちる
  idはプローブにも選ばれない。
- `map_redraw_coverage`のプローブは入口の`MapView.tsx`自身へ違反を書き、
  [T871](T871.md)が広げた母集団の拡張部分を一度も通らない。
- `web_layer_batch_import`のプローブは対象内ディレクトリへ置き、対象外の`main.py`を試さない。

`.github/workflows/docs-consistency.yml`がmutateを毎push実行し、
`.claude/commands/review/README.md`がそれを「実際に鳴るか」の根拠として名指ししている。

統合レビュー第10回のP0 F-2(3)（[2026-09-16_all.md](../../.claude/commands/review/history/2026-09-16_all.md)）。
[T891](T891.md)の母集団是正より**先に**入れる——直したかどうかを測れる状態を先に作るため。

## 完了条件

- 各強制検知器に「拾うべきなのに今の母集団に入らない位置」のネガティブケースが1件ずつあり、
  現状で期待どおりMISSする（＝その時点では「MISSが期待値」として固定される）。
- [T891](T891.md)の修正後に、同じケースが赤→緑へ変わる。

## 対応方針

プローブの素材を検知器の母集団関数から取るのをやめる、という直し方では足りない——素材を
別の場所から取っても、**置く場所が母集団の内側である限り**穴は見えない。`mutate`へ
「母集団の外縁」という第2の表を足し、検知器ごとに「拾うべきなのに今の母集団へ入らない位置」を
1件ずつ固定して、そこを拾えるかどうかの**期待値**と突き合わせる。

期待値がFalseの行は既知の穴（`GAP`）で、監査は落ちない。穴を埋めたら期待値をTrueへ
更新する。**埋まったのに更新していない場合も、埋めたはずの穴がまた空いた場合も`CHANGED`と
して落ちる**——どちら向きの変化も気づける。

## 実装メモ

- `EdgeProbe(where, detected, mutate, mode)`と`guard_probe_edges(wt)`を新設。外縁を持たない
  検知器（母集団が全件）は、理由の文字列を値に置く。
- `scripts/tests/test_review_checks.py`へ、強制検知器すべてが外縁のケースか「外側が無い」
  宣言のどちらかを持つことを固定するテストを足した（正例の網羅テストと対になる）。
- 正例の3つのヘルパー（`live_text`・`append`・`write`）を`probe_fs`へ出し、外縁側と共有した。
- **mutateがWindowsの手元で動いていなかったのを直した**: 未コミット変更をworktreeへ持ち込む
  `git apply`へパッチを**テキストで**渡しており、改行がCRLFへ変換されて文脈行が1行も
  一致しなかった（「未コミット変更をworktreeへ適用できませんでした」で即終了する）。
  バイト列で渡す形へ変更。編集中の検知器を試せるという、この仕組みの前提そのものが
  手元では成立していなかった。

## 検証結果

- `python scripts/review_checks.py mutate`: 正例44件すべてPASS、外縁22件すべて期待どおり
  （**既知の穴20件**＋外側が無い宣言2件［`plan_vs_tasks`・`task_numbering`］）。所要は
  86秒→134秒。
- **効いていることの確認**: `removed_axis_mentions`の期待値をTrue（拾えるはず）へ書き換えて
  実行すると`CHANGED 期待=検知 実際=見逃し`となり監査が落ちる。戻すと通る。
- 外縁20件の内訳は「記法での絞り込み」（アンダースコア・バッククォート・リンクの名前一致）、
  「手書きの母集団」（WEB_LAYER_DIRS・MATERIAL_TAG_READER_FILES・
  MODULE_REDEFINITION_PREFIXES・1ホップ固定）、「実在判定corpusがコメント込み」、
  「ファイル種別での除外」（README.md・__init__.py・globals.css・e2eのspec・
  backend/scripts・backendのテスト）、「追加でない変更」（改名）の5型。
  このうち[T891](T891.md)が埋めるのはコメント込みcorpusと記法の絞り込み。
