# T890. 検知器が「取りこぼしていない」ことを測れるようにする

規模M。
状態: 未着手（2026-09-16起票、統合レビュー第10回）

## 背景

`review_checks.py`のmutateは、各検知器へわざと違反を入れて鳴るかを確かめる仕組みだが、
**プローブの素材を検知器自身の母集団から作っている**ため、母集団の穴を原理的に検出できない。

- `removed_axis_probe_id`は違反に使うidを`removed_axis_ids()`から取る。母集団から落ちる
  idはプローブにも選ばれない。
- `map_redraw_coverage`のプローブは入口の`MapView.tsx`自身へ違反を書き、
  [T871](T871.md)が広げた母集団の拡張部分を一度も通らない。
- `web_layer_batch_import`のプローブは対象内ディレクトリへ置き、対象外の`main.py`を試さない。

`.github/workflows/docs-consistency.yml`がmutateを毎push実行し、
`.claude/commands/review/README.md`がそれを「実際に鳴るか」の根拠として名指ししている。

統合レビュー第10回のP0 F-2(3)（[2026-09-16_all.md](../../.claude/commands/review/history/2026-09-16_all.md)）。
[T891](T891.md)の母集団是正より**先に**入れる——直したかどうかを測れる状態を先に作るため。

## 完了条件

- 各強制検知器に「拾うべきなのに今の母集団に入らない位置」のネガティブケースが1件ずつあり、
  現状で期待どおりMISSする（＝その時点では「MISSが期待値」として固定される）。
- [T891](T891.md)の修正後に、同じケースが赤→緑へ変わる。
