# T535: 「ルートをクリア」で実験スロット（地図に残る緑線）も消えるようにする

状態: 完了（2026-09-02）

- 背景: ユーザー報告「ルートをクリアしても、地図に緑の線が残る。スマホでしか
  再現しない」。原因は研究モード中の生成が記録する`experimentSlots`
  （`page.tsx`、地図重ね描き・比較タブ用の履歴、最大3件、1件目の色が
  `EXPERIMENT_SLOT_COLORS[0] = "#16a34a"`＝緑）。`handleRoutesClear`が
  `experimentSlots`をリセット対象に含んでおらず、他に空へ戻す経路も無かった。
- 対応: `handleRoutesClear`（`frontend/src/app/page.tsx`）が`setExperimentSlots([])`
  も呼ぶよう変更。実験スロット履歴を残す設計よりも「クリアしたら地図が本当に
  空になる」という一般的な期待を優先する、というユーザー判断による。
- 検証: `page.test.tsx`に新規テストを追加（研究モードON→生成→クリア→再生成で、
  クリア前のスロットが残っていないことを確認）。`npx tsc --noEmit`・
  `npx eslint`ともクリーン。`npx vitest run src/app/page.test.tsx`17件green。
