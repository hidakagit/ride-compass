# T797. 出発地・経由地・目的地を同じ形で置けるようにする

規模M。
状態: 着手（2026-09-13、ユーザー要望「出発地、目的地、経由地、を明示的にピンを選んで
配置したい。出発地はデフォルトは現在地で良いが、現在地を移動できるのが分かりにくい」）

## 背景

3つとも役割は同じ「地点を置く」なのに、操作の形が揃っていない。

- 出発地: 地図の赤ピンを**ドラッグ**でしか動かせず、画面に手掛かりが無い。戻す操作は
  別の「現在地に移動」ボタンが兼ねている。
- 目的地: ボタンで武装してから地図をタップ。
- 経由地: **武装なしの素のタップ**で増える。パネルには件数と全消しの✕だけ。

## 対応方針（案A、モックで合意）

「条件」タブの目的地モードに、3つの地点を**同じ形の行**で並べる。行頭には地図のピンと
同じ色の印を置き、行とピンを見た目で結ぶ。

- 行の操作で武装し、武装した行だけを強調する。出発地の行にも操作が出るため、動かせること
  自体が画面に現れる（置いたあとは「現在地に戻す」へ変わる）。
- **ピンを置けるのは行を選んでいる間だけ**にする（[T781](T781.md)と同じ理屈で、地図を
  触っただけで経由地が増える事故が無くなる）。経由地だけは連続して置けるようにする。
- 地名での検索（[T631](T631.md)）は別タスク。行の値表示をそのまま使える形にしておく。
