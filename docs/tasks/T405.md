# T405. 動的要素の二重表現（風の環境/評価軸表示、Redis経由way_id→値配信）

状態: 未着手（[T400](T400.md)節2からの分割）

- 背景: 詳細はT400.md「2. 動的要素（時刻・向き等）を含む材料は『環境』と『道路』の二重表現を
  持つ」参照。環境グループの風は時刻＋方位（連続回転）スライダー＋`gridFill`で面表示。評価軸
  グループの風は、風グリッドの値とway自身の方位から`wind_penalty`を計算し`way_id`をキーに
  Redisへキャッシュ、新設の軽量APIとMapLibreの`setFeatureState`で道路タイルと合成して線色分け
  する。ルート確定後は環境グループの風チップと既存`routeStyleModes`の風モードを統合する。
