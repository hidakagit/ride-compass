# T606. キキクル4種・風/勾配road-value系レイヤーのデータ取得状態（読込中/データなし/失敗）可視化

状態: 作業中（2026-09-05起票）

## 背景

T603・T605でJMAタイル/色別標高図タイルの404を「珍しくない正常系」として扱うよう
バックエンド側を是正した過程で、ユーザーから「今エラーになっているもの以外も同じ思想が
必要かチェックして」「ユーザー向けにその地点は欠損だったことを示せる？　風とかもそうなん
だけど、今は読込待ちなのか区別がつかない」との指摘。

調査の結果、フロントエンド側に以下2つの独立したギャップがあると判明した。

1. キキクル4種（landslideRisk/heavyRainRisk/inundationRisk/floodRisk）は改善計画T432で
   「防災カテゴリとして常時マウント・チップ無し」とした経緯があり、他の環境グループ
   （降水ナウキャスト・風・雷等）が持つ`useLayerDataStatus`（T87）の読込中/データなし/
   エラー追跡から意図的に除外されている。ユーザーへ「読込中なのか欠損なのか」を示す手段が
   無い。
2. 風/勾配のroad-value系レイヤー（`useDynamicWayValues.ts`/`dedicatedWayValueLayer.ts`）は
   loadingフラグ自体を持たず、「読込中」と「取得したが値が無い」の両方を同じ
   `COLOR_NO_DATA`（灰色）で表示している。

ユーザーへ「①（キキクル）は地図タイルに出そうか、環境グループはまとめて同じ仕組みに」との
方針提示を受け、AskUserQuestionで確認した結果、**キキクル4種にも他の環境グループ
（降水ナウキャスト・風・雷等）と同じ「地図上チップ」を持たせ、T432の「チップ無し常時表示」
方針を撤回する**方針で合意した。あわせてLayerChipのdataStatusドット機構を地図上チップ
（MapOverlayControls.tsx）へ拡張し、環境グループの全レイヤー（キキクル含む）が同じ
チップ+ドットで読込中/データなし/エラーを示せるようにする。
