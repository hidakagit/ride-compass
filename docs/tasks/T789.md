# T789. 「条件」タブの入力値を次回も引き継ぐ

規模S。
状態: 着手（2026-09-13、ユーザー要望「周回/目的地、距離、候補数、毎回直すの面倒」）

## 背景

周回/目的地モード・距離・候補数は、開くたびに既定値へ戻る。同じ人が同じような条件で
繰り返し生成するため、毎回直す手間がそのまま毎回かかる。地図レイヤーの表示状態や
下部シートの高さ（[T785](T785.md)）は既にlocalStorageで引き継いでいる。

## 対応方針

同じ仕組み（`useStoredState`）で「条件」タブの入力値を保存し、次に開いたときの初期値に
する。目的地・経由地そのもの（地図上のピン）は対象にしない——場所は行くたびに変わるうえ、
古いピンが残っていると気づかないまま生成してしまう。
