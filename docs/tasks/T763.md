# T763. 候補の後処理チェーンを1箇所へ寄せる 規模S

状態: 未着手（2026-09-12起票。[T621](T621.md)の設計中、合成ルートを既存候補と同じ形へ
仕上げる導線を探して見つけた）

## 背景

`route_generator.py`は、候補を返す3経路（周回・目的地・経由地）それぞれで同じ4行を
並べている（`_with_overall_difficulty`→`_with_axis_difficulties`→
`_with_axis_contributions`→`_with_material_values`）。**「候補を評価済みの完成形へ
仕上げる」という1つの手順が、呼び出し側に3回写経されている状態**で、
[構造仕様8](../design-principles.md)の「拡張点は1本道」に当てはまる。

後処理を1段増やす・順序を変える・新しい経路を足すたびに、3箇所を揃えて直す必要がある
（揃わなくても型は通り、テストも経路ごとに独立しているため気づきにくい）。

## 保留することで何が起きうるか

- [T621](T621.md)が合成ルートを返す4本目の経路を作る。1箇所へ寄せないまま着手すると
  写経が4箇所へ増え、**合成ルートだけ後処理が1段抜ける**類の不整合が入りうる。
