# T762. 研究モード「比較」タブの空状態・表の幅・再生成後の表示

規模M。
状態: 完了（2026-09-15。2026-09-12起票）

## 背景

研究UIだが、操作可能性は一般UIと同基準で見る（[review:ui](../../.claude/commands/review/ui.md)の観点）。本番実測:

- **空状態**: `ComparisonPanel`は実験スロットが2件未満で`null`を返す。1回目の生成後に「比較」タブを開くとタブの下に何も無く、壊れて見える
- **表の幅**: 行見出しが「一時停止・徐行の密度(回/km) - poi_stop_per_km」のようにラベル＋内部idで長く、デスクトップ（サイドバー280px）では値の列が全て画面外（横スクロールのみ）。モバイルでも表の幅452 / 372。左上の列見出しが空セル
- **内部語彙**: ヒント文に「overall_difficulty」「軸スタジオ」が残る（[T438](T438.md)の修正は`RouteAxisProfile`側のみ）
- **再生成後**: `handleGenerate`は`comparisonTabActive`を変えないため、比較タブを開いたまま再生成すると新しい候補ではなく比較表が表示されたままになる
- **重ね描きの色**: スロット線（緑・橙・紫）が災害レイヤーの緑と衝突する（[T754](T754.md)で扱う）

個票は[history/2026-09-12_ui.md](../../.claude/commands/review/history/2026-09-12_ui.md)のF-17〜F-20。

## 調査項目

1. 空状態の文言（「もう1回生成すると比較できます」）をどこが出すか。`ComparisonPanel`自身の自己ガードを保つなら、`null`ではなく案内を返す
2. 行見出しに内部idが入る経路（材料カタログのラベルか、フロントの整形か）を確定し、一般向けの表示から外す。行見出しの幅を固定し、値の列を優先する
3. 生成成功時に候補タブへ戻す（`comparisonTabActive=false`）。比較タブを見続けたい場合があるか（スロットが積まれるのを眺める用途）
4. ヒント文の内部語彙を一般向けの言い回しへ

## 完了条件

- 1回目の生成後に比較タブを開いたとき案内が出ること
- 280px幅・390px幅の両方で、比較表の値の列が横スクロール無しで読めること
- 比較タブを開いたまま再生成したとき、新しい候補が表示されること

## 起票後の変化（2026-09-13、棚卸し）

背景の「デスクトップ（サイドバー280px）」は古い。[T759](T759.md)でサイドバーを380pxへ広げた
ため、表の幅の再測定が要る（狭いほうの制約はモバイル390px）。空状態・行見出しの内部id・
再生成後にタブが戻らない点は、いずれも実装に手が入っていない。

## 対応（2026-09-15）

- **空状態**: スロット0件・1件のとき`null`ではなく案内を返す（「もう1回生成すると…」）。
  自己ガードは`ComparisonPanel`自身に残したまま、返すものを空白から案内へ変えた。
- **行見出しの内部id**: 材料カタログの`label`は「論理名 - 物理名」で、これは材料を選ぶ
  軸スタジオの都合。一般向けの表示のために`MaterialCatalogEntry.name`（論理名だけ）を
  APIへ足し、比較表は`materialCatalogName`で引く。**`label`から物理名を削って作り直さない**
  ——論理名に区切り文字が含まれたときに壊れる。
- **表の幅**: `table-layout: fixed`で列を器の幅から決める（内容に合わせて伸ばさない）。
  行見出しは折り返して6rem、値は収まらなければ折り返す。列見出しからエンジン名を外した
  ——`road_graph`一択（T462でopenrouteserviceを撤去）で全列に同じ文字列が並ぶだけだった。
  正確な時刻・エンジン・その回の重みは見出しの`title`が持つ。
- **再生成後**: `handleGenerate`が`comparisonTabActive`を倒し、候補タブへ戻す。

## 検証

- `e2e/comparison.spec.ts`（新規2件、モバイル390px）: 1回目の生成後は案内が出ること、
  2回目で表が**器の幅に収まる**こと、比較タブを開いたまま生成すると候補へ戻ること。
  幅の破綻はhappy-domでは捕まらない（実寸を返さない）ため、e2eで見る。
- **検査が効くこと**: 表の幅の検査は、直す前は517.4px、列見出しを詰めた段階でも402.6pxで
  落ちた（いずれも器は390px）。`table-layout: fixed`で通るようになった。
- `npx vitest run`・`tsc --noEmit`・`eslint`・`prettier`・`CI=1 npx playwright test`
