# T756. 本番の地図初期表示が「地図を読み込み中」のまま長時間止まる

規模M。
状態: 未着手（2026-09-12起票）

## 背景

本番で初期表示の「地図を読み込み中…」が30〜70秒続くセッションが5回中3回あった。ルート生成は先に完了して候補一覧だけ出る（backendは応答している）。他の2回は6〜15秒で表示された。初見ユーザーは白紙の画面で待たされ、壊れているのか待てばよいのか判断できない。

個票は[history/2026-09-12_ui.md](../../.claude/commands/review/history/2026-09-12_ui.md)のF-1。

## 調査項目

1. **どこで止まっているか**の切り分け。基礎地図スタイル（`/api/basemap`経由、Next.jsのrewritesでbackendへ転送）・スタイルが参照するタイル・フロントのMapLibre初期化のどれか。ブラウザのネットワーク記録で最初のスタイル取得の所要時間を測る
2. **backend側の要因**。同時刻にアメダス観測値の取得も失敗していた（T757）。backend起動直後に外部データ系だけが失敗する既知の事象や、Renderのコールドスタートと重なっていないか。`/health`の`started_at`と症状時刻を突き合わせる
3. **フロント側の表示**。一定時間を超えたら「再試行」と原因の見当を出す。dev環境で観測されたMapLibre初期化停止（[T578](T578.md)前後の記録）と同型かも確認する

## 完了条件

- 止まる箇所を1つに特定し、実測値（秒）とともに個票の「対応状況」欄へ書く
- 特定した箇所への対応、または一定時間超過時の再試行導線のどちらかを入れる
