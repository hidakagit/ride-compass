# T515: 未使用依存関係 @fseehawer/react-circular-slider の削除

## 背景

T503でWindBearingSlider（走行方位コンパス）が`@fseehawer/react-circular-slider`非依存の
自前実装（矢印を回転させるダイヤル）へ全面的に作り替わった結果、
frontend/package.jsonのdependenciesに未使用の依存関係が残っていた
（`grep -rn "react-circular-slider" frontend/src`でコードベース全体から参照ゼロを確認済み）。
T503実施時、frontend/package.json/package-lock.jsonへ並行セッションが別の変更を同時に
加えていたため削除自体は見送られていた。

## 対応

- frontend/package.jsonのdependenciesから`@fseehawer/react-circular-slider`を削除。
- `npm install`でpackage-lock.jsonを同期（該当エントリが除去されたことを確認）。
- `docs/architecture.md`に残っていた「`WindBearingSlider`は`@fseehawer/react-circular-slider`
  採用」という古い記述を「矢印を回転させる自前実装」へ修正（T503時点で実装は既に
  差し替わっていたが、architecture.mdの追従が漏れていた）。

## 経緯確認（ユーザー指摘への回答）

作業中、ユーザーから「review:metricで使うから足したのでは」という確認があった。
調査の結果:
- `@fseehawer/react-circular-slider`がpackage.jsonへ追加されたコミットは
  T414（ddf54d2）1回のみ。
- 追加理由は[T414.md](T414.md)「frontend」節に明記の通り、WindBearingSlider
  （時刻＋向きのうち「向き」を指定するコンパスUI）の実装で、[T400.md](T400.md)の
  事前調査（自前SVG実装ではなく定番ライブラリを優先検討する方針）に基づき採用したもの。
- `review:metric`というスキル・コマンドはリポジトリ内（`.claude/commands/review/`配下、
  スキル一覧）のどこにも存在せず、`metric`文字列を含む他ドキュメント（T261.md・
  T302.md）もこの件と無関係な偶然の一致だった。
- 以上より、このライブラリの用途はWindBearingSlider実装のみであり、T503でその実装が
  作り替わった時点で不要になったことを確認した。

## 検証結果

- `npx tsc --noEmit`: `src/app/layout.tsx(31,50): error TS2304: Cannot find name
  'LayoutProps'.`のみ発生。依存削除前（fseehawer残存状態）でも同一エラーが再現する
  ことを確認済みで、本タスクと無関係な既存事象。
- `npx eslint src/`: エラーなし。
- `npx vitest run`（フロントエンド全体）: 99ファイル・907件すべて成功
  （`ECONNREFUSED ::1:3000`ログは既存テストがlocalhost:3000への接続失敗を意図的に
  検証している箇所のもので、テスト結果には影響しない）。
