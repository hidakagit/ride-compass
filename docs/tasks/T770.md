# T770. ルート線が面レイヤーの上で読めない（縁取りが無い）

規模S。
状態: 未着手（2026-09-12起票）

## 背景

区間の色分け線（`MapView.tsx: DETAIL_LAYER_ID`）は幅6px・不透明度1の単線で、色は
レンズ配色（総合難易度なら易しい＝緑）。縁取り（ケーシング）を持たないため、同系色の
面レイヤーが背景に来ると線の輪郭が消える。研究モードの比較スロット線（`drawExperimentSlots`、
緑・橙・紫）も同じ。

[T754](T754.md)の症状（地図全面が緑）は空タイル用PNGが不透明だったことが原因で、そちらは
別に直る。ただし「面が何色でも線が読める」という性質は`route-detail-segments-line`側に
無いままで、降水・標高図・キキクルの実データなど他の面でも同じことが起きる。

## 調査項目

- ケーシングを足す場所（`DETAIL_LAYER_ID`の直下にもう1本置く／`line-gap-width`を使う）と、
  比較スロット線への同じ扱いの適用範囲
- 縁取りの色を固定色にするか、ライト/ダークで変えるか（地図は常にライト配色）
- 矢印ハロー（`ROUTE_ARROW_HALO_LAYER_ID`）が既に持つハローとの重複・整合

起票時はT769だったが、同番号を別セッションが先にmasterへ載せたため振り直した。
