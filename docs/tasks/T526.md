# T526: 内訳バーの視覚表現見直し（軸数に応じて理論上100/N%まで潰れる）

状態: 未着手（2026-09-01起票、T524見送り分の追跡。トリガー未成立）

- 背景: `RouteAxisProfile.tsx`の軸別内訳バー（改善計画T518）は、バー長を
  「重み付き寄与度」（`raw*weight/weightSum`）にしている。公開軸8本にほぼ均等な
  重み（各0.125）が配分された標準状態では、raw=100（最悪値）の軸でもバー長は
  トラック幅の約12.5%にしかならない。全行が短いスリバー状になり、「軸間の相対
  比較」という内訳の目的が視覚的に成立しにくい可能性がある（T524コードレビュー
  correctness角度指摘）。数値列も0-100の難易度ではなく1桁の寄与度（例:「6」「3」）
  になり、同じ画面の「41/100 総合難易度」との読み取り基準の違いが説明されないまま
  残っている。
- 見送った理由: T518の設計意図（「バー長＝影響度、バー色＝深刻度」）自体は
  ユーザーからの明示的な指摘（「おすすめ度が高いのに重みづけが逆転していると
  混乱する」）に基づく妥当な設計であり、バグではなくUXチューニングの余地という
  位置づけ。着手にはトリガー条件を設けた。
- トリガー: 実機で複数軸のバーを並べて見た際に「短すぎて比較しづらい」という
  実感がユーザーから出た場合。
- 対応方針の候補（着手時に再検討）: バーの最大値を「全軸均等配分時の理論上限」
  ではなく、実際に表示中の軸の中での最大値（相対スケール）にする、または寄与度と
  生の難易度の両方を視覚的に区別できる形で見せる、等。
