# T501: 軸スタジオの複製しきい値リセット・公開済み軸の表示専用フィールド直接編集

状態: 着手中（2026-08-31）

## 背景

ユーザーがAxis Studioの複製ウィザード（Step4）で、地図の色分けしきい値
（`display_thresholds_override`）が複製元の値をそのまま引き継いでいる（自動計算が
働いていないように見える）ことに気づき、記載外の改善として2点を依頼した。

1. しきい値のデフォルトを、直前のステップで入力した変化点（breakpoints）から
   自動計算できないか。
2. 軸スタジオで公開済みの軸を編集できるようにできないか。不整合はあるか。

## 対応方針（ユーザー承認済み、2026-08-31）

1. **複製時のしきい値リセット**: `derive_ramp_inputs()`（backend/app/domain/
   axis_display.py）は`display_thresholds_override`が`None`ならbreakpointsのX値から
   既に自動計算している。複製フロー（`AxisComposer.tsx: draftFromDuplicate`）が
   複製元の手動設定値をそのまま引き継いでいたため自動計算が発動しなかった。
   複製時に`displayThresholdsOverride`を`null`へリセットする。
2. **公開済み軸の表示専用フィールド直接編集**: T271の「公開済み軸は不変・複製のみ」
   原則自体は維持する（一般ユーザーの保存重み設定がaxis_idキーで再現されるため、
   評価ロジックに影響する変更は依然禁止）。ただし評価結果に一切影響しない表示専用
   フィールド（`icon_id`・`chip_label`・`panel_hint`・`show_map_icon`・
   `display_thresholds_override`）だけは、公開済みのまま（unpublishを経由せず）直接
   更新できるよう例外を設ける。全フィールド編集可能にすると元の問題（他ユーザーの
   ルート結果が意図せず変わる）が再発するため、意図的に狭いスコープに留める。
