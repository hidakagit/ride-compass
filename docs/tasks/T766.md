# T766. RouteCandidateのテストフィクスチャを1箇所へ寄せる 規模S

状態: 未着手（2026-09-12起票、[T621](T621.md)で`edge_ids`を足したときに露見）

## 背景

フロントの`RouteCandidate`は`Omit<Required<...>>`で型付けされているため、
**全フィールドが必須**で、候補を組み立てるテストは全フィールドを書く。その構築が
8箇所に散っており、フィールドを1つ足すたびに8箇所を直すことになる。

`edge_ids`（T621）の追加で実際に8箇所が同時に落ちた。tscが機械的に全件を挙げるため
取り残しは起きないが、毎回8ファイルを触る差分が出る。

[T650](T650.md)がテストのフェイクを`frontend/src/testing`へ集約した先例があり、
同じ置き場へ寄せられる見込み（`e2e/fixtures.ts`は別のビルド対象のため要確認）。
