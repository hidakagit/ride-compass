# T939. レンズ凡例の段階が、ルート前後で別系統のキー・別の表記で作られている 規模M

状態: 未着手（2026-09-19起票、統合レビュー第11回）

## 背景

同じ軸の同じ段階が、ルート生成の前と後で別の実装から作られている。非表示キーの保存先は共有のため、
ルート前に隠した段が生成後に黙って復活し、「一部非表示」の表示だけが残る。
最上位帯の語も`以上`と`超`で食い違い、`超`の側は述語（`>=`）と逆である。
