# 手動タスクの前提

`python scripts/orchestrate.py prereqs $ARGUMENTS`を実行し、出力を要約する。

- 先頭に「前提N件・残りM件」を置き、残りの前提を状態（稼働中なら担当・判断待ち・振り出し待ち・
  停止中・未着手）と一緒に並べる。
- 残り0なら「開始してよい」とはっきり書く。
- 前提の一覧は仕掛中のダッシュボードで持つ（`docs/conventions/asking-user.md`「仕掛中のダッシュボード」節。
  前提に入れる基準は`docs/conventions/orchestration.md`「ユーザーが手動で進めているタスク」節）。足す・外すは
  ダッシュボードで行い、記録を書き換えるコミットにも状態の表にもしない。道具の読み先を記録の`## 前提（並行実行）`節から
  ダッシュボードへ移すのはT1073で、それまでは記録の節とダッシュボードの両方を読んで合わせる。
  前提を先に進めるなら`/orchestrate:priority --prereqs-of <Txxx> 高`。
- このコマンドはリポジトリも状態の表も書き換えない。
