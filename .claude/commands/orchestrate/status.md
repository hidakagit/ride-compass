# 並行実行の状態

`python scripts/orchestrate.py status $ARGUMENTS`を実行し、出力を要約する。

- 要約の先頭に、稼働中の本数と上限・監査待ち・停止ファイルの有無を1行で置く。
- エージェントごとに「何をしていて・いつ始めて・見込みに対してどこにいて・異常があるか」を
  1〜2行で書く。出力の`!`（状態の表と事実の食い違い）は必ず拾い、`?`（確かめるべき点）は
  該当があるものだけ挙げる。
- 表に無いのに動いている作業ツリーがあれば、それも挙げる（上限の数え方に入る）。
- 読み取りだけで、状態の表もリポジトリも書き換えない。食い違いの是正は
  `docs/conventions/orchestration.md`「異常の是正」節に従って、別の手順として行う。
